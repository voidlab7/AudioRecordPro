## PawMBTI 答题选项闪动 Bug 修复

### 问题
答题时切换题目，选项会"闪动"一次。

### 根因分析
**双重 opacity 入场动画叠加**：
- 卡片级（`QuizCard` 的 `motion.div`）：整卡片 `opacity: 0 → 1` + 滑入
- 选项级（`OptionCard` 的 `motion.button`）：每个选项又独立做 `opacity: 0 → 1, y: 20 → 0`，且带 delay

两层 opacity 叠加后，选项在卡片滑入时先透明，等 delay 后再渐显，视觉上就是"闪动"。

### 修复
- `QuizCard.tsx`：移除 `OptionCard` 上的 `initial/animate/transition` 和 `delay` prop
- `ProQuizCard.tsx`：移除 `ProOptionCard` 上的 `initial/animate/transition` 和 `delay` prop
- 保留卡片级滑入动画（spring + opacity），保留选中指示器的 scale 动画

### 待办
- ⏳ Nginx 配置 `try_files` — `/quick` 和 `/pro` 返回 404，需在服务器端添加 SPA 路由回退

## PawMBTI 累积统计次数功能修复

### 问题
服务器上的"累计 N 次测评"计数功能未生效，原因：
1. `count-server.cjs` Node.js 服务可能未在服务器上启动
2. 部署脚本 `deploy_website.sh` 只会 `pm2 restart`，不会首次 `pm2 start`，导致首次部署后服务不会自动启动
3. Nginx 需要配置 `/api/` 反向代理到 `127.0.0.1:3001`

### 修复
- `deploy_website.sh`：改进计数服务启动逻辑，新增 pm2 进程存在性判断（有 → restart，无 → start + save）
- `nginx-example.conf`：添加 `X-Forwarded-For` 和超时设置

### 服务器配置步骤
1. 安装 pm2：`npm install -g pm2`
2. 首次手动启动：`cd /var/www/pawmbti-server && pm2 start count-server.cjs --name pawmbti-counter && pm2 save && pm2 startup`
3. 确认 Nginx 配置包含 `/api/` 反向代理
4. 之后部署脚本会自动管理重启

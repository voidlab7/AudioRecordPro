## PawMBTI v1.6.1 发版 — 修复移动端保存结果图片不生效

### 问题分析
原方案使用 `<a download>` + `link.click()` 触发下载，在移动端不生效：
- iOS Safari 不支持通过 `<a download>` 下载 Data URL
- 微信内置浏览器完全禁用 download 属性
- Android 部分浏览器行为不一致

### 解决方案
采用「弹窗预览 + 长按保存」方案，分三层降级：
1. **Web Share API**（优先）：支持的浏览器直接调起系统分享面板
2. **弹窗预览**（移动端降级）：全屏弹窗显示图片，提示用户长按保存
3. **`<a download>`**（桌面端）：保持原有下载行为

### 新增文件
- `src/components/shared/ImagePreviewModal.tsx`：通用图片预览弹窗
  - 移动端提示"长按图片保存到相册"
  - 微信浏览器特殊提示"选择保存图片"
  - 桌面端提示"已自动下载"+"右键另存为"
  - ESC/点击背景关闭
- `src/hooks/useSaveImage.ts`：通用截图保存 Hook
  - 封装 html2canvas 截图 + Web Share API + 弹窗预览

## PawMBTI 新增：埋点系统 + 邀请码 + 数据看板

## PawMBTI 资源优化（解决 SSL ERROR + 低带宽）

### 问题
- 4Mbps 带宽服务器经常出现 SSL ERROR
- 首屏资源过大（原 ~1.5MB），并发能力极低

### 优化措施
1. **图片压缩**：public 目录从 1.7MB → 384KB
   - 删除 logo-original.png(968K)、og-image.svg(115K)、og-logo-temp.png(42K)、vite.svg
   - favicon-512x512 从 248K → 40K（缩到192px）
   - 新增 og-image.webp(12K)、favicon-512x512.webp(8K)
2. **HTML 优化**：精简 favicon 引用（4个→2个），移除冗余 Twitter Card 标签
3. **Nginx 配置重写**（nginx-example.conf）：
   - SSL session 缓存（减少重复握手）
   - 连接/请求速率限制（防单用户打满带宽）
   - assets/ 强缓存 365 天 + immutable
   - 图片/字体缓存 30 天
   - Gzip comp_level 6 + 更多 MIME 类型
   - HTTP → HTTPS 强制跳转
4. **首屏加载**：从 ~1.5MB 降到 **~156KB (gzip)**，并发提升约 10 倍

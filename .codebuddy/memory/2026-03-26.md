## 邀请链接管理后台实现

### 扩展后端 API（count-server.cjs）
新增以下管理端点：
- `POST /api/invite/revoke` — 撤销邀请码
- `POST /api/invite/update` — 编辑邀请码（修改使用次数、过期时间、备注、恢复已撤销码）
- `GET /api/invite/usage` — 查看使用记录（支持按码筛选、分页）
- `GET /api/invite/stats` — 统计概览（活跃/过期/撤销/用完数量、7天趋势、TOP10热门码）
- `POST /api/invite/cleanup` — 批量清理过期和已撤销码
- `GET /api/admin/invite` — 管理后台 HTML 页面

改进：
- 提取 `verifyAdmin()` 公共管理员验证函数，去除重复代码
- 验证接口返回详细错误码（INVALID_TOKEN / TOKEN_EXPIRED / USAGE_LIMIT_REACHED）
- 新增 `invite-usage-log.json` 详细使用日志（记录 IP、UA、Referer）
- 邀请码新增 `status` 字段，支持 active/revoked 状态

### 管理后台页面（admin-invite.html）
独立 HTML 页面，通过 `/api/admin/invite` 访问，功能包括：
- 🔐 登录认证（使用 ADMIN_PASSWORD）
- 📊 概览面板：统计卡片 + 7天使用趋势图 + 热门码TOP10
- 📋 管理面板：邀请码列表（搜索、状态筛选、编辑、撤销/恢复、复制链接、清理过期）
- ➕ 生成面板：批量生成邀请码（数量/次数限制/有效期/备注）
- 📈 使用记录：带分页和筛选的详细使用日志

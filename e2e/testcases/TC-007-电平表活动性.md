## 断言

- A1 人工判读：B 组电平明显高于 A/C 组，B 组内部帧间有变化
- 帧间差异机判（可选增强，Python PIL）：

```bash
# 两帧不同像素数粗判（电平区域裁剪后对比），活动帧 vs 静止帧差异显著
python3 - <<'EOF'
from PIL import Image, ImageChops
a = Image.open('帧A.png').convert('L'); b = Image.open('帧B.png').convert('L')
diff = ImageChops.difference(a, b)
bbox = diff.getbbox()  # None = 完全相同
print('帧间差异区域:', bbox)
EOF
```

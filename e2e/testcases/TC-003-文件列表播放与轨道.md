# TC-003 — 文件列表 → 播放 → 暂停 → 删除

> 首次执行：待执行 | 类型：E2E 功能链路 | P0
> 覆盖：「选择录制好的文件可以播放」「录制好的音频有轨道，轨道可以播放」

## 前置条件

- App 内已有 ≥1 条录音（沙盒 `AudioRecordings/` 非空；没有就先跑 TC-002 产出一条）
- 基线：记录沙盒目录文件数

```bash
ls ~/Library/Containers/com.voidzhang.audio-record-mac/Data/Documents/AudioRecordings/ | wc -l
```

## 步骤与预期

| # | CU 动作 | 预期 | 验证 |
|---|---|---|---|
| 1 | 侧栏切到「录制文件」标签 | 文件列表渲染（文件名/时长） | 截图 + AX |
| 2 | 点第一条文件 | 选中态；右侧出现轨道（波形）与播放控制 | 截图 |
| 3 | 轨道波形断言 | 波形非空白、有幅度起伏（与录音内容对应） | 截图 |
| 4 | 点播放 | 状态「播放中」、进度推进 | 间隔 3s 截图×2，进度数值变化 |
| 5 | 点暂停（空格键或按钮） | 状态「已暂停」、进度停住 | 截图×2 对比进度不变 |
| 6 | 再点播放 → 点停止 | 播放结束/复位 | 截图 |
| 7 | 删除该文件 | 列表项消失；沙盒文件同步删除 | 截图 + ls 计数 -1 |

## 硬验证（A3）

- 播放进度由 App UI 反映引擎 currentTime，CU 层以两帧进度差 > 0（播放）与 = 0（暂停）机判（A1）
- 删除断言（A3）：

```bash
ls ~/Library/Containers/com.voidzhang.audio-record-mac/Data/Documents/AudioRecordings/ | wc -l
# 预期 = 步骤 0 的基线 - 1；文件名与被删条目一致地消失
```

## Pass 条件

1. 波形截图非空白（有可辨识幅度结构）
2. 播放进度两帧有差、暂停后两帧无差
3. （如执行删除）沙盒文件同步消失

## 备注

- 暂停键的 AX 标识以 get_app_state 实测为准（探索后固化到本表）
- 轨道与波形渲染深度验证（缩放、播放头联动）归 TC-010 像素级还原或后续编辑器专项

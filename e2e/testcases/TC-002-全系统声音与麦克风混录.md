## 硬验证（A3）

```bash
RECENT=$(ls -t ~/Library/Containers/com.voidzhang.audio-record-mac/Data/Documents/AudioRecordings/*.m4a 2>/dev/null | head -1)
echo "产物: $RECENT"
afinfo "$RECENT" | grep -E 'duration|format'
# 转 wav 算 RMS（非静音断言）
afconvert "$RECENT" /tmp/tc002.wav -d LEI16@48000 -c 2
python3 - <<'EOF'
import wave, struct, math
w = wave.open('/tmp/tc002.wav'); n = w.getnframes()
data = struct.unpack(f'<{n}h', w.readframes(n))
rms = math.sqrt(sum(x*x for x in data)/len(data))
print(f'RMS={rms:.0f}')
assert rms > 500, '静音/极低电平 → FAIL'
print('PASS: 非静音')
EOF
```

## Pass 条件

1. 「全部系统声音」选中态 + 麦克风 toggle 开启态截图落盘
2. 产物时长 ∈ [5, 18]s（8s 录制 + 状态切换开销）
3. RMS > 500（440Hz 正弦波通道有效）
4. 时长 > 0 且非静音（BUG-1 回归点）

## 备注

- 麦克风通道单独断言较难（环境音不可控），本用例以「系统通道有效 + 麦克风混入无报错」为准；麦克风通道深度验证方案（对麦播放已知测试音）后续单独立用例
- 「麦克风单录」当前不支持（麦克风是附加输入，见 README 功能缺口表）

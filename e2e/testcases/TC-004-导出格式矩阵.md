# TC-004 — 导出格式矩阵（M4A / WAV / FLAC / AIFF）

> 首次执行：待执行 | 类型：E2E 功能矩阵 | P1
> 覆盖：「录制之后可以转成其他格式」
> 编码链路事实（REL-006 后）：四格式全走系统原生编码（AVAudioFile/CoreAudio），无 ffmpeg、无外部进程；
> MP3/OGG 已随 ffmpeg 导出链移除（macOS 26 无 Apple MP3 编码器，CoreAudio 无 Vorbis）

## 前置条件

- 有一条 ≥8s 录音（可复用 TC-002 产物）
- 无 ffmpeg 依赖（REL-006 起 App 不再携带/探测 ffmpeg）

## 步骤（每种格式一轮，共 4 轮）

| # | CU 动作 | 预期 |
|---|---|---|
| 1 | 文件列表选中录音 → 顶栏「导出」（或 Cmd+E，菜单项「导出」） | 导出卡片弹出（默认 M4A） |
| 2 | 点格式下拉 → 选目标格式 | 卡片格式显示更新，无警告文案（REL-006 起 FLAC 不再提示需要 ffmpeg）。坑：NSPopUpButton 首点不生效，必须点开菜单后 get_app_state 当帧确认 → 当帧坐标点菜单项（TC-001 坑 1） |
| 3 | 点卡片「导出」→ NSSavePanel 确认（存 `~/Desktop/tc004_<fmt>.<ext>`）→ 再确认 | 「正在解密并转码…」→「✅ 导出成功」。坑：双确认（TC-001 坑 2） |
| 4 | 下一格式，循环 | — |

## 硬验证（A3，逐格式）

```bash
for f in ~/Desktop/tc004_*; do echo "== $f"; afinfo "$f" | head -6; done
```

断言（逐格式）：

| 格式 | afinfo 期望 | 时长 |
|---|---|---|
| M4A | AAC | ≈ 源时长 ±1s |
| WAV | pcm / 16-bit | 同上 |
| FLAC | flac（File type ID: flac；24bit 源出 24bit） | 同上 |
| AIFF | aiff / pcm | 同上 |

- 全部格式：文件 > 0 字节、时长 > 0（BUG-1 拦截断言）
- FLAC 专项：`afinfo` 必须能读出 `estimated duration`（STREAMINFO 已 finalize）——REL-006 前探针实证未 finalize 的 FLAC 流 afinfo 报 AudioFileOpenURL failed，故此断言同时守护 finalize 时序

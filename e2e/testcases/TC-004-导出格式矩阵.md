# TC-004 — 导出格式矩阵（MP3 / FLAC / OGG / M4A / AIFF）

> 首次执行：待执行 | 类型：E2E 功能矩阵 | P1
> 覆盖：「录制之后可以转成 MP3 等其他格式」
> 编码链路事实：M4A/WAV/AIFF 原生编码；MP3/FLAC/OGG 走 App 内置 ffmpeg（build-app.sh 打包进 Resources）

## 前置条件

- 有一条 ≥8s 录音（可复用 TC-002 产物）
- App Resources 内有 ffmpeg（`build/AudioRecordMac.app/Contents/Resources/ffmpeg` 存在且可执行）

## 步骤（每种格式一轮，共 5 轮）

| # | CU 动作 | 预期 |
|---|---|---|
| 1 | 文件列表选中录音 → 顶栏「导出」 | 导出卡片弹出（默认 M4A） |
| 2 | 点格式下拉 → 选目标格式 | 卡片格式显示更新。坑：NSPopUpButton 首点不生效，必须点开菜单后 get_app_state 当帧确认 → 当帧坐标点菜单项（TC-001 坑 1） |
| 3 | 点卡片「导出」→ NSSavePanel 确认（存 `~/Desktop/tc004_<fmt>.<ext>`）→ 再确认 | 「正在解密并转码…」→「✅ 导出成功」。坑：双确认（TC-001 坑 2） |
| 4 | 下一格式，循环 | — |

## 硬验证（A3，逐格式）

```bash
for f in ~/Desktop/tc004_*; do echo "== $f"; afinfo "$f" | head -6; done
# OGG 若 afinfo 不识别，用 ffmpeg 校验：
for f in ~/Desktop/tc004_*.ogg; do ffmpeg -i "$f" 2>&1 | grep -E 'Duration|Audio'; done
```

断言（逐格式）：

| 格式 | afinfo/ffmpeg 期望 | 时长 |
|---|---|---|
| M4A | AAC | ≈ 源时长 ±1s |
| MP3 | MPEG audio | 同上 |
| FLAC | flac | 同上 |
| OGG | ffmpeg 识别 Audio: vorbis/opus | 同上 |
| AIFF | aiff / pcm | 同上 |

- 全部格式：文件 > 0 字节、时长 > 0（BUG-1 拦截断言）

## Pass 条件

5 种格式全部产出且编码/时长断言通过；不支持的格式要记录明确报错截图（并在 README 矩阵标注能力边界），不算静默 FAIL。

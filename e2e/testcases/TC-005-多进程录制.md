## 硬验证（A3）

时长/RMS 同 TC-002。混录内容用频谱断言验证双源真实性：

```bash
RECENT=$(ls -t ~/Library/Containers/com.voidzhang.audio-record-mac/Data/Documents/AudioRecordings/*.m4a | head -1)
afconvert "$RECENT" /tmp/tc005.wav -d LEI16@48000 -c 2
python3 - <<'EOF'
import wave, struct, math
w = wave.open('/tmp/tc005.wav'); n = w.getnframes(); sr = w.getframerate()
data = struct.unpack(f'<{n}h', w.readframes(n))[::2]  # 左声道
N = min(len(data), 24000)  # 前 0.5s
def amp(freq, step=2):
    s = c = 0.0
    for i in range(0, N, step):
        a = data[i]
        s += a*math.sin(2*math.pi*freq*i/sr); c += a*math.cos(2*math.pi*freq*i/sr)
    return math.hypot(s, c)/(N//step)
e440, e880 = amp(440), amp(880)
print(f'440Hz={e440:.1f}  880Hz={e880:.1f}')
assert e440 > 100 and e880 > 100, '双源混录缺失 → FAIL'
print('PASS: 440Hz 与 880Hz 同时存在')
EOF
```

## Pass 条件

1. 两个进程均在列表出现且可同时选中（多选交互探索后固化）
2. 产物时长 ∈ [7, 20]s、RMS 非静音
3. 440Hz 与 880Hz 频率分量同时存在（混录真实性证明）

# QA（鉴） — 用户偏好记忆

> 最后更新: 2026-05-17

## 沟通偏好

- 用户偏好结构化 BUG 清单（表格 + 严重度 + 修复方案）
- 用户要求按 REQ 维度对照验收
- 报告需要包含修复优先级和工作量估算

## 工作习惯

- 用户会交叉切换角色（枢→绘→矩→铸→鉴），流程完整
- 用户重视 ai-workspace 的产物沉淀
- 用户发现问题后会要求写入记忆

## 技术偏好

- macOS 原生 App（Swift/AppKit），不是 Web
- 自绘控件体系（Industrial Design），不用系统控件
- 编译验证（build.sh）是基本门槛
- BUG 报告按严重度分 CRITICAL / HIGH / MEDIUM / LOW

## 一、交付内容

### R1 单边渲染 + 暗轮廓
- `EditorWaveformView` 三条绘制路径（bars / tiles / skeleton）从「上下镜像剪影」切**单边向上生长**（贴 clip 下缘，上半空间让给音量线——剪映语言）
- `WaveformEnvelopeRenderer` 新增 `fillUpward(points:baselineY:color:)`：与 `fillMirror` 同语言的闭合包络一次填充；单点/零宽退化 = 3pt 贴基线静音带（FIX-004「压平保基线带」语义延续）
- `clipGain: Float`（0…2.0，didSet clamp + 重绘）；`envelopeFullHeight / envelopeBaselineY / envelopeMaxAmp / volumeLineY` 共用标尺（渲染与拖拽换算同源）
- **暗轮廓层**：gain≠100% 时先画原始包络（waveformBase alpha 0.30、不乘 gain），再叠增益波形——对标剪映「线上方暗轮廓、线下亮色」，降/增增益一眼可读

### R2 音量线 + 拖拽 + 播放联动
- 音量线：横贯 clip 的 1.5pt 水平线，`y = 满幅标尺 × gain`（gain=100% 时恰在波形峰顶；过 100% 钳 maxAmp）
- 拖拽圆点：9pt 实心圆+白描边，**跟随播放头**（播放头不在可视区时贴右缘内侧）——对标老板参考图「白色圆形拖拽点」
- 热区：圆点 ±14pt 或音量线 ±8pt，优先级在 seek 之前；`mouseDragged` 反解 `gain = (y − baseline) / 满幅`，实时重绘（高度实时跟随）
- 播放联动：delegate 新增 `editorWaveformView(_:didChangeGain:)` → `EditorViewController` 接 `previewPlayerNode?.volume`（取代原轨道头滑条职责）

### R3 过载变色 + 轨道头滑条移除
- 过载态（gain>100%）：波形/音量线/圆点统一切 `waveformOverdrive #FF6B4A`；音量线常态 `volumeEnvelope #FFA94D`（剪映橙，老板参考图拍板）——新增两 token，不碰既有色
- 轨道头音量滑条**全链拆除**：`VolumeSliderView` 类（51 行）、`trackRowDidChangeVolume` delegate、`setVolume` API、`onTrackVolumeChange` 回调、`EditorAudioTrack.volume` 死字段；`muteButton` 上移贴编号行；**静音喇叭保留**（UI-031 交付物，需求单明示）

## 三、已知限制与取舍（如实声明）

1. **gain>100% 播放不增响**：`AVAudioPlayerNode.volume` 上限 1.0；且拍板 a 导出=原始音频。过载区视觉警示「波形被推入削波区」，实际听感不变。如需真实过载增益需接 MixerNode，另开单

3. clipGain 不落盘（同上，单 clip 检视器无 clip 模型接线）

## 交付内容（3 文件 + lite 脚本注释）

1. **Kit `Sources/Utils/SpaceKeyPolicy.swift`（新增）**：三态纯函数 `.toggle` / `.swallowRepeat` / `.passthrough`。修饰键只显式查四个真实位（Cmd/Shift/Option/Ctrl，rawValue 硬编码避免 Kit 依赖 AppKit），非标准 flag 位（R10 坑1 的 0x2000_0000）不污染判定。文本焦点布尔由 App 侧传入（NSTextView 类型检查留在 App）。
2. **Kit `Tests/SpaceKeyPolicyTests.swift`（新增，6 用例）**：纯空格 toggle / repeat 吞 / 文本焦点放行 / 四修饰键逐一放行 + 组合放行 / 非空格键放行 / 非标准位不污染（R10 坑1 回归固化）。
3. **EditorViewController.swift**：
   - `togglePlayback()`：播放中→stopPreview（FIX-003 保留 playhead=暂停语义），未播放→startPreview（从暂停处续播）；`editorToolbarDidTapPreviewPlay` 转调同一入口（「不另起播放逻辑」字面成立）。
   - 监视器生命周期：`EditorRootView.viewDidMoveToWindow` → `windowPresenceChanged` 回调 → `updateSpaceKeyMonitor(present:)` 挂/撤；deinit 兜底清理。
   - `isKeyWindow` 判定在**监视器闭包**（窗口分发层），`handleSpaceKeyEvent` 只做逻辑分发——见下「排障 R3」。
   - 初始焦点收归：编辑器挂载时若焦点误落可编辑控件（keyViewLoop 自动分配），一拍 async 收归窗口（`makeFirstResponder(nil)`）——用户显式点击输入框时焦点自然进入，未提交内容走 textDidEndEditing 正常 commit。防御性代码（本轮 lite 环境未观察到该状态，first_responder 观测字段=NSResponder 占位）。
   - lite 第 14 步 `space_toggle`：合成 CGEvent（`keyboardSetUnicodeString` 避 R10 坑2 + `.keyboardEventAutorepeat` 位）走 `handleSpaceKeyEvent` 与监视器同一逻辑分发，六断言——①toggle→播放 ②再 toggle→暂停 ③playhead 原位（先 seek dur×0.5 的确定性判定）④repeat 帧吞不切换 ⑤Cmd+Space 放行不切换 ⑥真窗口临时 field editor 聚焦时空格 passthrough、`makeFirstResponder(nil)` 恢复后再 toggle 生效；detail 带 `first_responder`/`key_window` 观测字段。步数 13→14。

## 排障记录（R1→R3，3 轮收敛）

1. **R1 轮 FAIL（ev_repeat=false）**：误判方向「初始焦点在输入框致 textFocus=true 全 passthrough」——合成事件层最小脚本验证 isARepeat/flags 保真无问题后，R2 轮加初始焦点收归仍 FAIL。
2. **R2 轮 FAIL（同症）**：加诊断日志（passthrough 原因 + 断言处 firstResponder 快照）。
3. **R3 轮真相（key_window=false）**：`handleSpaceKeyEvent` 开头的 `isKeyWindow` guard 是元凶——**无人值守跑批时主窗口非 key 属常态**（agent shell 的宿主 App 前台，`open` 拉起的被测 App 被抢焦点），R1/R2 全部假象皆源于此（「焦点在输入框」推断错误）。修法：isKeyWindow 上移监视器闭包（生产语义不变：局部监视器只收本 app 事件，非 key 时正常键盘事件本就进不来，guard 防的是 CGEvent 注入类合成边缘），逻辑分发层不再做窗口检查——lite 直调测逻辑不被「哪个 app 在前台」污染。R4 轮 14/14 全 PASS。
4. **方法论**：纸面推理 2 轮无果后第 3 轮直接把判定输入（isRepeat/textFocus/rawModifiers/keyWin/firstResponder 类型）打进日志一次定位——**分发类 bug 早该上观测**。

## 用户故事

> **作为**一个音频工作者，**我想要**把客户发来的 WAV 文件转为 MP3，**以便**通过邮件发送（WAV 太大无法附件）。

---

## 功能描述

支持 6 种音频格式互转，提供比特率、采样率、声道等参数配置。

---

## 支持格式

| 格式 | 编码方案 |
|------|----------|
| M4A | AVFoundation |
| WAV | AVFoundation |
| AIFF | AVFoundation |
| MP3 | FFmpeg（libmp3lame） |
| FLAC | FFmpeg |
| OGG | FFmpeg（libvorbis） |

---

## 参数配置

| 参数 | 选项 |
|------|------|
| 比特率 | 128 / 192 / 256 / 320 kbps |
| 采样率 | 22.05 / 44.1 / 48 / 96 kHz |
| 声道 | 单声道 / 立体声 |
| 质量预设 | 低 / 中 / 高 / 无损 |

---

## 验收标准

| # | 标准 | 通过条件 |
|---|------|----------|
| 1 | 格式互转 | 6 种格式互转正确，输出可播放 |
| 2 | 转换速度 | 10 分钟音频转换 < 5 秒 |
| 3 | 质量 | 有损转换听感无明显劣化 |
| 4 | 参数 | 比特率/采样率/声道配置生效 |
| 5 | 错误处理 | 损坏文件给出明确提示 |

---

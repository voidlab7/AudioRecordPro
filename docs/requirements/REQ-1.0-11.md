## 用户故事

> **作为**一个用户，**我想要**录音在异常情况下不丢失，**以便**安心录制长时间内容而不担心意外中断。

---

## 功能描述

处理各种异常场景，确保录音数据安全和用户体验。

---

## 异常场景处理

| 异常场景 | 处理方案 |
|----------|----------|
| **磁盘空间不足**（< 100MB） | 录制前检测，弹窗警告；录制中空间耗尽 → 立即停止，保存已录内容 |
| **App 被强杀 / 系统崩溃** | 使用临时文件写入，App 重启后检测 → 提示"发现未保存的录音，是否恢复？" |
| **录制文件损坏** | 导出时校验完整性；损坏文件标记⚠️，提示"文件可能已损坏" |
| **权限中途被撤销** | 立即停止录制 → 保存已录内容 → 弹窗提示 |
| **外接音频设备断开** | 自动切换到内置设备继续录制（不中断），状态栏提示 |
| **录制中 Mac 进入睡眠** | 阻止睡眠（IOPMAssertion）；强制合盖 → 停止录制并保存 |
| **进程录制目标进程退出** | 自动停止录制 → 保存已录内容 → 提示 |

---

## 技术要点

- 临时文件写入机制（防止 App 被杀丢数据）
- IOPMAssertion 阻止睡眠
- 磁盘空间监控（< 100MB 阈值）
- 文件完整性校验

---

## 验收标准

| # | 标准 | 通过条件 |
|---|------|----------|
| 1 | 异常恢复 | App 被杀后重启可恢复未保存录音 |
| 2 | 磁盘保护 | 磁盘满时正确停止并保存 |
| 3 | 权限撤销 | 权限撤销后保存已录内容并提示 |
| 4 | 设备断开 | 设备断开后自动切换继续录制 |
| 5 | 睡眠阻止 | 录制中不进入睡眠 |
| 6 | 进程退出 | 目标进程退出后正确停止并保存 |
| 7 | 文件校验 | 损坏文件正确标记 |

# REQ-2.0-02 启动默认录制准备态 UI 重构

## 版本：V2.0 | 优先级：P0 | 状态：⬜ 待开发

> 基于实际界面反馈新增的插队需求
> 目标：纠正首屏 UI 信息架构——刚打开应是"录制准备态"，不是"空编辑器 / 空时间线"
> 预估工时：1 天

---

## 1. 一句话需求

应用启动后，主界面应呈现清晰的"录制准备态"——用户一眼就知道"这是一个录音工具，我可以立即开始录制"，而不是看到空白的编辑器时间线或空波形区域产生困惑。

---

## 2. 问题背景

### 当前问题

应用启动后（`.idle` 状态），波形区域显示空白/静态内容，编辑工具栏可见但无意义（没有内容可编辑），整体给人"空编辑器"的感觉，而非"准备录制"的感觉。用户首次打开时不确定下一步该做什么。

### 期望效果

启动后的首屏应传达明确的信息层级：
1. **主行动点**：录制按钮是视觉焦点，引导用户"点击开始录制"
2. **录制目标**：当前选中的录制源清晰可见（系统声音 / 某个应用）
3. **准备就绪**：电平表显示实时输入电平（证明音频通路已就绪）
4. **无干扰**：编辑工具栏在 idle 态隐藏或置灰，不分散注意力

---

## 3. 范围

### In Scope

- 定义 `.idle`（录制准备态）的完整 UI 表现
- 波形区域在 idle 态的占位内容设计（非空白）
- 编辑工具栏在 idle 态的可见性/交互性控制
- 电平表在 idle 态的行为（是否显示实时输入电平预览）
- 轨道板在 idle 态的显示内容
- 控制面板在 idle 态的视觉强调（录制按钮突出）
- 状态栏在 idle 态的提示文案

### Not in Scope

- 录制进行态（`.recording`）的 UI 改动（已在 REQ-2.0-01 完成）
- 编辑态（`.editing`）的 UI 改动（在 REQ-2.0-05 处理）
- 虚拟时间线波形实现（在 REQ-2.0-03 处理）
- 多轨道显示（在 REQ-2.0-06 处理）

---

## 4. UI 设计规格

### 4.1 波形区域（idle 态）

**当前**：空白区域或静态中线

**改为**：
- 显示居中的引导提示，如麦克风/音波图标 + "点击录制按钮开始" 文案
- 背景保持深色（工业风格），图标和文案使用 `IndustrialColors.textSecondary`
- 如果有上次录制的文件，可选择显示"上次录制：xxx.wav"的快捷入口

### 4.2 编辑工具栏（idle 态）

**当前**：工具栏按钮全部可见

**改为**：
- idle 态下编辑工具栏整体隐藏（`isHidden = true`）或所有按钮置灰（`isEnabled = false`）
- 录制完成进入编辑态后才显示/启用

### 4.3 电平表卡片（idle 态）

**当前**：静态显示零电平

**改为**：
- 如果音频输入源已就绪，显示实时输入电平预览（让用户确认"声音通路正常"）
- 如果音频源未就绪，显示"未检测到音频输入"提示

### 4.4 轨道板（idle 态）

**当前**：显示轨道信息但无内容

**改为**：
- 显示当前选中的录制目标名称和图标
- 轨道状态指示为"待录制"（灰色圆点，非红色录制指示灯）

### 4.5 控制面板（idle 态）

**当前**：录制按钮与其他按钮同等视觉权重

**改为**：
- 录制按钮（● REC）视觉突出：更大的尺寸或脉冲动画暗示"可点击"
- 播放/停止按钮在 idle 态置灰（无内容可播放）
- 计时器显示 "00:00.00"（保持不变）
- 格式信息（48kHz·32bit·立体声）保持显示（让用户知道录制参数）

### 4.6 状态栏（idle 态）

**当前**：显示"准备就绪"

**改为**：
- 显示更具引导性的文案，如"选择录制目标，点击 ● 开始录制"
- 或显示当前录制目标："准备录制：全部系统声音"

## 7. 验收标准

- [ ] 应用启动后，波形区域不显示空白，而是显示有意义的引导占位内容
- [ ] 编辑工具栏在 idle 态不可交互（隐藏或置灰）
- [ ] 录制按钮在 idle 态是视觉焦点（最突出的可交互元素）
- [ ] 电平表在 idle 态显示实时输入电平（如果音频源可用）
- [ ] 状态栏显示引导性文案（非简单的"准备就绪"）
- [ ] 从 idle 态点击录制后，UI 平滑过渡到 recording 态
- [ ] 录制停止后不回到 idle 态（进入 editing 态，由 REQ-2.0-05 处理）
- [ ] 首次启动的用户能在 3 秒内理解"这是录音工具，点录制按钮开始"

## 10. 设计参考

### 竞品参考

- **Audio Capture Pro**：启动后显示清晰的录制目标列表 + 大录制按钮，无空白区域
- **Logic Pro**：新建项目后显示"拖放音频文件或点击录制"的引导
- **GarageBand**：启动后录制按钮是最突出的 UI 元素

### 设计原则

- **信息架构清晰**：idle 态 = 录制工具，不是编辑器
- **行动引导明确**：用户不需要思考下一步是什么
- **状态区分明显**：idle / recording / editing 三态视觉差异大

# REQ-1.0-01 系统音频录制引擎

> **版本**：V1.0 | **优先级**：P0 | **预估**：2天
> **状态**：✅ 已完成
> **关联**：[需求列表](./README.md) | [V1_功能细化](../product/v1-feature-breakdown.md)

---

## 用户故事

> **作为**一个知识工作者，**我想要**录制系统播放的音频（如 YouTube 视频、网课），**以便**后续离线反复收听学习，不需要每次都打开浏览器。

> **作为**一个远程工作者，**我想要**录制 Zoom 会议的全部音频，**以便**会后整理会议纪要，不遗漏重要信息。

---

## 功能描述

使用 CoreAudio Process Tap（macOS 14.4+）捕获系统全局音频输出，实现高质量系统音频录制。

---

## 技术规格

| 项目 | 规格 |
|------|------|
| 技术方案 | CoreAudio Process Tap（macOS 14.4+） |
| 采样率 | 48kHz |
| 声道 | 立体声 |
| 位深 | 16-bit PCM 或 AAC |
| 启动延迟 | < 100ms |
| 稳定性 | 连续录制 4 小时无崩溃 |
| 权限 | 仅需系统音频权限（非屏幕录制权限） |

---

## 功能要求

1. 捕获系统全局音频输出
2. 不影响用户正常听音
3. 支持热插拔外接音频设备
4. 录制过程中设备切换不中断

---

## 验收标准

| # | 标准 | 通过条件 |
|---|------|----------|
| 1 | 基本录制 | 录制 YouTube 声音，回放清晰无杂音 |
| 2 | 启动延迟 | 点击录制到实际开始 < 100ms |
| 3 | 长时间稳定性 | 连续录制 4 小时无崩溃、无内存泄漏 |
| 4 | 热插拔 | 录制中插拔耳机不崩溃，音频正常切换 |
| 5 | 用户无感 | 录制过程中用户正常听音不受影响 |

---

## 依赖

- macOS 14.4+
- CoreAudio Process Tap API
- 系统音频权限（REQ-1.0-08）

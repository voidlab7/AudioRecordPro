---

## 用户故事

> **作为**一个用户，**我想要**进入编辑模式对录音进行后期处理，**以便**不需要打开专业软件就能完成简单编辑。

---

## 功能描述

提供音频编辑器的 UI 框架，包含波形显示、工具栏和撤销/重做系统的基础架构。

---

## 入口

文件列表 → 选中文件 → 编辑按钮

---

## 布局结构

```
┌─────────────────────────────────────┐
│ ← 返回  |  文件名  |  ↩ ↪  |  保存  │
├─────────────────────────────────────┤
│                                     │
│           波形显示区域               │
│         （支持缩放/滚动）            │
│                                     │
├─────────────────────────────────────┤
│  裁剪 | 静音裁剪 | 标准化 | 淡入淡出  │
└─────────────────────────────────────┘
```

---

## 功能要求

1. 波形显示支持缩放（放大/缩小）
2. 波形支持水平滚动
3. 撤销/重做按钮（最多 20 步）
4. 保存按钮（覆盖原文件 或 另存为）
5. 返回按钮（未保存时提示）
6. 工具栏展示可用编辑工具

---

## 验收标准

| # | 标准 | 通过条件 |
|---|------|----------|
| 1 | 进入编辑 | 从文件列表正确进入编辑器 |
| 2 | 波形显示 | 音频波形正确渲染 |
| 3 | 缩放 | 波形可放大/缩小，细节清晰 |
| 4 | 返回 | 未保存时提示是否保存 |
| 5 | 布局 | 各区域布局合理，操作直觉 |

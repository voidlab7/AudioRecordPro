# REQ-1.0-03 麦克风录制

> **版本**：V1.0 | **优先级**：P0 | **预估**：1天
> **状态**：✅ 已完成
> **关联**：[需求列表](./README.md) | [V1_功能细化](../product/v1-feature-breakdown.md)

---

## 用户故事

> **作为**一个用户，**我想要**录制自己的声音，**以便**制作旁白、语音备忘或播客素材。

---

## 功能描述

使用 AVAudioEngine 录制麦克风输入，支持系统默认输入设备及外接设备。

---

## 技术规格

| 项目 | 规格 |
|------|------|
| 技术方案 | AVAudioEngine |
| 输入设备 | 系统默认输入设备 |
| 外接支持 | USB 麦克风 / 蓝牙耳机麦克风 |
| 采样率 | 48kHz |
| 声道 | 单声道/立体声（跟随设备） |

---

## 功能要求

1. 使用系统默认输入设备录制
2. 支持外接 USB 麦克风
3. 支持蓝牙耳机麦克风
4. 设备切换时自动跟随系统默认设备

---

## 验收标准

| # | 标准 | 通过条件 |
|---|------|----------|
| 1 | 基本录制 | 录制人声，回放清晰无杂音 |
| 2 | USB 麦克风 | 外接 USB 麦克风正常录制 |
| 3 | 蓝牙耳机 | 蓝牙耳机麦克风正常录制 |
| 4 | 设备切换 | 录制中切换设备不崩溃 |

---

## 依赖

- AVAudioEngine（macOS 14.4+）
- 麦克风权限（REQ-1.0-08）

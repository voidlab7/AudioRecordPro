# REQ-1.0-02 进程级音频录制

> **版本**：V1.0 | **优先级**：P0 | **预估**：2天
> **状态**：✅ 已完成
> **关联**：[需求列表](./README.md) | [V1_功能细化](../product/v1-feature-breakdown.md)

---

## 用户故事

> **作为**一个播客制作者，**我想要**只录制 Chrome 中播放的访谈音频（不录制其他 App 的通知声），**以便**获得干净的素材用于后期制作。

---

## 功能描述

使用 CoreAudio Process Tap（macOS 14.4+）指定进程音频捕获，实现单进程音频隔离录制。

---

## 技术规格

| 项目 | 规格 |
|------|------|
| 技术方案 | CoreAudio Process Tap（macOS 14.4+） |
| 进程列表刷新 | 2 秒轮询 |
| 选择模式 | 单选 |
| 进程显示 | 名称 + 图标 |

---

## 功能要求

1. 实时刷新进程列表（2 秒轮询）
2. 显示进程名称 + 图标
3. 单选模式选择目标进程
4. 无音频输出的进程灰显
5. 进程退出自动停止录制，保存已录内容
6. 仅录制指定进程声音，其他 App 不混入

---

## 验收标准

| # | 标准 | 通过条件 |
|---|------|----------|
| 1 | 隔离录制 | 仅录制 Chrome 声音，其他 App 声音不混入 |
| 2 | 进程列表 | 正确显示当前有音频输出的进程 |
| 3 | 进程退出 | 目标进程退出后自动停止并保存已录内容 |
| 4 | ~~灰显~~ | ~~无音频输出的进程正确灰显~~ — **V1.0 砍掉**，仅显示有音频的进程 |
| 5 | 刷新 | 新启动的 App 在 2 秒内出现在列表中 |

---

## 依赖

- macOS 14.4+
- CoreAudio Process Tap API
- 系统音频权限（REQ-1.0-08）

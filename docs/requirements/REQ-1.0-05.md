## 用户故事

> **作为**一个用户，**我想要**清晰的录制状态反馈和流畅的控制交互，**以便**随时知道当前录制状态并快速操作。

---

## 功能描述

实现完整的录制状态机和对应的 UI 交互反馈。

---

## 状态机定义

```
IDLE → PREPARING → RECORDING → STOPPING → IDLE
                                    ↓
                                  ERROR
```

---

## 按钮交互

| 状态 | 按钮样式 | 交互 |
|------|----------|------|
| IDLE | 红色圆形 | 点击开始录制 |
| PREPARING | 红色 + 旋转动画 | 不可点击 |
| RECORDING | 红色方形 + 脉冲动画 | 点击停止 |
| STOPPING | 灰色 + 旋转动画 | 不可点击 |
| ERROR | 红色警告 | 点击重试 |

---

## 实时信息显示

| 信息 | 刷新频率 |
|------|----------|
| 录制时长 | 1s |
| 文件大小 | 2s |
| 音频电平 | 60fps |
| 波形显示 | 60fps |

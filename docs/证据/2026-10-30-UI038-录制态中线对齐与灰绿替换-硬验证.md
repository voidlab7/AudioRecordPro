1. **单一基准 `centerlineY(in:)`**（新增）：roundedBars 路径返回 `42 + max(1, h−88)/2`（= timelineRect 垂直中心 = 条带层 position.y 42 + 条带图内 centerY stripH/2 的合成视觉中心）；静态预览态返回 `rect.midY`（跟随剪影原基准，不波及 UI-037 已验收形态）；envelope 备用风格返回 `rect.midY`（维持原状）。
2. **`drawNativeTimeline`**：虚线 centerY 从 `rect.midY` 改为 `centerlineY(in: rect)`（消除恒差 2pt）；虚线绘制加条件 `stripOwnsCenterline = isRecording && renderStyle == .roundedBars && !waveformData.isEmpty`——录制中条带已出现时整根虚线让位（需求审核拍板「推荐②」），尚无数据/预览/停止态照常显示。
3. **`drawRoundedBars`**（停止后静态兜底）：centerY 同改 `centerlineY`，与录制中条带层无中线跳变。
4. **`renderBarsStrip`**：注释锚定恒等关系（strip 内 `stripH/2` + clip 层 position.y=42 ≡ `centerlineY` roundedBars 分支），数值不动（它本就是基准持有者）。

## R2 轮（2026-10-30 验收期返工）：点击录制瞬间即变绿，灰线不再滞留一拍

> 老板验收反馈：「预期是默认一条灰线，点击时灰线变成绿线，然后从右往左移动。现在点击录制会闪一下灰线，然后才变成绿线。」

**根因（代码取证）**：R1 的三处门控都以「已有波形数据」为切换条件——`useStripLayer`（条带层显隐）、`updateStripTranslation` guard（条带驱动）、`stripOwnsCenterline`（灰线让位）均含 `!waveformData.isEmpty`。点击录制后首条数据要等音频引擎启动 + 第一个时间桶（barInterval）才落下（数百 ms 量级），期间：灰虚线照画（=「闪一下灰线」）；首条落下瞬间灰虚线**整根消失**、仅右端冒一个绿点、左侧空白（≠「整条变绿」）。

**R2 修法（+18/−6，WaveformView.swift 4 处）**：
1. `draw()`：`useStripLayer` 去掉 isEmpty——录制中条带层常显。
2. `updateStripTranslation()`：guard 去掉 isEmpty；平移公式 `n = max(1, min(count, maxVisibleBars))`，无数据期按 n=1 静音点行参与（右缘贴 timeline 右缘）；phase 无数据期恒 0。首条落下时 (n−1) 增一且相位归零，两者相抵——与既有未满窗/满窗连续性同性质，像素级无跳变。
3. `renderBarsStrip()`：槽位补零至满宽 `maxVisibleBars`——补零槽位 amplitude 经 `max(1.0,·)` 钳 2pt 圆头绿点（与真实静音条同形态同色），点击瞬间即整条「变绿」。
4. `drawNativeTimeline()`：`stripOwnsCenterline` 去掉 isEmpty——录制中灰虚线无条件让位。

**改后时序**：点击录制 → 灰虚线消失、满宽静音点行同位出现（灰→绿瞬时换色，无滞留）→ 首条数据从右端槽位逐条替换、整条点行随相位从右往左推进 → 停止后回到灰虚线兜底（R1 基准，无跳变）。

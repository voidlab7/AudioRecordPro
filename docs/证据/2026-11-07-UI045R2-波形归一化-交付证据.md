## 需求（老板原话）

「剪映这个设计是所有音频，它可以把波纹打满，但是它不会顶到最顶部。而我们不一样，我们往上抬的时候，最底部它不会往上走很多，会有很多很平的音频，它不会顶上去。我需要剪映的设计。」（附剪映三态图：初始→打一半→打满 +20.0dB，对照我们实机平坦趴底）

## 实现（机制）

`amp_norm = sample / clipPeakNorm × normHeadroom`，再走既有 `drawGainAwareEnvelope`（增益线性叠加 + 越满幅溢出红，零改动）：

| 项 | 值/说明 |
|---|---|
| 归一基准 `clipPeakNorm` | clip 全局桶峰值最大值（allSamples.max / tiles max；非视口内重算→缩放滚动不跳变） |
| headroom | 0.90（最大段恒到可用高 90%——「打满但不顶到最顶部」） |
| 增益叠加 | 音量线 gainScale 在归一化之上线性放大（拖线整条上涨、安静段明显上移） |
| 过载语义 | 不变：越满幅段 #FF6B4A 溢出红；+20dB 极限态整条近满格（对齐剪映图 2/3） |
| 覆盖路径 | 粗桶 / 逐列真峰值细路径（UI-041，帧级峰值钳 1 防跳采伪过冲）/ tile 三路全改 |
| 编辑命令后重算 | undo/redo/split/delete 全走 `loadAudio(from:)` 重建 allSamples → 计算属性自动随新 buffer 重算 |
| 纯显示层 | 播放（FIX-020 EQ 链）/导出（±1 口径）/录制态波形（FIX-018 方案 A）/dB 气泡与拖拽交互零改动 |
| 取代关系 | FIX-010 拍板 B「固定满刻度」在编辑器显示层被本归一化取代（Kit 层 `WaveformAmplitudeMapper` 口径不变，演进注记已补） |
| 全静音兜底 | clipPeak 跌破门限按 1.0（旧满刻度行为，全基线不崩） |

改动文件：`EditorWaveformView.swift`（+normHeadroom/clipPeakNorm/三路径归一）、`WaveformAmplitudeMapper.swift`（演进注记）。

## 一句话定位

AudioRecord 是一个 macOS 原生音频工具，核心价值是：

> **在 Mac 上稳定录制系统声音 / 指定 App 声音 / 麦克风 / 混录，并在录完后完成轻量编辑、导出和后续转文字。**

产品不应演化为复杂 DAW，而应保持“录制优先 + 轻编辑 + 后续 AI 增强”的清晰路径。

## 核心目标用户

| 用户 | 典型场景 | 核心诉求 |
|---|---|---|
| 知识工作者 | 录制 YouTube、网课、会议音频 | 稳定录下系统声音，便于复听和整理 |
| 远程工作者 | 录制 Zoom / 腾讯会议 / 飞书会议 | 会议后整理纪要，不遗漏信息 |
| 播客 / 自媒体 | 录制线上访谈、系统声音 + 麦克风 | 获得干净素材，录完轻编辑后发布 |
| 教育工作者 | 录制课程回放和讲解 | 系统声音 + 麦克风混录 |
| 音频处理用户 | 导入、编辑、转换音频 | 简单处理，不想打开专业 DAW |

## 差异化方向

| 能力 | 竞品常见情况 | AudioRecord 机会 |
|---|---|---|
| 系统音频录制 | 剪映 / WavePad 不支持，Audio Capture Pro 支持 | 做到稳定、低门槛、原生体验 |
| 进程级录制 | 大多数编辑器不支持 | 只录 Chrome / Zoom / 某个 App 声音 |
| 录制 + 轻编辑闭环 | 录制工具通常不编辑，编辑器通常不录系统音频 | 录完即裁剪、标准化、淡入淡出 |
| 本地隐私 | SaaS 转写 / 会议工具通常上传音频 | 纯本地录制，后续本地转写 |
| macOS 原生 | 跨平台工具体验不够原生 | AppKit + 系统权限 + 原生快捷键 |

## 版本路线

| 版本 | 定位 | 核心能力 | 当前关注 |
|---|---|---|---|
| V1.0 | 极致录制 + 基础导出 | 系统音频、进程音频、麦克风、混录、文件管理、基础导出 | 核心路径稳定、权限和异常处理 |
| V1.1 | 轻编辑 | 裁剪、静音裁剪、标准化、淡入淡出、撤销重做 | 编辑器与录制态边界清晰 |
| V1.2 | 格式转换 + 导入导出 | 多格式互转、导入、批量转换、导出设置 | 统一“导出”和“转换格式”的语义 |
| V1.3 | 商业化 | 免费版限制、Pro 订阅、StoreKit 2、付费墙 | 订阅状态与功能限制一致 |
| V2.x | AI 增强 | 本地转写、AI 降噪、字幕导出、智能分段 | 在稳定录制和轻编辑基础上增强 |

## 当前产品判断

最重要的产品判断是：

> AudioRecord 是“录制工作区 + 编辑工作区”两个清晰工作流的工具，不是把所有音频功能堆在一个页面里的工具。

因此：

- 录制页保持克制，服务“稳定录下来”。
- 编辑页参考剪映时间线，但只保留音频必要元素。
- 后续差异化放在本地转写、AI 降噪、智能分段上。

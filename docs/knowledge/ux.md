# UX / UI 知识库

> 更新时间：2026-05-20  
> 来源：从 `../AudioRecordApp知识库.md` 的 UI 设计、交互设计、UI 重构任务拆分。  
> 范围：UI 原则、录制态、编辑态、交互规则、当前 UI 问题和后续重构方向。

## UI 设计原则

1. **录制优先**：首次打开和空闲态的核心任务是“开始录制”，不是编辑。
2. **两态清晰**：录制态与编辑态必须视觉上明确区分，不在同一画面强行混合。
3. **音频优先**：参考剪映时间线结构，但不照搬视频预览区。
4. **轻编辑而非 DAW**：不做复杂多轨混音、效果链、插件系统。
5. **工业深色风格**：继续使用 `IndustrialDesignTokens`，深色面板、小圆角、功能性强调色。
6. **信息密度适中**：录制状态、目标、波形、电平、计时器清楚即可，避免卡片堆叠。

## 正确信息架构

```text
AudioRecord App
├─ 录制工作区 Recording Workspace
│  ├─ 左侧：录制来源 / 已录文件
│  ├─ 中央：实时波形 / 空状态 / 播放波形
│  ├─ 右侧：电平监控（可窄栏或内嵌）
│  └─ 底部：计时器 + 录制 / 播放控制
│
└─ 编辑工作区 Editing Workspace
   ├─ 左侧：已录文件列表（保持可见）
   ├─ 顶部：返回 / 文件名 / 撤销 / 重做 / 保存
   ├─ 中央：时间线轨道区
   │  └─ 单轨行 = 轨道头 + 音频片段波形
   ├─ 底部：编辑工具 + 预览控制
   └─ 状态栏：时长 / 采样率 / 声道 / 编辑步数
```

## 录制态规范

录制态不应该出现编辑轨道板，也不应该常驻裁剪、标准化、淡入淡出等编辑工具。

| 状态 | 显示 | 禁止 |
|---|---|---|
| Idle | 空波形 / 上次文件波形、录制按钮、音源选择 | 不显示编辑工具栏 |
| Preparing | 加载 / 权限 / 初始化提示，录制按钮 disabled | 不允许切音源、进编辑 |
| Recording | 实时波形、L/R 电平、计时器、停止按钮 | 不显示轨道板、不允许编辑 |
| Stopping | 保存中提示 | 不允许重复停止 |
| Error | 错误提示 + 重试 | 不保留半激活编辑工具 |

## 编辑态规范

编辑态参考剪映的“轨道头 + 片段同一行”结构，而不是独立左侧轨道板。

```text
┌────────────────────────────────────────────────────────────┐
│ ← 返回       Recording.wav                 ↩ ↪      保存   │
├────────────────────────────────────────────────────────────┤
│ Timeline Ruler: 0:00      0:30      1:00      1:30          │
├──────────────┬─────────────────────────────────────────────┤
│ Track Header │ Audio Clip / Waveform                       │
│ 系统声音      │ ▄▃▅▇▆▃▄▅▇▆▃▄▅▇▆▃▄▅▇▆▃▄                   │
│ [M] [S]      │       ║ selected range ║                    │
├──────────────┴─────────────────────────────────────────────┤
│ [裁剪] [静音裁剪] [标准化] [淡入淡出]       [▶ 预览] [■]    │
└────────────────────────────────────────────────────────────┘
```

关键规则：

- 轨道头是时间线轨道的一部分，不是独立卡片。
- 波形是音频片段，应该有边界、选中态、拖柄、播放游标。
- 编辑器保存、撤销、返回属于导航栏。
- 裁剪、标准化、淡入淡出属于工具栏。
- Mute / Solo 未接入真实数据流前隐藏或降级 disabled，避免伪功能。

### 缩放与滑动控件（P0 — 2026-05-25 新增）

编辑器必须提供**可见的缩放/滑动 UI 控件**，不能仅依赖隐藏手势：

```text
┌────────────────────────────────────────────────────────────┐
│ 波形区（可缩放/滚动/选区）                                  │
├────────────────────────────────────────────────────────────┤
│ ◀ ═══════╗████████╠═══════════════════════════════════ ▶   │  ← 横向滚动条
├────────────────────────────────────────────────────────────┤
│ [▶][■]                      [🔍−] ━━●━━━━━ [🔍+] [⊞ Fit] │  ← 底部工具栏
└────────────────────────────────────────────────────────────┘
```

| 控件 | 位置 | 功能 |
|------|------|------|
| 🔍+ / 🔍− 按钮 | 底部工具栏右侧 | 点击放大/缩小，长按连续缩放 |
| 缩放滑块 | 两按钮之间 | 拖动连续调整缩放级别（对数映射） |
| ⊞ Fit All 按钮 | 滑块右侧 | 一键回到全局概览 |
| 横向滚动条 | 波形区与工具栏之间 | 拖动定位，zoomLevel > 1 时显示 |

快捷键：Cmd+= 放大、Cmd+- 缩小、Cmd+0 适应全部。
手势：Cmd+滚轮缩放（已有）、触控板捏合缩放（新增）、横向滑动（已有）。

> 详细交互规格见：`../design/编辑器缩放控件-交互规格.md`

## 当前已知 UI 问题

| 问题 | 表现 | 处理方向 |
|---|---|---|
| 卡片式布局混乱 | 左侧文件列表、轨道板、波形、电平、控制面板都像独立卡片 | 建立统一工作区层级 |
| 录制态和编辑态混杂 | 录制中也显示类似编辑轨道的信息 | 录制态隐藏编辑语义 |
| 轨道与波形分离 | 轨道控制板在左，波形在右，像两个无关区域 | 改为轨道头 + 波形片段同一行 |
| 电平表孤立 | 右侧电平卡片像外挂组件 | 降级为监控栏 |
| 编辑工具作用对象不清 | 主界面工具栏与编辑器工具栏重复 | 编辑工具只在编辑器内出现 |

## 推荐重构任务

1. **重建两态工作区模型**：用明确的 `AppWorkspaceMode` 管理录制 / 播放 / 编辑状态。
2. **废弃主界面半功能 `EditToolbarView`**：主界面只提供编辑入口。
3. **编辑器改为剪映式时间线轨道**：轨道头与波形片段合并成一行。
4. **电平表降权与数据打通**：右侧作为监控栏，L/R 数据真实。
5. **统一文件操作按钮语义**：导出、转换格式、分享分别对应不同任务。

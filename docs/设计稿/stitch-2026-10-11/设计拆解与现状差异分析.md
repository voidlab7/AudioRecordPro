## 一、设计拆解（v2 · 五个区域）

```
┌──────────────────────────────────────────────────────────────┐
│ 🔴🟡🟢 AudioRecord Pro   [Selected Source: 企业微信 pill]  ⚙ Export │ ← 标题栏
├──────────┬──────────────────────────────────────────┬────────┤
│ RECORD|FILES│ ● Ready                                │ dB     │
│          │                                           │ METER  │
│ SYSTEM   │                                           │  0     │
│  AUDIO   │        ┌─────────┐                        │ -3     │
│ 系统声音卡 │        │ 波形图标  │                        │ -6     │
│          │        └─────────┘                        │ -12    │
│ APP AUDIO│        Ready to Record                     │  ...   │
│ Refresh  │   Press record or hit [Space] to start    │ -48    │
│ 8 个App行 │                                           │  L R   │
│ ✓企业微信 │       （细网格背景，无其他元素）              │ 绿黄条  │
│          │                                           │        │
│ MICROPHONE├──────────────────────────────────────────┤        │
│ Also Mic │ ● Ready to Record   00:00.00  🔴           │        │
└──────────┴──────────────────────────────────────────┴────────┘
```

- **A. 标题栏**：交通灯 + 「AudioRecord Pro」居左；**居中**「Selected Source: <app>」翠绿 Capsule 药丸；右侧 ⚙ Settings + 白底 Export。
- **B. 左侧边栏（≈260px）**：RECORD/FILES 分段（RECORD 绿点激活）；SYSTEM AUDIO 分区 + 系统声音卡片（含副标 "Default Output Master" + radio）；APP AUDIO 分区 + **Refresh**，App 行 = 彩色图标 + 名称 + radio；选中态 = 翠绿高亮条 + 对勾；底部 MICROPHONE 分区 + 「Also Record Mic / Mix into current track」开关。
- **C. 主画布**：深碳黑 + **细网格背景**；顶部**极简状态**：绿点 + 「Ready」一个词（v1 的 PID/Buffer/Engine 元信息已删）；居中发光波形图标卡片 + 「Ready to Record」+ **一行短副标题**「Press record or hit [Space] to start」（含 Space 键帽）。v1 的水印已删。
- **D. 底部控制栏（≈72px）**：左侧 = 绿点 + 「Ready to Record」（v1 的采样率/位宽小字已删）；**几何居中** = 大号等宽时间码 `00:00.00` + 红色大圆钮（红色光晕环）；右侧**空**（v1 的 Format 下拉已删）。
- **E. 右缘电平表（≈40px）**：dB METER 竖排刻度（0/-3/-6/-12/-24/-48）+ L/R 双通道绿黄渐变竖条。

**色彩**：深碳黑 #0F1115 / 翠绿 #10B981→#00F5A0（glow）/ 红 #FF3B30（光晕）/ 白 8% hairline / 白 35% 次级文本。暗黑毛玻璃质感。

## 三、与今晨简化口径的冲突（✅ 已裁决 2026-10-11 15:15）

| 冲突 | 今晨口径 | 设计 v2 | **老板裁决** |
|---|---|---|---|
| ① 画布副标题 | 删，只留标题 | 一行「Press record or hit [Space] to start」 | ✅ **按设计恢复**（空格键提示有价值） |
| ② 底部状态文字「Ready to Record」 | 删 | 有（左侧，带绿点） | ✅ **维持删除**，底部不要 |
| ③ Format 下拉 / 元信息 | 现状没有 | v2 已自行删除 | 无冲突 |

## 四、实现策略（建议，待签）

1. **不换框架**：规格 md 推荐的 SwiftUI 重写不采纳。现状 AppKit 交互全部能跑，视觉（毛玻璃 `NSVisualEffectView`、glow shadow、`CGContext` 网格）AppKit 全能做。重写 = 高风险零功能收益。
2. **改动面**（主窗口 6 文件）：`TitleBarView`（药丸+Settings）、`SidebarView`（Refresh/选中态/彩色图标）、`WaveformView`（网格+发光卡片+Ready 状态点+副标题）、`ControlPanelView`（三段式重构+大号时间码）、`LevelMeter`（渐变+L/R）、设计系统色板。
3. **单子**：开 **UI-003 主界面视觉重构（按 Stitch v2 设计稿）**，验收标准含冲突①②的裁决结果；预估 1-1.5 天。
4. 规格 md 中 ScreenCaptureKit 等**采集技术描述不采纳**——现状 CoreAudio ProcessTap 已跑通，不动。

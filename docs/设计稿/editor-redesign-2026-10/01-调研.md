## 1. 剪映专业版 / CapCut（桌面版）

### 1.1 整体布局示意

来源依据：QQ 阅读书籍节选《剪映专业版的界面》（列明七大区域）[来源1]、《认识剪映专业版的界面》（列明六大区域与时间线区三要素）[来源2]、CSDN 愚公系列教程 [来源3]。

官方/出版资料描述编辑页分为以下区域：**工具栏（顶部左侧，媒体/音频/文本/贴纸/特效/转场/滤镜/调节/素材包）、素材区（左上，随工具栏选项切换内容）、预览区（中央上方）、素材调整区（右侧，选中轨道后显示对应属性面板）、常用功能区（时间轴上方：分割/删除/标记/定格/倒放/镜像/旋转/撤销等）、时间轴（底部）、时间轴设置区（主轨磁吸/自动吸附/联动/缩放）** [来源1][来源2]。

### 1.2 轨道头信息结构

剪映专业版时间轴支持多轨道分层（视频/音频/文本/贴纸无限轨道）。**每个轨道左侧有"眼睛图标"（隐藏/显示）和"锁图标"（锁定/解锁）**；时间轴右上角有缩放滑块，支持彩色标记与吸附功能 [来源3]。除隐藏/锁定外，是否有其他轨道头控件（如音量、 solo），来源未逐一列明——**未能核实，仅一般性描述**：轨道头整体较窄，属性调节主要依赖右上的素材调整区而非轨道头本身。

### 1.3 工具栏分组方式

- **顶部工具栏**：按素材类型分组——媒体、音频、文本、贴纸、特效、转场、滤镜、调节、素材包，点选后驱动左上素材区内容切换 [来源1][来源2]。
- **时间轴上方"常用功能区"**：按操作频次分组——分割、删除、定格、倒放、镜像、旋转、裁剪，以及撤销按钮 [来源1][来源2]。
- **时间轴设置区**：时间轴行为类开关——主轨磁吸、自动吸附、联动、缩放 [来源1]。

即剪映采用「**素材供给类工具在顶部 + 剪辑动作类工具在时间轴旁 + 时间轴行为开关贴着时间轴**」的三层分组。

### 1.4 转写与波形的联动方式

剪映的转写以「智能字幕」形式存在：对音频/视频做语音识别后，在时间轴上生成一条**字幕文本轨道**，字幕块与音频在时间轴上对齐 [来源4：第三方实测文章提及智能字幕生成字幕轨道]。点击字幕块可定位并编辑文本。至于「点击句子高亮波形 / 按词级联动播放」这类逐句联动交互，公开资料未见描述——**未能核实，仅一般性描述**。

### 1.5 可借鉴 / 不借鉴及理由

- **借鉴**：①「选中轨道素材 → 右侧出现上下文属性面板」的模式，非常适合 Loocap 把降噪/音量等参数收进右侧检查器而非堆在工具栏；②「撤销按钮放在时间轴上方常用功能区」，剪辑高频操作贴近工作区；③时间轴缩放/吸附等「行为开关」贴着时间轴放置。
- **不借鉴**：①顶部九宫格素材工具栏是为短视频创作的素材供给设计，Loocap 是录音后期工具，不需要素材库切换；②多层轨道纵向堆叠的信息密度对录音场景过重。
- **对 Loocap 的启示**：把「裁剪/降噪/音量」做成右侧上下文面板（选中片段才出现），底部只留一排真正高频的动作按钮（分割、撤销、导出），工具栏从「供给型」改为「动作型」。

## 2. Descript（重点：转写 ↔ 音频联动）

### 2.1 整体布局示意

来源依据：Descript 官方 Help Center《The editor interface》——官方将编辑器划分为四大区域：**Script editor（撰写/编辑/审阅转写稿的地方，可像文档一样编辑并由此编辑音视频）、Scene editor（视觉预览区）、Timeline（传统波形视图，可修剪/分割/移动片段）、Sidebar（侧边栏：Project/Scene/Layer/Elements/Media/AI Tools/Underlord 等工具面板）** [来源1]。

Descript 官方研讨会逐区讲解：转写稿在**左侧**，场景编辑器（画面预览）在**中间**，项目/图层面板在**右侧**，时间轴在**底部** [来源3]。第三方完整指南佐证：导入音频后同时出现在两处——右侧主编辑区的转写文本 + 底部传统波形时间轴；大部分时间在转写文本里工作，需要精细控制时间时才去时间轴 [来源2]。

### 2.2 轨道头信息结构

Descript 官方帮助以「script / canvas / timeline / sidebar」描述编辑器，未提供类似 DAW 的「轨道头」逐控件文档。时间轴上的轨道按媒体图层组织（说话人音频轨、视频轨、字幕等）。**轨道头具体控件（音量/静音/锁定等）未能核实，仅一般性描述**：与剪映、Logic 不同，Descript 的管理重心在右侧 Sidebar（图层/媒体/AI 工具），时间轴轨道头相对轻量 [来源1][来源3]。

### 2.3 工具栏分组方式

- **右侧 Sidebar 按工作对象分组**：Project（文件与工程）、Scene（布局/背景/转场）、Layer（位置/尺寸/时长/效果）、Elements（形状/文本/GIF）、Media（素材浏览）、AI Tools（Studio Sound 降噪、删除填充词等自动化工具）、Underlord（AI 协作编辑）[来源1]。
- 常规剪辑动作（修剪、分割、移动）直接在 Timeline 上做 [来源1]。
- 顶部是否还有全局工具栏：官方页面未详述——**未能核实，仅一般性描述**。

### 2.4 转写与波形的联动方式（核心）

以下均有官方来源：

- **词级对齐**：导入或录制后自动生成转写，每个词与时间轴上的音视频区间对齐；**播放时当前正在说的词会实时高亮**（官方研讨会演示：「每当我说的那个词，它就被高亮」）[来源3]。
- **点击/选中文字即编辑音频**：选中一段文本按 Delete，对应音频即被删除；删除按词级精度进行，通常可精确到词附近 [来源2][来源3]。撤销与文本编辑器一致（Cmd+Z 即可恢复被删音频）[来源2]。
- **wordbar（词边界条）**：时间轴上波形上方有一条 wordbar，明确告诉用户「波形对应的是哪些词」，用于快速增删词间距；按住 Cmd/Control 拖动词边界可修正对齐不准的词；从 wordbar 拖动一个词可直接调整该词的时序 [来源2：官方 wordbar 帮助页]。
- **反向联动**：文本驱动音频，音频精修仍回到时间轴手动修剪 [来源1][来源2]。
- **双击转写中的错词只改显示文本，不影响音频** [来源2]。

### 2.5 可借鉴 / 不借鉴及理由

- **借鉴**：①「文本是第一编辑面，波形是精修面」的双层模型——Loocap 有转写，最值得整体移植；②播放时词级高亮 + 点击词定位，成本不高、收益极大；③「文本删除即音频删除 + Cmd+Z 语义化恢复」，比波形上找编辑点直观得多；④错词双击修正只改文本不改音频——要区分「修正文本」与「修改音频」两种操作语义。
- **不借鉴**：①wordbar 这类词边界微调 UI 复杂度高，Loocap 词级对齐精度未必达到 Descript 水平，先不做；②Scene/Layer 等视频向侧栏分组对纯音频录音工具过重。
- **对 Loocap 的启示**：Loocap 的编辑页可以考虑「转写区与波形区上下并列、共享同一播放头」：播放时转写逐词高亮；点击句子把播放头跳过去并高亮波形对应区间；选中文本删除 = 删除对应音频。这套联动应作为重设计的第一优先级。

## 3. Logic Pro（轨道头信息结构标杆）

### 3.1 整体布局示意

来源依据：Apple 官方帮助《Logic Pro 轨道头概述》与《Get started with Logic Pro track header controls》。官方明确：**轨道头（Track Header）位于 Tracks 区左侧**，每个轨道有名称与图标，右侧为横向排布的轨道区域（Regions/片段）[来源1][来源2]。顶部为主窗口控制/播放控制等（官方有 "Logic Pro interface overview" 章节，具体顶栏逐项**未能核实，仅一般性描述**）。

### 3.2 轨道头信息结构（信息最全的行业参照）

Apple 官方文档列明的轨道头控件 [来源1][来源2]：

- **默认控件**：所有轨道有「录音启用（R）」「静音（Mute）」「独奏（Solo）」按钮；音轨额外有「输入监视（Input Monitoring）」按钮。
- **可选控件**（通过「轨道头配置」弹窗增删）：轨道编号（**回放期间轨道编号会被一个小电平指示器替代**，显示输出电平）、颜色条（轨道头左边缘）、轨道图标、音量滑块/电平指示器、声相/发送旋钮、控制表面条、Groove 轨道指示、Track Alternatives 菜单、附加名称栏。
- **轨道头可横向拖宽/收窄**（拖动分割线），给 Tracks 区腾出空间。
- **联动语义**：轨道头上的音量/声相/静音/独奏与混音器中该轨道通道条控件**双向联动**——改轨道头滑块，混音器推子同步变化 [来源2]。

### 3.3 工具栏分组方式

Logic Pro 顶部为菜单栏与控制条（播放/录制/位置/模式等）。官方接口概览章节存在，但本次检索到的页面以轨道头为主，**控制条逐项分组未能核实，仅一般性描述**：Apple 风格是「全局走顶部控制条 + 轨道级操作进轨道头 + 片段级操作用右键/双击局部菜单」，三级分治。

### 3.4 转写与波形的联动方式

Logic Pro 无内建语音转写面板，此节不适用。

### 3.5 可借鉴 / 不借鉴及理由

- **借鉴**：①轨道头控件「默认最小集 + 可配置扩展」的思路；②**回放时轨道编号位替换为电平表**——一个位置两种信息，空间利用率极高；③轨道头与混音参数的联动语义（轨道头不是装饰，是混音快捷入口）；④轨道头宽度可拖拽调节。
- **不借鉴**：①R/输入监视等录制期控件对编辑页冗余；②图标+颜色条+双名称栏的信息量对两轨的 Loocap 过度。
- **对 Loocap 的启示**：Loocap 的「系统音 / 麦克风」两条轨的轨道头建议包含：轨道名+图标、静音/独奏、音量滑块、**回放时在固定位置显示实时电平**。深色工业风下用颜色条区分系统音/麦克风两轨非常自然（Logic 的颜色条机制）。

- [来源2] Apple 官方《Get started with Logic Pro track header controls》：https://support.apple.com/en-gu/guide/logicpro/lgcpe19a7a67/10.7/mac/11.0

## 4. Audacity（波形编辑布局）

### 4.1 整体布局示意

### 4.5 可借鉴 / 不借鉴及理由

- **借鉴**：①「选区数值可键盘精确输入」的 Selection Toolbar——Loocap 做选区裁剪时给出起/止/时长三个可编辑读数，专业感与精度立刻提升；②Edit Toolbar「缩放一排 + 修剪/静音/撤销/重做一排」的分组法，与 Loocap 的功能集（选区/裁剪/降噪/撤销）高度重合；③轨道控制面板与 dB 垂直刻度分离的经典波形区结构；④工具栏可停靠/浮动/重置。
- **不借鉴**：①十余条工具栏平铺的「专业软件全家桶」密度，与 Loocap 的极简录音定位冲突；②菜单栏依赖（macOS App 不宜把核心编辑动作藏在菜单里）；③视觉风格老旧，深色工业风不应参考其默认浅色主题。

### 7.5 可借鉴 / 不借鉴及理由

- **借鉴**：①**「替换/修剪/增强」三个动词式按钮**——把复杂音频处理收敛成普通人能懂的动词，Loocap 的功能集（裁剪/降噪/音量）与之几乎同构；②黄色修剪控制柄的「两个把手定范围」交互，选区裁剪最直白的形态；③**「保存为新录音 / 覆盖保存」的二选一**，是「编辑不可逆焦虑」的官方级解法；④「播放设置不改原文件」——增强等效果做成非破坏性回放开关。
- **不借鉴**：①纯单轨模型无法承载 Loocap 的系统音+麦克风双轨；②「编辑」独占整窗的模式让转写无处安放（Loocap 需要常驻转写面板）。
- **对 Loocap 的启示**：Loocap 的「增强/降噪」可以参考其非破坏性思路（效果开关挂在回放链上，导出时才渲染）；裁剪交互直接用「黄柄选区 + 保留内/删除内」双确认；导出旁常驻「另存为新录音」降低误操作恐惧。

## 9. 共性布局模式总结

1. **「文本 ↔ 时间轴」双面编辑是转写类产品的行业共识**。Descript、通义听悟、飞书妙记虽然形态不同（桌面 App / 网页），但都提供「点击文字 → 播放位置跳转」；Descript 更进一步把文本作为第一编辑面（删字即删音频）。只要产品有转写，「点句子定位」就是标配交互。
2. **上下结构（文本上 / 波形下）或左右结构（媒体左 / 文本右）二选一**：已有波形+转写的产品（Descript）用上下结构共享播放头；纯回听型产品（听悟/妙记）用左右结构。有真实波形的产品更适合上下结构——波形是天然的「播放区」。
3. **轨道头承担「轨道级状态」，右侧/浮层承担「片段级属性」**。Logic Pro 把静音/独奏/音量/声相放轨道头，剪映把选中素材的属性放右侧检查器；两者组合（轨道头放状态开关 + 右侧上下文面板放参数）是现代编辑页的标准分工。
4. **工具栏按「供给 / 动作 / 行为」三类分组，位置各有归属**：素材供给类在顶部（剪映）、剪辑动作类贴近时间轴（剪映常用功能区、Audacity Edit Toolbar 的修剪/静音/撤销排）、时间轴行为开关吸附在时间轴旁（剪映时间轴设置区）、数值读数放底部（Audacity Selection Toolbar）。几乎没有产品把动作按钮放在左右两侧。
5. **撤销/重做永远出现在高频动作区**：剪映放在时间轴上方常用功能区，Audacity 放在 Edit Toolbar 下排与顶部 Project toolbar，Descript 直接复用 Cmd+Z 文本语义。撤销是唯一在三类专业软件中都「贴着工作区放」的功能。
6. **播放时的实时指示是不可省略的反馈**：Logic 回放时轨道编号变电平表、Descript 逐词高亮、听悟/妙记转写跟随滚动。编辑页的每个「固定信息位」都应考虑回放时临时让位给动态信息。
7. **极简与专业可以通过「情境化」调和**：语音备忘录无常驻工具栏，全部功能以动词按钮在编辑窗口情境出现，并靠「另存为新录音」消除破坏性焦虑。功能集相似的产品（Loocap 与之功能高度同构）适合「默认极简、选中即出上下文工具」的策略。

## 10. 对 Loocap 编辑页的整体建议（汇总）

结合 Loocap 现状（深色工业风、系统音+麦克风双轨、有转写、选区/裁剪/降噪/音量/撤销重做/导出）：

1. **布局骨架**：上下结构——上部为转写面板（可折叠），下部为双轨波形区；左侧窄轨道头（Logic 式：轨名+图标、M/S、音量、回放电平），右侧上下文检查器（剪映式：选中片段才出现降噪/音量参数）。
2. **转写联动**（第一优先级，参考 Descript/听悟/妙记）：点击句子 → 播放头跳转 + 波形区间高亮；播放时逐词/逐句高亮；顶部搜索框支持关键词高亮定位；导出支持 SRT（含时间戳与轨来源）。
3. **动作栏**：贴近时间轴放一排高频动作（分割/裁剪/降噪/撤销/重做/导出，Audacity 式分组），底部放选区读数（起/止/时长可键入，Audacity 式）。
4. **安全感**：导出旁常驻「另存为新录音」语义；降噪/增强优先做成非破坏性回放开关（语音备忘录式），导出时渲染。
5. **双轨特性**：用颜色条区分系统音/麦克风（Logic 式），转写按轨来源标注「发言人」；系统音轨与麦克风轨可独立静音/独奏。

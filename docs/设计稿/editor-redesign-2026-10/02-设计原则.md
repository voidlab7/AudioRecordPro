# 02 · 设计原则（一页）

> UI-018 编辑页整体重设计 · 2026-10-16 · 依据 `01-调研.md`（7 款产品）与 `00-现状功能清单.md`（89 项功能）
> 沿用工程深色工业风与 `IndustrialDesignTokens` 现有 token 为底；改动处均给理由。

---

## 1. 布局骨架（上下三段式，两方向共用，仅比例不同）

```
┌──────────────────────────────────────────────────┐
│ 顶栏 44px：返回 ‖ 撤销/重做 ‖ 文件名+时长 ‖ 保存     │
├──────────────────────────────────────────────────┤
│ 时间尺 22px（刻度 + 播放头倒三角）                  │
├──────────────────────────────────────────────────┤
│ 波形轨道区（轨道头 88px 列 + 波形）   ← A 紧凑/B 主导 │
│                  ⇅ 可拖拽分隔条（转写面板高度可调）  │
├──────────────────────────────────────────────────┤
│ 转写分栏（波形下方）                  ← A 主导/B 紧凑 │
├──────────────────────────────────────────────────┤
│ 动作栏 44px：播放控制 ‖ 高频动作 ‖ 选区读数 ‖ 缩放   │
├──────────────────────────────────────────────────┤
│ 状态栏 24px：当前时间 · 总时长 · 采样率/声道 · 消息  │
└──────────────────────────────────────────────────┘
默认 1200×750；最小 960×640（转写分栏可折叠至 0）
```

- **转写常驻在波形下方分栏**（老板已拍板），替代现状「180pt 抽屉」——抽屉展开时把波形推出视口，联动无从谈起；分栏共享同一时间轴与播放头，波形↔文字天然对齐。
- **A/B 唯一骨架差异是比例**：A 波形 30% / 转写 55%（文本是第一编辑面，Descript 式）；B 波形 58% / 转写 24%（轨道是第一编辑面，剪映式）。分隔条均可拖。

## 2. 轨道头（Logic 式最小完备集，宽 80→88px）

固定信息：**颜色条（4px，轨色）+ 轨道名 + 图标**；状态开关 **M / S**（现状保留，语义不变）；
新增两件（均来自调研共识）：**音量滑块（迷你，轨道级）**；**回放时编号位变实时电平表**（Logic 官方机制，一个位置两种信息）。可配置扩展留实现单。

## 3. 工具栏分组（供给/动作/行为三分，各归其位）

| 组 | 位置 | 内容 | 来源依据 |
|---|---|---|---|
| 走带 | 动作栏左侧 | ▶/⏸ ■、当前时间 | Audacity Transport |
| 高频动作 | 动作栏中部 | 切分 · 裁剪 · 静音裁剪 · 标准化 · 淡入淡出 ‖ 撤销/重做贴工作区 | 剪映常用功能区 + Audacity Edit Toolbar 下排 |
| 选区读数 | 动作栏右侧 | 起点 / 终点 / 时长（**可键入**） | Audacity Selection Toolbar |
| 视图行为 | 动作栏最右 | 缩放 −/滑块/+/Fit All | 现状 ZoomControls 保留 |

原则：**动作贴近工作区，参数进上下文**——选中 Clip/文字后动作按钮才点亮，批量参数（LUFS 预设、语言）走浮层，不再平铺。

## 4. 色彩分工（终止「一橙到底」）

| 语义 | 色 | Token |
|---|---|---|
| 系统音轨波形 | 青绿 | `primary #13BBA3` |
| 麦克风轨波形 | 珊瑚橙 | `waveformCoral #E87850`（现状签名色，保留给"人声"） |
| 播放头 | 红 | `waveformAccent #E85050`（不变） |
| 选区 | 绿拖柄 + 白 8% 底 | `primary` + `white@8%`（现状遮罩改亮一档，选中感更强） |
| 转写当前句/联动高亮 | 青绿描边+10% 底 | `primary`（与系统音轨呼应=「正在播的来源」） |
| 转写进行中 | 紫进度 | `#B387FF`（现状代码写死色收编进 token） |
| 背景/文字/分割线 | 不变 | `#0F1115 / #161B22 / #1D232C`；`#EDEFF2 / #A0A0A5 / #6B6B70`；`white@8%` |

理由：轨道色=来源色，全程唯一映射（波形、转写来源标、轨道头颜色条三处一致）；绿色从「只当强调色」升格为「系统音语义色」，珊瑚橙专职麦克风——两方向通用。

## 5. 字号 / 间距体系（沿用 + 收编）

- 字：标题 18 Bold / 区块题 12 Semibold / 正文 13 / 标签 11 / 时间尺与读数 9–10pt **等宽**；不新增字号档。
- 距：4/8/12/16/24 五档不变；分栏内边距统一 16；圆角 6/10/14 不变。
- 动效：120ms 标准 / 200ms 分栏展开（现状 token）。

## 6. 转写联动铁律（两方向共同承诺，调研最高共识）

1. 点击句子 → 播放头跳转 + 波形对应区间高亮（Descript/听悟/妙记三源一致）；
2. 播放时当前句逐词高亮、面板自动跟随滚动；
3. 句前缀时间戳等宽字体可点击复制；来源标（系统音/麦克风）用轨色小圆点；
4. 搜索框：关键词高亮 → 逐个跳转（妙记三段式）；
5. 导出 txt/md 保留，新增 SRT（含时间戳+来源轨）列为建议项。

## 7. 安全感（语音备忘录式）

保存仍写回原文件（`.arlock` 语义不变）；「另存为新录音」列为建议项；降噪/标准化建议改**非破坏性开关**（回放链实时试听，导出才渲染）——本设计稿只画 UI 位，语义进实现单再定。

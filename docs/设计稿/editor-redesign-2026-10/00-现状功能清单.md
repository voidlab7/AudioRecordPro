# UI-018 编辑页重设计 — 现状功能清单

> 盘点范围：`AudioRecordApp/Sources/Views/Editor/` 全部 11 个视图文件 + `AudioRecordApp/Sources/Editor/EditorViewController.swift` + 嵌入模式相关 `AudioRecordApp/Sources/Views/EditToolbarView.swift`。
> 说明：本文档只陈述源码中真实存在的功能与常量，不做推测；不存在的功能在 §2 中显式标注「不存在」。
> 视觉 token 统一定义在 `AudioRecordApp/Sources/Utilities/IndustrialDesignTokens.swift`（IndustrialColors / IndustrialTypography / IndustrialSpacing / IndustrialCornerRadius）。
> 注意：工程中**不存在** `EditorWindowController`（全仓 Grep 无匹配），编辑器由 `EditorViewController` 直接以 NSView 形态嵌入（独立模式）或嵌入 `MainWindowView`（embedded 模式）。

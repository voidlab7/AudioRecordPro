## 2. 方向差异表（实现单拆分边界）

| 维度 | A 文本主导 | B 轨道主导 |
|---|---|---|
| 波形区/转写比例 | 30% / 55% | 58% / 24%（186px 固定起步） |
| 转写形态 | 文档流单列大字，句子=第一等公民 | 双列紧凑句卡，3 行截断，点开可全文 |
| 轨道头内容 | 颜色条+名+图标+M/S+迷你电平 | 颜色条+名+图标+**音量滑块**+M/S+回放电平 |
| 选中反馈 | 文本选中（青绿 16% 底+描边）+波形选区 | Clip 亮框（teal 1.5px 圆角 8）+**上方上下文工具条**（裁剪/切分/静音裁剪/标准化/淡入淡出/删除） |
| Trim 专属拖柄 | 不画（保持现状语义：选区柄即裁剪） | 红色 4px 柄画在选区框两外侧（裁剪语义外扩） |
| 高频动作位置 | 常驻动作栏中部 | 常驻 + 选中浮层双入口（同功能同命令） |
| 推荐度 | ★★★☆☆ | ★★★★☆（与现状连续性最好） |
| 建议拆单 | UI-019（分栏骨架+拖拽分隔+折叠）、UI-020（转写联动：点句/逐词/搜索）、UI-021（文档流转写样式） | UI-019（分栏骨架）、UI-020（转写联动）、UI-022（上下文工具条+Clip 亮框+Trim 柄接线）、UI-023（轨道头音量/电平） |

## 3. 两者共同的「新增交互承诺」（实现单验收对照）

1. 转写点句 → 播放头跳转 + 波形区间青绿 10% 高亮（`segLink` 位置 = 句时间戳区间）；
2. 播放时当前句自动滚动 + 逐词青绿高亮；
3. 选区读数三框可键入（Enter 生效，非法值红框）；
4. 转写分栏拖拽调高（范围 34px～60% 窗高）、双击把手折叠；
5. 播放时轨道头编号位变电平表（A：迷你条；B：双色电平条）；
6. 搜索关键词 → 句内黄高亮（`#FFD600` @30% 底）→ 上下句跳转按钮。

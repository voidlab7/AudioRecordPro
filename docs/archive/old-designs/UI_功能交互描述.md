## 一、整体窗口布局

窗口采用 **macOS 深色工业风格**设计，尺寸 1200×750px（最小 900×600），透明标题栏 + 全沉浸式内容区，左右分栏：

```
┌─────────────────────────────────────────────────────────────┐
│  [🔴🟡🟢]  透明标题栏（38px 安全区）                          │
├──────────────┬──────────────────────────────────────────────┤
│              │                                              │
│  侧边栏       │     波形显示区 (WaveformView, 42%高度)        │
│  (200-400px)  │       ┌──────┐                              │
│              │       │电平表│ (右上角叠加)                    │
│              │       └──────┘                              │
│              ├──────────────────────────────────────────────┤
│              │                                              │
│              │     音轨监控区 (TracksView, 弹性高度)           │
│              │                                              │
│              ├──────────────────────────────────────────────┤
│              │     传输控制面板 (ControlPanelView, 90px)      │
│              ├──────────────────────────────────────────────┤
│              │     底部状态栏 (StatusBarView, 32px)           │
└──────────────┴──────────────────────────────────────────────┘
```

### 窗口配置

| 属性 | 值 |
|------|-----|
| 默认尺寸 | 1200 × 750 px |
| 最小尺寸 | 900 × 600 px |
| 标题栏 | 透明 + 标题隐藏（fullSizeContentView） |
| 外观 | 强制暗色模式（NSAppearance.darkAqua） |
| 支持 | 全屏、缩放、分栏拖动 |

## 二、左侧侧边栏（SidebarView）

侧边栏宽度 200~400px，可通过 SplitView 拖拽调整，用 Tab 页切分为两个功能区。

### Tab 1: Audio Recorder（录制目标选择）

```
┌─────────────────────────┐
│  [Audio Recorder] [Saved Files]  ← Tab 栏 (44px)
├─────────────────────────┤
│  "录制目标"（标题）       │
│  "选择要录制的音频源"     │
├─────────────────────────┤
│  ┌─────────────────────┐│
│  │ 🔊 全部系统声音      ││ ← 固定选项行
│  │    All System Audio  ││
│  └─────────────────────┘│
├─────────────────────────┤
│  "选择应用声音"   [🔄]   │ ← 刷新按钮
├─────────────────────────┤
│  ┌─────────────────────┐│
│  │ 📱 Chrome     (PID) ││ ← 进程列表（滚动）
│  │ 📱 Spotify    (PID) ││
│  │ 📱 Discord    (PID) ││
│  │ ...                  ││
│  └─────────────────────┘│
├─────────────────────────┤
│  ┌─────────────────────┐│
│  │ 🎤 麦克风叠加        ││ ← 底部麦克风面板 (92px)
│  │     [Toggle 开关]    ││
│  └─────────────────────┘│
└─────────────────────────┘
```

#### 功能说明

| 区域 | 功能 | 交互方式 |
|------|------|---------|
| "全部系统声音" 固定行 | 选择录制全系统混音 | 单击选中（与进程列表互斥） |
| 🔄 刷新按钮 | 重新获取可用音频进程列表 | 单击触发 |
| 进程列表 | 显示所有正在输出音频的应用 | 单击某行选中该进程作为录制源 |
| 麦克风面板 | 控制是否将麦克风音频混入录制 | Toggle 开关切换 |

#### 视觉交互反馈

- **选中行**：左侧出现 3px 青色竖条指示
- **Hover 效果**：背景色变亮 + 边框变色
- **按下效果**：整行微下移 1px
- **进程行信息**：应用图标 + 应用名（大写）+ PID 编号

## 三、右侧主内容区

### 3.1 波形显示区（WaveformView）

**位置**：右侧面板顶部，占 42% 高度（最小 200px）

```
┌────────────────────────────────────────────────────┐
│  时间轴: 00:00    00:15    00:30    00:45    01:00 │
│  ─────────────────────────────────────────────────  │
│                                                    │
│  ▕▎▎▌▍▎▍▌▎▎▍▌▍▎▌▍▎▎▎▍▌▎▌▍   (波形图形)          │
│  ────────────────|─────────── (中线)               │
│  ▕▎▎▌▍▎▍▌▎▎▍▌▍▎▌▍▎▎▎▍▌▎▌▍   (镜像波形)          │
│                  ▲                                 │
│              播放游标                    ┌────────┐ │
│                                        │ L ████ │ │
│                                        │ R ███  │ │
│                                        └────────┘ │
└────────────────────────────────────────────────────┘
```

#### 两种工作模式

| 模式 | 触发条件 | 显示内容 | 用户交互 |
|------|---------|---------|---------|
| **实时录制模式** | 正在录制时 | 从左向右动态填充的细条波形，播放头在 54% 位置显示红色竖线 | 无交互（只读） |
| **静态波形模式** | 选中已录制文件 | 完整波形图，已播部分高亮，未播部分暗淡 | 鼠标点击/拖拽 → Seek 到指定时间 |

#### 视觉元素

| 元素 | 说明 |
|------|------|
| 时间轴标签 | 底部 5 个等分时间标签 |
| 中线 | 水平参考线 |
| 刻度线 | 8 条垂直参考线 |
| 波形颜色 | 珊瑚红渐变（#FF6B6B ~ #FF8E53） |
| 播放游标 | 红色竖线 + 顶部/底部圆形标记 |
| 背景 | 深灰 `#141c20`，4px 圆角，1px 细边框 |
| 内边距 | 左右各 84px |


| 元素 | 功能 |
|------|------|
| 左通道（L）电平条 | 实时显示左声道音量级别 |
| 右通道（R）电平条 | 实时显示右声道音量级别 |

## 四、核心功能流程

### 4.1 录制流程

```
1. 选择录制目标
   ├── 方式A: 点击「全部系统声音」→ 录制所有系统音频混音
   └── 方式B: 点击某个应用进程 → 仅录制该应用音频
2. [可选] 开启麦克风 Toggle → 将麦克风音频混入
3. 点击 ⏺ 录制按钮
4. 录制进行中：
   ├── 波形区：实时显示音频波形（从左向右填充）
   ├── 电平表：实时显示左右声道音量
   ├── 状态栏：显示 "Recording..."
   └── 计时器：开始计数 00:00:00 → ...
5. 点击 ⏹ 停止按钮
6. 文件自动保存 → 出现在 Saved Files 列表中
```

### 4.2 播放流程

```
1. 切换到 Saved Files Tab
2. 点击选中一个录音文件
3. 波形区加载该文件的完整静态波形
4. 点击 ▶ 播放按钮
5. 播放进行中：
   ├── 波形区：显示播放进度（已播段高亮，未播段暗淡）
   ├── 电平表：显示播放音量
   ├── 可鼠标点击/拖拽波形 → Seek 跳转到指定位置
   ├── 可点击 ⏸ 暂停
   └── 计时器显示当前播放位置
6. 播放结束 → 自动停止
```

### 4.3 导出流程

```
1. 在 Saved Files 中选中目标文件
2. 点击「导出 MP3」按钮
3. 弹出 NSSavePanel → 用户选择保存位置和文件名
4. 后台调用 /usr/bin/afconvert 进行 WAV → MP3 转码
5. 转码完成 → 通知用户
```

## 六、技术实现要点

| 项目 | 技术方案 |
|------|---------|
| 布局方式 | 纯代码 Auto Layout（无 Storyboard/XIB） |
| 窗口模式 | fullSizeContentView + 透明标题栏 |
| 分栏 | NSSplitView（垂直分割，可拖动） |
| 列表 | NSScrollView + NSStackView |
| 波形绘制 | 自定义 NSView + Core Graphics draw |
| 电平表 | 自定义 NSView + CADisplayLink 级刷新 |
| 音频捕获 | CoreAudio Process Tap（macOS 14.4+） |
| 文件转码 | /usr/bin/afconvert CLI 工具 |
| 权限 | 麦克风权限 + 系统音频捕获权限 |

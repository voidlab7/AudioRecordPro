## 产品定位（一句话）

> **Mac 上录制任何声音，一键转文字。**

核心价值链：

```
[获取层]          [转换层]        [处理层]
系统音频录制  →   转文字     →   用户自行 AI 处理
  ↑                ↑               ↑
 我们做           我们做          用户自己做
（核心壁垒）    （差异化）      （不做，成本太高）
```

### V2.x CDN 成本覆盖分析

#### CDN 成本（Cloudflare R2）

| 项目 | 成本 | 说明 |
|------|------|------|
| 存储 | ~$0.02/月 | 1.5GB 模型文件 × $0.015/GB |
| **出站流量** | **$0** | Cloudflare R2 出站免费！ |
| 总 CDN 成本 | **≈ $0.02/月** | 几乎为零 |

> ⚠️ 即使用传统 CDN（腾讯云/阿里云），成本也可控：
> - 1000 用户下载 1.5GB 模型 = 1.5TB 流量 × ¥0.5/GB = **¥750 一次性**
> - 但用户只下载一次模型，不是每月下载

#### 收入 vs 成本（V2.x）

假设用 **Cloudflare R2**（推荐方案）：

| 付费用户数 | 月收入（Apple 抽成后 70%） | CDN 月成本 | 净利润 | 覆盖倍数 |
|-----------|--------------------------|-----------|--------|----------|
| **1 人** | $7（月费）或 $2.9（年费均摊） | $0.02 | $6.98 | **350x** |
| **10 人** | $70 | $0.02 | $69.98 | **3500x** |
| **100 人** | $700 | $0.02 | $699.98 | **35000x** |
| **1000 人** | $7000 | $0.02 | $6999.98 | **350000x** |

**结论：1 个付费用户就能覆盖 CDN 成本 350 倍。CDN 成本完全不是问题。**

#### 即使用最贵的方案（传统 CDN）

| 场景 | 流量成本 | 需要多少用户覆盖 |
|------|----------|-----------------|
| 100 用户首次下载模型 | ¥75（一次性） | 1 个月费用户即可覆盖 |
| 1000 用户首次下载模型 | ¥750（一次性） | 2 个月费用户即可覆盖 |
| 10000 用户首次下载模型 | ¥7500（一次性） | 15 个月费用户即可覆盖 |

**关键点**：模型下载是**一次性**的，用户下载后本地永久保存，不会每月重复下载。所以 CDN 成本是一次性支出，而订阅收入是持续的。

#### 推荐的模型分发策略

```
┌─────────────────────────────────────────────────────────────┐
│  V2.x 模型分发策略（成本最优）                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  阶段 1（0-100 用户）:                                       │
│  └─ Hugging Face 直接下载（完全免费）                        │
│     + 国内镜像 hf-mirror.com（免费）                         │
│     成本: $0                                                │
│                                                             │
│  阶段 2（100-1000 用户）:                                    │
│  └─ 加入 Cloudflare R2 作为备用加速                          │
│     成本: ~$0.02/月（存储）+ $0 出站                         │
│                                                             │
│  阶段 3（1000+ 用户）:                                       │
│  └─ Cloudflare R2 为主 + Hugging Face 备用                   │
│     成本: ~$0.02/月                                         │
│     此时月收入已 > $7000，CDN 成本可忽略                     │
│                                                             │
│  结论: CDN 成本永远不会成为瓶颈                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## V1.x 版本路线图

### V1.0 — 极致录制 + 基础导出（2-4 周）

**目标**：核心录制功能稳定可用，可发布 Beta

| # | 功能 | 说明 | 状态 |
|---|------|------|------|
| 1 | 系统音频录制 | 全部系统声音 | 已有，需打磨 |
| 2 | 进程级录制 | 指定 App 声音 | 已有，需打磨 |
| 3 | 麦克风录制 | 麦克风输入 | 已有 |
| 4 | 混录 | 系统/进程 + 麦克风 | 已有 |
| 5 | 基础导出 | M4A / WAV 格式导出 | 需完善 |
| 6 | 文件管理 | 录音列表、Finder 打开、播放 | 需完善 |
| 7 | 权限引导 | 麦克风/屏幕录制权限引导 | 需新增 |
| 8 | 现代 UI | 重新设计的界面 | 需重构 |

**交付标准**：
- 录制稳定，无崩溃
- 三条核心路径（系统音频/进程音频/混录）回归通过
- 可在 App Store 提交

---

### V1.1 — 轻编辑（2 周）

**目标**：录完即可用，不需要打开其他编辑器

| # | 功能 | 说明 | 实现难度 |
|---|------|------|----------|
| 1 | 裁剪首尾 | 拖动选区删除首尾无用部分 | 低 |
| 2 | 静音裁剪 | 自动检测并删除超过 N 秒的静音段 | 中 |
| 3 | 音量标准化 | 一键调整到 -16 LUFS 标准响度 | 低 |
| 4 | 淡入淡出 | 首尾 0.5-3 秒渐变 | 低 |

**不做的编辑功能**：
- ❌ 多轨混音
- ❌ 音频特效（回声/混响等）
- ❌ 变声/换音色
- ❌ 精确波形编辑
- ❌ 实时效果预览

**交付标准**：
- 裁剪操作流畅，支持撤销
- 静音检测阈值可调

---

### V1.2 — 格式转换 + 音频导入导出（1-2 周）

**目标**：不仅能录制后导出，还能导入外部音频进行格式转换

| # | 功能 | 说明 | 实现难度 |
|---|------|------|----------|
| 1 | 格式转换 | M4A / WAV / MP3 / FLAC / OGG 互转 | 低 |
| 2 | 音频导入 | 拖拽或选择文件导入 | 低 |
| 3 | 批量转换 | 多个文件一次性转换格式 | 中 |
| 4 | 导出设置 | 比特率、采样率可选 | 低 |

**使用场景**：
- 录制后转换为 MP3 分享
- 导入一个 WAV 文件，导出为 M4A 压缩
- 批量将多个录音转为统一格式

**交付标准**：
- 支持主流音频格式互转
- 转换速度快（利用 AVFoundation / FFmpeg）
- 导出文件质量无损或可控

## V2.x 版本路线图（涉及模型）

### V2.0 — 语音转文字（2-3 周）

**目标**：录制→转文字一条龙，核心差异化功能

| # | 功能 | 说明 | 技术方案 |
|---|------|------|----------|
| 1 | 本地转写引擎 | Whisper.cpp 集成 | whisper.cpp + CoreML |
| 2 | 一键转文字 | 录完后一键触发 | 按钮触发，显示进度 |
| 3 | 文字结果展示 | 带时间戳的文字 | 内置文本视图 |
| 4 | 复制全文 | 一键复制到剪贴板 | 系统剪贴板 |
| 5 | 导出 TXT / SRT / Markdown | 多格式文字导出 | 文件写入 |
| 6 | 多语言支持 | 中/英/中英混合 | Whisper 多语言模型 |
| 7 | 模型管理 | 首次下载模型 ~1GB | Hugging Face + CDN 备用 |

**杀手级场景**：
- YouTube 视频 → 录制 → 转文字 → 复制走
- Zoom 会议 → 录制 → 转文字 → 会议纪要
- 网课回放 → 录制 → 转文字 → 学习笔记

---

### V2.1 — AI 降噪（1-2 周）

**目标**：录制质量提升

| # | 功能 | 说明 | 技术方案 |
|---|------|------|----------|
| 1 | 后处理降噪 | 录完后一键降噪 | RNNoise / DeepFilterNet |
| 2 | 降噪强度 | 可调节降噪级别 | 轻/中/强 三档 |
| 3 | 实时降噪 | 录制时实时去噪（可选） | 本地模型实时处理 |

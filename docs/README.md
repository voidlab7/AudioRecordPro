## 文档使用规则

1. 讨论产品、UI、交互、技术方案时，先读 `知识库/README.md`。
2. 讨论具体需求编号和排期时，读 `需求/README.md`。
3. 讨论 UI 落地细节时，再读 `设计/`。
4. 讨论底层技术细节时，再读 `架构/`。
5. 若文档与代码冲突，以实际代码为准，并同步更新 `知识库/` 对应文件。
6. 后续不要继续新增多个互相冲突的 UI 草案；优先更新 `设计/设计规范.md` 和 `设计/`。

## 写作规则（Tab 工作铁律）

1. **不轻信 UI**：功能结论必须有落盘硬验证（文件存在、编码、时长、RMS），文档里写「已验证」必须附证据路径。
2. **根因闭环**：缺陷记录 = 日志证据 + 代码行号 + 修复方案 + 回归用例，缺一不归档。
3. **沙盒意识**：运行时产物都在 `~/Library/Containers/com.voidzhang.audio-record-mac/` 下。
4. **日志是第一现场**：`沙盒 Data/Documents/AudioRecordings/Logs/audiorecord_<日期>.log`。
5. **一处事实一处文档**：同一事实只在一个文档维护，其他地方引用链接，禁止复制粘贴出分叉。

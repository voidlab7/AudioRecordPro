## 用户故事

### 系统音频录制

> **作为**一个知识工作者，**我想要**录制 YouTube 上的英语教学视频音频，**以便**后续反复收听学习，不需要每次都打开浏览器。

> **作为**一个远程工作者，**我想要**录制 Zoom 会议的全部音频，**以便**会后整理会议纪要，不遗漏重要信息。

### 进程级录制

> **作为**一个播客制作者，**我想要**只录制 Chrome 中播放的访谈音频（不录制其他 App 的通知声），**以便**获得干净的素材用于后期制作。

### 混录模式

> **作为**一个在线教育讲师，**我想要**同时录制学生分享的屏幕音频和我的麦克风讲解，**以便**制作完整的课程回放。

### 轻编辑

> **作为**一个播客主播，**我想要**录制完成后快速裁掉开头的寒暄和结尾的闲聊，**以便**直接导出发布，不需要打开 Logic Pro。

### 格式转换

> **作为**一个音频工作者，**我想要**把客户发来的 WAV 文件批量转为 MP3，**以便**通过邮件发送（WAV 太大无法附件）。

| 格式 | 1 分钟 | 10 分钟 | 30 分钟 | 1 小时 | 4 小时 |
|------|--------|---------|---------|--------|--------|
| **M4A** (AAC 128kbps) | ~1 MB | ~10 MB | ~29 MB | ~58 MB | ~230 MB |

### 1. 录制引擎

#### 1.1 系统音频录制
- 技术方案：CoreAudio Process Tap（macOS 14.4+）— 捕获系统全局音频输出
- 规格：48kHz / 立体声 / 16-bit PCM 或 AAC
- 延迟：< 100ms 启动延迟
- 稳定性：连续录制 4 小时无崩溃
- 不影响用户正常听音，支持热插拔外接音频设备
- 权限：仅需系统音频权限（非屏幕录制权限），用户感知更轻量

#### 1.2 进程级录制
- 技术方案：CoreAudio Process Tap（macOS 14.4+）— 指定进程音频捕获
- 进程列表实时刷新（2 秒轮询），显示名称 + 图标
- 单选模式，无音频输出时灰显
- 进程退出自动停止录制，保存已录内容

#### 1.3 麦克风录制
- 技术方案：AVAudioEngine
- 使用系统默认输入设备
- 支持外接 USB 麦克风 / 蓝牙耳机麦克风

#### 1.4 混录模式
- 系统/进程音频 + 麦克风混合为单文件
- 麦克风作为附加输入开关
- **默认音量比例**：系统音频 100% + 麦克风 100%（等比混合）
- **V1.0 不支持独立音量调节**（V1.1 考虑加入混录音量滑块）
- 混录输出为立体声：系统音频保持原始声道，麦克风混入双声道

### 2. 录制控制

**状态机**：IDLE → PREPARING → RECORDING → STOPPING → IDLE（+ ERROR / PLAYING）

**按钮交互**：
- IDLE：红色圆形，点击开始录制
- PREPARING：红色 + 旋转动画，不可点击
- RECORDING：红色方形 + 脉冲动画，点击停止
- STOPPING：灰色 + 旋转动画，不可点击
- ERROR：红色警告，点击重试

**实时信息**：时长(1s) / 文件大小(2s) / 电平(60fps) / 波形(60fps)

---

### 3. 基础导出
- 默认 M4A（AAC 128kbps），可选 WAV（PCM 16-bit）
- 文件命名：[录制模式]_[日期]_[时间].[格式]
- 导出流程：录制完成 → 自动保存 → 可另存为到指定位置

---

### 4. 文件管理
- 列表：按时间倒序，显示文件名/时长/大小/日期
- 操作：播放/重命名/删除/在 Finder 显示/导出/分享
- 播放：进度条可拖动 + 波形预览 + 位置指示器
- 存储位置：~/Documents/AudioRecordings/

### 5. 权限引导
- 麦克风权限 + 系统音频权限
- 首次启动 2 步引导（麦克风 → 系统音频）
- 状态栏实时显示权限状态（绿/红/灰）
- 权限被拒：功能灰显 + 提示跳转设置
- 不需要欢迎页（工具型 App，用户下载即知用途，直接进入权限引导）

### 8. 边界条件与异常处理

| 异常场景 | 处理方案 |
|----------|----------|
| **磁盘空间不足**（< 100MB） | 录制前检测，弹窗警告"磁盘空间不足，可能无法完成录制"；录制中空间耗尽 → 立即停止，保存已录内容 |
| **App 被强杀 / 系统崩溃** | 使用临时文件写入，App 重启后检测未完成的临时文件 → 提示"发现未保存的录音，是否恢复？" |
| **录制文件损坏** | 导出时校验文件完整性；损坏文件在列表中标记⚠️，提示"文件可能已损坏" |
| **权限中途被撤销** | 立即停止录制 → 保存已录内容 → 弹窗"录制权限已被撤销，已保存 XX:XX 的录音" |
| **外接音频设备断开** | 录制中设备断开 → 自动切换到内置设备继续录制（不中断），状态栏提示"音频设备已切换" |
| **录制中 Mac 进入睡眠** | 阻止睡眠（IOPMAssertion）；如果用户强制合盖 → 停止录制并保存 |
| **进程录制目标进程退出** | 自动停止录制 → 保存已录内容 → 提示"[进程名] 已退出，录制已自动停止" |
| **同时打开多个 App 实例** | 仅允许单实例运行（NSApp 检测） |

### 9. V1.0 付费策略

**V1.0 上线时为完全免费**（无任何限制），原因：
1. 积累初始用户和口碑
2. 收集用户反馈，验证核心假设

- V1.0 ~ V1.2：完全免费，所有功能开放

### 1. 裁剪首尾
- 精度：0.1 秒，拖动左右拖柄选区
- 灰色遮罩标记裁剪区，支持预览
- 保存：覆盖原文件 或 另存为新文件
- 技术：AVAssetExportSession timeRange

### 2. 静音裁剪
- 阈值：-60dB ~ -20dB，默认 -40dB
- 最小时长：0.5s ~ 3.0s，默认 1.0s
- 检测速度：< 3 秒（10 分钟音频）
- 可选择性删除，删除后 50ms 交叉淡化
- 技术：PCM buffer 逐帧 RMS 检测

### 3. 音量标准化
- 算法：LUFS
- 预设：播客(-16) / YouTube(-14) / 广播(-24) / 自定义
- 峰值限制：-1 dBTP（True Peak）
- 处理速度：< 2 秒（10 分钟音频）

### 4. 淡入淡出
- 时长：0.5s ~ 3.0s，步进 0.1s
- 曲线：线性 / 对数 / S 曲线
- 默认：淡入 0.5s + 淡出 1.0s，对数曲线

### 5. 编辑器 UI
- 入口：文件列表 → 选中 → 编辑按钮
- 布局：返回 + 文件名 + 撤销/重做 + 保存 + 波形 + 工具栏
- 撤销：最多 20 步

### 6. V1.1 验收标准

| # | 标准 | 通过条件 |
|---|------|----------|
| 1 | 裁剪 | 预览正确，保存后时长正确 |
| 2 | 静音裁剪 | 准确率 > 90%，无爆音 |
| 3 | 标准化 | 响度在目标 ±1 LUFS 内 |
| 4 | 淡入淡出 | 听感平滑，无突变 |
| 5 | 撤销 | 所有操作可撤销/重做 |
| 6 | 非破坏性 | 原文件可保留 |
| 7 | **负向测试** | 对空文件/极短文件(< 1s)/损坏文件执行编辑操作，给出明确错误提示而非崩溃 |

### 1. 格式转换
- 支持：M4A / WAV / MP3 / FLAC / OGG / AIFF 六格式互转
- 设置：比特率(128-320) / 采样率(22.05-96k) / 声道 / 质量预设
- 技术：M4A/WAV/AIFF 用 AVFoundation，其他用 FFmpeg 静态库

### 2. 音频导入
- 方式：拖拽 / Cmd+O / Finder 关联
- 导入后复制到 App 目录，可编辑/转换/导出
- 额外支持：CAF / WMA / APE / OPUS

### 3. 批量转换
- 无限文件数，2 并发
- 总进度 + 单文件进度
- 单个失败不影响其他
- 保持原文件名，重名自动加后缀

- 月费：$4.99/月（中国 25 元/月）
- 年费：$29.99/年（中国 168 元/年）

### 3. 付费引导
- 录制超 5 分钟 → 弹窗
- 点击编辑 → 锁定图标

- StoreKit 2 集成，启动时自动验证

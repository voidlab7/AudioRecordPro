> 作者：绘·设计师 | 日期：2026-05-17 | 模式：Standard

## 一、设计决策总览

### SAFE / RISK 分层

```
SAFE CHOICES（品类基线）
  ✅ 导航栏 + 波形区 + 工具栏 三段式布局（Logic Pro / GarageBand / Audacity 共识）
  ✅ 深色背景 + 波形珊瑚红配色（延续录制页视觉语言）
  ✅ 左右拖柄选区交互（裁剪类工具的行业标准）
  ✅ Cmd+Z/Shift+Z 撤销重做（macOS 平台共识）
  ✅ 工具栏在波形区下方（与需求文档一致，DAW 惯例）

RISKS（产品获得自己面孔的地方）
  🔶 编辑器不占满全屏——Sidebar 保持可见，编辑器仅替换 Content 区
     → 收益：用户可快速切换文件，无需返回
     → 代价：编辑器波形区宽度减少 260px（Sidebar 宽度）
     → 判断：可接受——目标用户是简单编辑，不是专业 DAW
  🔶 工业风「硬件面板」风格延伸到编辑器
     → 收益：视觉一体感，品牌辨识度
     → 代价：需要自定义所有 UI 组件，无法复用系统控件
```

### 枢的 7 个决策点 → 绘的定稿

| # | 决策点 | 定稿 | 理由 |
|---|--------|------|------|
| 1 | 编辑器入口方式 | **B — 文件选中后出现「编辑」按钮** | 双击已绑定播放，右键菜单层级太深；直接在文件行右侧露出编辑图标最直觉 |
| 2 | 切换动画 | **B — 左右滑入** | Content 区向左推出录制页、从右滑入编辑页（200ms easeOut），给用户「进入子层级」的方向感 |
| 3 | Sidebar 可见性 | **A — 保持可见** | 编辑中仍可切换文件，Sidebar 文件列表标记当前编辑文件的「编辑中」状态 |
| 4 | 工具栏位置 | **A — 波形区下方** | 与 Logic Pro / Audacity / GarageBand 一致；工具操作「向上作用于波形」符合心智模型 |
| 5 | 波形选区交互 | **B — 左右拖柄** | REQ-1.1-02 明确要求拖柄；拖柄交互在裁剪首尾场景最直觉 |
| 6 | 静音段标记样式 | **B — 灰色半透明 + 红色删除线** | 灰色（被静音）+ 红色细线（将被删除）双信号，比纯灰色更明确 |
| 7 | 撤销/重做按钮 | **A — 导航栏右侧** | 撤销是全局操作不是编辑工具，放导航栏与 Xcode/Figma 一致 |

## 二、编辑器入口设计

### 文件列表行改造

当前 `IndustrialRecordedFileRowView` 结构：`[波形图标] [文件名 + 元信息] [格式徽章]`

改造为：

```
┌────────────────────────────────────────────────┐
│ 🎵  Recording-2026-05-17.wav              WAV  │
│     DUR 02:34    SIZE 24.1 MB            [✏️]  │
└────────────────────────────────────────────────┘
                                            ↑
                                       编辑按钮（hover 时出现）
```

**交互规则：**
- 默认：编辑按钮隐藏，格式徽章正常显示
- Hover 时：格式徽章位置出现「编辑」图标按钮（pencil.line SF Symbol）
- 点击编辑按钮 → 进入编辑器
- 单击行其他区域 → 选中文件（当前行为不变）
- 双击 → 播放（当前行为不变）
- 录制中：编辑按钮不出现（禁止同时编辑和录制）

### 编辑中状态标记

进入编辑器后，文件列表中被编辑的文件行显示特殊状态：

```
┌────────────────────────────────────────────────┐
│ 🎵  Recording-2026-05-17.wav         EDITING   │  ← 琥珀色徽章
│     DUR 02:34    SIZE 24.1 MB                  │
└────────────────────────────────────────────────┘
```

- 徽章文字：`EDITING`
- 颜色：`IndustrialColors.tertiary`（琥珀色 #FFD6A3）
- 背景：`IndustrialColors.surfaceContainerHighest`
- 该行不响应双击播放（文件被锁定）

## 四、EditorNavigationBar 设计

### 布局

```
┌───────────────────────────────────────────────────────────┐
│  [← 返回]   📄 Recording-2026-05-17.wav   [↩] [↪]  [保存] │
│   左对齐          居中                       右对齐         │
└───────────────────────────────────────────────────────────┘
```

### 组件规范

| 组件 | 类型 | 尺寸 | 样式 |
|------|------|------|------|
| 返回按钮 | IndustrialIconButtonView | 28×28 | SF Symbol: `chevron.left`，文字 "返回" |
| 文件名 | NSTextField | 自适应 | `IndustrialTypography.h2`（14px Bold），白色，居中，truncate middle |
| 撤销按钮 | IndustrialIconButtonView | 28×28 | SF Symbol: `arrow.uturn.backward`，禁用态：0.3 opacity |
| 重做按钮 | IndustrialIconButtonView | 28×28 | SF Symbol: `arrow.uturn.forward`，禁用态：0.3 opacity |
| 保存按钮 | IndustrialButtonView | 64×28 | 文字 "保存"，主色高亮态 |

### 状态变化

| 状态 | 返回按钮 | 撤销/重做 | 保存按钮 |
|------|---------|----------|---------|
| 刚进入（无编辑） | 可用 | 两个都禁用 | 禁用（灰色） |
| 有编辑操作 | 可用（退出时弹确认） | 撤销可用 | 可用（高亮青色边框） |
| 撤销到初始状态 | 可用 | 撤销禁用，重做可用 | 禁用 |
| 保存后 | 可用 | 两个都禁用 | 禁用 |

### 未保存退出确认

点击「返回」且有未保存编辑时：

```
┌─ 确认对话框 ───────────────────────────┐
│                                        │
│  📝 有未保存的编辑                      │
│                                        │
│  当前编辑尚未保存，是否保存后退出？      │
│                                        │
│        [放弃]    [取消]    [保存]        │
│                                        │
└────────────────────────────────────────┘
```

- 「保存」→ 保存后退出编辑器
- 「放弃」→ 丢弃编辑直接退出
- 「取消」→ 留在编辑器

使用 `NSAlert` 实现，按钮顺序遵循 macOS HIG。

## 五、EditorWaveformView 设计

### 与录制 WaveformView 的关系

| 维度 | WaveformView（录制用） | EditorWaveformView（编辑用） |
|------|----------------------|---------------------------|
| 数据源 | 实时 PCM 峰值流 | 文件完整波形数据（一次性加载） |
| 坐标系 | 固定——1:1 映射，左起右滚 | 可变——`visibleTimeRange` + `zoomLevel` |
| 交互 | 点击/拖拽 seek | 缩放、滚动、选区拖柄 |
| 叠加层 | 播放游标 | 选区遮罩、静音段标记、播放游标、时间标尺 |
| 绘制方式 | `draw(_ dirtyRect:)` | `draw(_ dirtyRect:)` + CALayer 叠加 |

**结论：新建 `EditorWaveformView`，不修改现有 `WaveformView`。**

### 波形渲染规范

```
┌─ 时间标尺（24px）─────────────────────────────────────┐
│  0:00    0:30    1:00    1:30    2:00    2:30         │
├───────────────────────────────────────────────────────┤
│                                                       │
│  ██ █ ███ ██████ ███ █ ██ █████ ██ █ ███ █████ █     │  ← 波形柱
│  ██████████████████████████████████████████████████   │  ← 中线
│  ██ █ ███ ██████ ███ █ ██ █████ ██ █ ███ █████ █     │
│                                                       │
│                    ▼ 播放游标                          │
├───────────────────────────────────────────────────────┤
│  dB 标尺  -48  -36  -24  -12   0                      │
└───────────────────────────────────────────────────────┘
```

#### 颜色方案

| 元素 | 颜色 | Token |
|------|------|-------|
| 波形柱（正常） | 珊瑚红 | `waveformCoral` (#FF6B5F) |
| 波形柱（已播放/选中区域内） | 珊瑚红高亮 | `waveformCoral` alpha 0.9 |
| 波形柱（选区外/淡出区） | 珊瑚红低饱和 | `waveformSoft` (#FF8A80) alpha 0.4 |
| 中线 | 白色虚线 | `gridMedium` alpha 0.5 |
| 播放游标 | 红色 | `waveformAccent` (#FF453A) |
| 时间标尺文字 | 灰色 | `textTertiary` (#9CA3AF) |
| 时间标尺刻度 | 暗灰 | `onSurfaceVariant` alpha 0.24 |
| dB 标尺文字 | 暗灰 | `textTertiary` alpha 0.5 |
| 背景 | 深灰 | `surfaceContainerLow` (#161D1E) |

#### 缩放交互

| 操作 | 触发方式 | 行为 |
|------|---------|------|
| 放大 | Cmd + = / 双指外扩 / 滚轮 + Cmd | `zoomLevel *= 1.5`，以鼠标位置为锚点 |
| 缩小 | Cmd + - / 双指内收 / 滚轮 + Cmd | `zoomLevel /= 1.5`，最小到 fitAll |
| 适配全部 | Cmd + 0 | `zoomLevel = fitAll`，显示完整波形 |
| 水平滚动 | 双指左右滑 / 水平滚轮 | 平移 `visibleTimeRange` |

**缩放级别范围：**
- 最小：`fitAll`（整个文件适配视口宽度）
- 最大：每个采样点占 8px（即看到单个 PCM 采样）
- 默认进入时：`fitAll`

#### 选区交互（裁剪用）

```
       左拖柄                    右拖柄
          ▼                        ▼
┌─────┬──╋════════════════════════╋──┬─────┐
│ dim │  ║   选中区域（正常亮度）   ║  │ dim │
│ 灰色 │  ║                        ║  │ 灰色 │
└─────┴──╋════════════════════════╋──┴─────┘
```

| 元素 | 样式 |
|------|------|
| 选区内波形 | 正常亮度（`waveformCoral` alpha 0.8-1.0） |
| 选区外波形 | 降低亮度（`waveformSoft` alpha 0.25） |
| 选区外遮罩 | `surface` (#0E1416) alpha 0.4 |
| 左拖柄 | 4px 宽竖条，`primary` (#8AEBFF)，上下各 8px 圆角，中间有 3 条水平线纹（抓手视觉） |
| 右拖柄 | 同左拖柄 |
| 拖柄 hover | 发光效果 `glowCyan` |
| 选区边界线 | 1px `primary` alpha 0.6 |

**拖柄交互：**
- 鼠标接近拖柄 8px 范围 → 光标变为 `resizeLeftRight`
- 拖动拖柄 → 实时更新选区范围 + 时间显示
- 拖柄上方显示时间标签（如 "0:42.3"）
- 最小选区宽度：100ms（防止空选区）

```
│          │▓ 灰色  ▓│              │▓ 灰色  ▓│      │
│          │▓ + 红线 ▓│              │▓ + 红线 ▓│      │

```

| 元素 | 样式 |
|------|------|
| 静音段背景 | `surfaceContainerHigh` (#242B2D) alpha 0.6 |
| 静音段波形 | `waveformMuted` (#FF6B5F alpha 0.32) |

## 八、页面切换动效

### 录制页 → 编辑器（进入）

```
时间线:  0ms ─────────── 200ms
         
录制页:  [完整显示] ─→ [向左滑出 + 淡出]
编辑器:  [从右侧偏移 30px + 透明] ─→ [正常位置 + 完全不透明]

缓动:  easeOut (CAMediaTimingFunction)
时长:  200ms (IndustrialAnimation.long)
```

### 编辑器 → 录制页（返回）

```
时间线:  0ms ─────────── 200ms
         
编辑器:  [完整显示] ─→ [向右滑出 30px + 淡出]
录制页:  [从左侧偏移 30px + 透明] ─→ [正常位置 + 完全不透明]
```

**实现方式：** `NSAnimationContext.runAnimationGroup`，在 Content 区的容器视图内切换子视图。

## 九、快捷键映射

### 编辑器模式快捷键

| 快捷键 | 功能 | 条件 |
|--------|------|------|
| `Cmd+Z` | 撤销 | 有操作可撤销 |
| `Cmd+Shift+Z` | 重做 | 有操作可重做 |
| `Cmd+S` | 保存 | 有未保存编辑 |
| `Cmd+Shift+S` | 另存为 | 始终可用 |
| `Space` | 预览播放/暂停 | 始终可用 |
| `Escape` | 返回录制页 | 未保存时弹确认 |
| `Cmd+=` | 放大波形 | 始终可用 |
| `Cmd+-` | 缩小波形 | 始终可用 |
| `Cmd+0` | 适配全部 | 始终可用 |
| `Cmd+A` | 全选 | 选中整段波形 |
| `Delete` | 删除选区 | 有选区时 |

### 快捷键隔离

编辑器模式下，录制快捷键被禁用：
- `Cmd+R`（录制）→ 不响应
- `Cmd+E`（导出）→ 不响应
- `Cmd+Del`（删除录音）→ 不响应

通过 `NSMenuItemValidation` 的 `validateMenuItem(_:)` 方法，根据当前是否在编辑器模式来启用/禁用菜单项。

## 十、五态覆盖（Craft: state-coverage）

| 状态 | 场景 | 视觉表现 |
|------|------|---------|
| **Loading** | 加载长音频波形 | 波形区显示骨架屏动画（从左到右的灰色渐变扫光）+ "加载波形..." 文字 |
| **Empty** | 不适用（必须选文件才能进编辑器） | — |
| **Error** | 文件损坏/格式不支持 | 波形区居中显示红色错误图标 + "无法读取音频文件" + 返回按钮 |
| **Populated** | 正常编辑状态 | 完整波形 + 工具栏可用 |
| **Edge** | 极短音频（<1s）/ 极长音频（>30min） | 短音频：自动放大到最大级别；长音频：加载时分段加载，LOD 降采样 |

## 十一、无障碍（Craft: accessibility-baseline）

| 检查项 | 要求 | 实现 |
|--------|------|------|
| 对比度 | ≥ 4.5:1 | 所有文字色与背景色对比度已检查（`onSurface` #DDE4E5 on `surface` #0E1416 = 14.7:1 ✅） |
| 键盘导航 | Tab 键可遍历所有交互元素 | 返回→撤销→重做→保存→工具按钮→波形区（按左右键移动游标） |
| VoiceOver | 所有按钮有 accessibilityLabel | 「返回录制页」「撤销编辑」「重做编辑」「保存」「裁剪工具」等 |

> **作者**: PM（枢）| **日期**: 2026-05-25 | **优先级**: P0

> **关联设计**: `docs/design/V1.1-编辑器UI设计方案.md`  
> **状态**: 📋 规格定稿，待绘确认视觉 + 铸实现

---

## 1. 问题定义

### 当前状态

编辑器已有底层缩放/滑动能力（`zoomIn()`/`zoomOut()`/`scrollWheel`），但**用户无法发现和使用**：

| 能力 | 当前实现 | 用户可见性 |
|------|----------|-----------|
| 缩放 | Cmd + 滚轮 | ❌ 无 UI 提示，用户不知道 |
| 左右滑动 | 触控板横向滑动 | ❌ 无滚动条，无视觉反馈 |
| 适应全部 | `fitAll()` 方法存在 | ❌ 无按钮触发 |
| 缩放级别 | `zoomLevel` 属性存在 | ❌ 无视觉指示当前级别 |

### 用户期望（参考剪映）

剪映时间线提供了清晰的缩放 UI：
1. **右上角缩放控件**：🔍➖ — 滑块 — 🔍➕
2. **时间标尺**：顶部显示时间刻度，随缩放级别变化
3. **滚动条**：底部横向滚动条，可拖拽定位
4. **触控板手势**：捏合缩放 + 双指横向滑动

### 核心痛点

> 用户录完一段 30 分钟的音频，进入编辑器后看到整段压缩的波形，**不知道怎么放大查看细节**，也**不知道怎么滑动到中间某个位置**。

## 2. 目标用户故事

### US-Z01：通过按钮缩放

> 作为编辑音频的用户，我想通过点击放大/缩小按钮来调整波形的时间精度，以便找到需要裁剪的位置。

### US-Z02：通过滑块快速调整缩放级别

> 作为需要在概览和细节之间频繁切换的用户，我想拖动缩放滑块快速跳到目标精度，而不是反复点击按钮。

### US-Z03：通过滚动条定位

> 作为处理长录音的用户，我想通过拖动底部滚动条快速跳到录音的中间或末尾位置。

### US-Z04：一键适应全部

> 作为想要查看整段录音概览的用户，我想一键让波形缩放到适应整个窗口宽度。

### US-Z05：知道当前缩放状态

> 作为正在编辑的用户，我想随时知道当前的缩放级别和可见时间范围，以便判断是否需要进一步放大。

├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│              ▄▃▅▇▆▃▄▅▇▆▃▄▅▇▆▃▄▅▇▆▃▄▅▇▆▃▄▅▇▆▃▄                  │  ← 波形区

├────────────────────────────────────────────────────────────────────┤
│ [▶ 预览] [■]                    [🔍−] ━━━━●━━━━━━━ [🔍+] [⊞ Fit] │  ← 底部工具栏

### 3.2 缩放控件区域（底部工具栏右侧）

```text
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  [▶ 预览] [■]              [🔍−] ━━━━●━━━━━━━ [🔍+] [⊞]│
│                                                         │
│  ← 播放控制（左侧）        ← 缩放控件组（右侧）→        │

```

**缩放控件组组成**：

| 元素 | 说明 | 尺寸 |
|------|------|------|
| 🔍− 缩小按钮 | 点击缩小 1 级 | 24×24 图标按钮 |
| 缩放滑块 | 拖动连续调整缩放级别 | 宽 80-120px，高 4px 轨道 |
| 🔍+ 放大按钮 | 点击放大 1 级 | 24×24 图标按钮 |
| ⊞ Fit All 按钮 | 一键适应全部 | 24×24 图标按钮 |

### 3.3 横向滚动条（波形区下方）

```text
┌────────────────────────────────────────────────────────────────────┐
│ ◀ ═══════════════╗████████████╠══════════════════════════════ ▶    │
│   ↑               ↑ 可见范围指示器（thumb）                  ↑     │
│   左箭头          宽度 = 可见时长/总时长 × 轨道宽度          右箭头  │
└────────────────────────────────────────────────────────────────────┘
```

**滚动条规格**：

| 属性 | 值 |
|------|-----|
| 高度 | 12px（含 padding） |
| 轨道高度 | 4px |
| Thumb 最小宽度 | 40px（即使缩放到极致也不会太小） |
| Thumb 颜色 | `IndustrialColors.primary` alpha 0.6 |
| 轨道颜色 | `IndustrialColors.outlineVariant` alpha 0.3 |
| 位置 | 波形区与底部工具栏之间 |
| 可见条件 | `zoomLevel > 1.0` 时显示，`fitAll` 时隐藏 |

## 4. 交互规格

### 4.1 缩放按钮交互

| 操作 | 行为 |
|------|------|
| 点击 🔍+ | `zoomLevel *= 1.5`，锚定波形区中心 |
| 点击 🔍− | `zoomLevel /= 1.5`，锚定波形区中心 |
| 长按 🔍+/🔍− | 连续缩放（每 200ms 触发一次） |
| 🔍+ 到达最大缩放 | 按钮变为 disabled 状态（alpha 0.35） |
| 🔍− 到达 `zoomLevel = 1.0` | 按钮变为 disabled 状态 |

### 4.2 缩放滑块交互

| 操作 | 行为 |
|------|------|
| 拖动滑块 | 连续调整 `zoomLevel`，范围 `1.0 ~ maxZoomLevel` |
| 滑块映射 | 对数映射（非线性），低缩放区域占更多滑块空间 |
| 拖动时锚点 | 锚定波形区中心时间点 |
| 释放滑块 | 停在当前位置，不回弹 |
| 点击滑块轨道 | 跳到点击位置对应的缩放级别 |

**对数映射公式**：
```
sliderPosition = log(zoomLevel) / log(maxZoomLevel)  // 0.0 ~ 1.0
zoomLevel = pow(maxZoomLevel, sliderPosition)
```

### 4.3 Fit All 按钮交互

| 操作 | 行为 |
|------|------|
| 点击 ⊞ | `visibleStartTime = 0`，`visibleDuration = totalDuration`，`zoomLevel = 1.0` |
| 动画 | 200ms easeOut 过渡到全局视图 |
| 滑块位置 | 回到最左端 |
| 滚动条 | 隐藏（因为已经是全部可见） |

### 4.4 横向滚动条交互

| 操作 | 行为 |
|------|------|
| 拖动 Thumb | 更新 `visibleStartTime`，波形跟随滑动 |
| 点击轨道空白区 | 跳到点击位置对应的时间 |
| 点击左/右箭头 | 滑动 `visibleDuration * 0.25`（即 1/4 屏） |
| Thumb 宽度 | `= max(40, trackWidth * visibleDuration / totalDuration)` |
| 显示/隐藏 | `zoomLevel > 1.0` 时 fadeIn 显示，`= 1.0` 时 fadeOut 隐藏 |

### 4.5 触控板/鼠标手势（保留并增强）

| 手势 | 行为 | 说明 |
|------|------|------|
| Cmd + 滚轮上下 | 缩放（锚定鼠标位置） | 已有，保留 |
| 触控板捏合 | 缩放（锚定捏合中心） | 新增 |
| 横向滑动 | 左右滚动 | 已有，保留 |
| Option + 滚轮 | 快速缩放（步进更大） | 新增，可选 |

### 4.6 键盘快捷键

| 快捷键 | 行为 | 说明 |
|--------|------|------|
| `Cmd + =` / `Cmd + +` | 放大 | macOS 标准 |
| `Cmd + -` | 缩小 | macOS 标准 |
| `Cmd + 0` | Fit All | 适应全部 |
| `Cmd + 1` | 缩放到 1 秒/屏 | 精细编辑 |
| `Cmd + 2` | 缩放到 10 秒/屏 | 中等精度 |
| `Cmd + 3` | 缩放到 1 分钟/屏 | 概览 |
| `←` / `→` | 滑动 1/10 屏 | 微调定位 |
| `Shift + ←` / `Shift + →` | 滑动 1/2 屏 | 快速定位 |
| `Home` / `End` | 跳到开头/结尾 | 快速导航 |

## 5. 视觉规格

### 5.1 缩放按钮

| 属性 | 值 |
|------|-----|
| 图标 | SF Symbol: `minus.magnifyingglass` / `plus.magnifyingglass` |
| 尺寸 | 24×24 |
| 图标颜色（正常） | `IndustrialColors.onSurfaceVariant` |
| 图标颜色（hover） | `IndustrialColors.onSurface` |
| 图标颜色（disabled） | `IndustrialColors.onSurfaceVariant` alpha 0.35 |
| 背景（正常） | 透明 |
| 背景（hover） | `IndustrialColors.surfaceContainerHighest` |
| 圆角 | `IndustrialCornerRadius.sm` (4px) |

### 5.2 缩放滑块

| 属性 | 值 |
|------|-----|
| 轨道宽度 | 80-120px（响应式，最小 80） |
| 轨道高度 | 3px |
| 轨道颜色 | `IndustrialColors.outlineVariant` |
| 已填充轨道颜色 | `IndustrialColors.primary` alpha 0.5 |
| Knob 直径 | 10px |
| Knob 颜色 | `IndustrialColors.primary` |
| Knob hover | 12px + 阴影 |

### 5.3 Fit All 按钮

| 属性 | 值 |
|------|-----|
| 图标 | SF Symbol: `arrow.left.and.right.square` 或 `rectangle.arrowtriangle.2.outward` |
| 尺寸 | 24×24 |
| Tooltip | "适应全部 (⌘0)" |
| 其他 | 同缩放按钮视觉规格 |

### 5.4 时间标尺（增强）

| 属性 | 值 |
|------|-----|
| 高度 | 24px |
| 背景 | `IndustrialColors.surfaceContainer` |
| 刻度线颜色 | `IndustrialColors.outlineVariant` |
| 时间文字 | `IndustrialTypography.caption`，`IndustrialColors.onSurfaceVariant` |
| 刻度密度 | 根据 `pixelsPerSecond` 自动调整（避免重叠） |
| 当前时间指示 | 播放头位置的红色三角标记 |

**刻度密度规则**：

| pixelsPerSecond | 主刻度间隔 | 副刻度间隔 | 时间格式 |
|---:|---:|---:|---|
| < 2 | 5 分钟 | 1 分钟 | `HH:MM` |
| 2 ~ 10 | 1 分钟 | 15 秒 | `MM:SS` |
| 10 ~ 50 | 15 秒 | 5 秒 | `MM:SS` |
| 50 ~ 200 | 5 秒 | 1 秒 | `MM:SS.s` |
| > 200 | 1 秒 | 0.1 秒 | `SS.ss` |

## 6. 状态反馈

### 6.1 缩放级别指示

在缩放滑块旁（或 tooltip）显示当前可见时间范围：

```text
正常态:    [🔍−] ━━━━●━━━━━━━ [🔍+] [⊞]
Tooltip:   "当前视图: 0:30 ~ 1:30 (1分钟)"
```

### 6.2 缩放动画

| 场景 | 动画 |
|------|------|
| 点击按钮缩放 | 150ms easeOut |
| 拖动滑块 | 实时跟随，无延迟 |
| Fit All | 200ms easeOut |
| 键盘快捷键 | 150ms easeOut |
| 触控板捏合 | 实时跟随 |

### 6.3 边界反馈

| 场景 | 反馈 |
|------|------|
| 缩放到最大 | 🔍+ 按钮 disabled + 滑块到右端 + 轻微弹性回弹 |
| 缩放到最小（Fit All） | 🔍− 按钮 disabled + 滑块到左端 + 滚动条隐藏 |
| 滑动到开头 | 左箭头 disabled + Thumb 贴左 |
| 滑动到结尾 | 右箭头 disabled + Thumb 贴右 |

## 7. 与现有功能的关系

### 7.1 与 REQ-2.0-03 的关系

本规格是 REQ-2.0-03 的**用户可见层**补充：

```text
REQ-2.0-03a（数据模型 + Tile 引擎）  ← 底层数据
REQ-2.0-03b（视图改造 + 绘制迁移）   ← 绘制层
本规格（缩放控件交互规格）            ← 用户交互层（新增）
```

**依赖关系**：
- 缩放控件调用 `EditorWaveformView.zoomIn()`/`zoomOut()`/`fitAll()`
- 滚动条更新 `visibleStartTime`
- 这些方法已存在，控件只是提供 UI 入口

### 7.2 与现有代码的关系

| 现有代码 | 本规格补充 |
|----------|-----------|
| `zoomIn(anchorX:)` | 缩放按钮点击时调用（anchorX = 波形区中心） |
| `zoomOut(anchorX:)` | 缩小按钮点击时调用 |
| `fitAll()` | Fit All 按钮点击时调用 |
| `scrollWheel` Cmd+滚轮 | 保留，与按钮并存 |
| `scrollWheel` 横向滑动 | 保留，滚动条同步更新 |
| `zoomLevel` 属性 | 滑块位置 = log(zoomLevel) / log(maxZoomLevel) |
| `visibleStartTime` | 滚动条 Thumb 位置 = visibleStartTime / totalDuration |

### 7.3 实现优先级

本规格可以**独立于 REQ-2.0-03a/b 先行实现**：

```text
Phase 1（可立即实现）:
  - 缩放按钮 🔍+/🔍−（调用已有 zoomIn/zoomOut）
  - Fit All 按钮（调用已有 fitAll）
  - 键盘快捷键
  - 横向滚动条

Phase 2（依赖 REQ-2.0-03a/b）:
  - 缩放滑块（需要 LOD 切换配合）
  - 触控板捏合缩放
  - 缩放时 tile 按需加载
```

## 9. 竞品参考

| App | 缩放控件位置 | 缩放方式 | 滚动条 |
|-----|-------------|---------|--------|
| **剪映** | 右上角 🔍−滑块🔍+ | 按钮+滑块+捏合 | 底部 minimap |
| **GarageBand** | 右上角滑块 | 滑块+Cmd滚轮 | 底部滚动条 |
| **Logic Pro** | 右上角滑块 | 滑块+Cmd滚轮+捏合 | 底部滚动条 |
| **Audacity** | 工具栏按钮 | 按钮+Ctrl滚轮 | 底部滚动条 |
| **我们** | 底部工具栏右侧 | 按钮+滑块+Cmd滚轮+捏合 | 波形区下方 |

**我们的选择理由**：
- 放在底部工具栏右侧而非右上角，因为编辑工具在底部，缩放是编辑辅助操作，放在一起更自然
- 同时提供按钮+滑块+手势，覆盖不同用户习惯

## 11. 风险与约束

| 风险 | 影响 | 缓解 |
|------|------|------|
| 底部工具栏空间不足 | 缩放控件与播放控件挤在一起 | 响应式：窗口 < 800px 时隐藏滑块，只保留按钮 |
| 缩放滑块精度不够 | 用户难以精确定位到目标缩放级别 | 对数映射 + tooltip 显示当前可见范围 |
| 滚动条与触控板冲突 | 用户同时操作两者导致跳动 | 滚动条拖动时暂停触控板响应 |
| 短文件不需要缩放 | 控件占空间但无用 | 文件 < 10s 时隐藏缩放控件组 |

## 一、产品概述

WavePad Audio Editor 是 **NCH Software** 出品的老牌音频编辑器（v24.22），定位为**全功能音频编辑工具**。跨平台支持 macOS / Windows / iOS / Android。

### 产品定位

| 维度 | WavePad |
|------|---------|
| **定位** | 专业音频编辑器（重编辑，轻录制） |
| **历史** | NCH Software 老牌产品，版本号已到 24.x |
| **平台** | macOS / Windows / iOS / Android |
| **风格** | 传统桌面软件风格，功能密集 |
| **系统音频** | ❌ 不支持（仅麦克风录制） |

### 与前两款竞品的区别

| 维度 | Audio Capture Pro | Audio One | WavePad |
|------|-------------------|-----------|---------|
| **核心定位** | 纯录制 | 录制+混音 | 纯编辑 |
| **系统音频** | ✅ | ❌ | ❌ |
| **编辑深度** | 无 | 中等（DAW） | 深度（专业编辑器） |
| **UI 现代感** | ★★★★ | ★★★★★ | ★★ |
| **功能数量** | 少 | 中 | 极多 |
| **目标用户** | 录制需求者 | 音乐创作者 | 音频后期处理者 |

## 二、核心能力

### ⚠️ 关键限制：无系统音频录制

WavePad 仅支持**麦克风录制**（Record audio from a microphone），不支持系统音频和进程级音频捕获。

| 能力 | 支持情况 | 说明 |
|------|----------|------|
| 🔊 系统音频录制 | ❌ **不支持** | — |
| 📱 进程级音频捕获 | ❌ **不支持** | — |
| 🎙️ 麦克风录制 | ✅ 支持 | 基础录制功能 |
| ✂️ 音频编辑 | ✅ **核心能力** | 极其丰富的编辑功能 |
| 🎚️ 音频特效 | ✅ 支持 | Effects / Levels / Voice 多个特效类别 |
| 📊 音频分析 | ✅ 支持 | 独立 Analysis 菜单 |
| ☁️ 云存储集成 | ✅ 支持 | Dropbox / Google Drive / OneDrive |

## 四、UI 设计分析

### 🔴 核心结论：UI 设计非常落后

WavePad 的 UI 停留在 **2010 年代早期**的设计语言，与现代 macOS 应用格格不入。

### 1. 落后的设计元素

| 问题 | 具体表现 |
|------|----------|
| **Ribbon 工具栏** | 使用 Windows 风格的 Ribbon 界面，在 macOS 上非常违和 |
| **图标风格** | 拟物化图标（剪刀、胶水瓶等），风格过时 |
| **左侧面板** | 纯文本超链接列表，像 2005 年的网页导航 |
| **字体渲染** | 非 macOS 原生字体，看起来像跨平台框架渲染 |
| **颜色方案** | 深灰背景 + 白色波形，缺乏层次感和现代感 |
| **布局密度** | 信息过于密集，缺乏呼吸空间 |
| **Tab 样式** | 蓝色 Tab 标签，像浏览器标签而非原生控件 |
| **按钮样式** | 工具栏按钮大小不一，排列杂乱 |
| **"Upgrade" 按钮** | 右上角突兀的升级按钮 |

### 2. 与现代 macOS 设计规范的差距

| macOS 设计规范 | WavePad 实际 |
|----------------|-------------|
| SF Symbols 图标 | 自定义拟物图标 |
| 毛玻璃/半透明 | 纯色不透明背景 |
| 圆角卡片 | 直角矩形 |
| 系统字体 San Francisco | 非系统字体 |
| 暗色/亮色模式跟随 | 固定深色 |
| 简洁工具栏 | 密集 Ribbon 栏 |
| 侧边栏原生样式 | 超链接文本列表 |

### 3. 为什么 UI 落后但仍有市场

| 原因 | 说明 |
|------|------|
| **功能极其丰富** | 20+ 工具栏按钮，覆盖几乎所有音频编辑需求 |
| **老用户习惯** | 版本号 24.x，积累了大量老用户 |
| **跨平台一致** | 同一套 UI 在 Win/Mac/Mobile 上运行 |
| **专业用户不在乎 UI** | 专业用户更看重功能完整性 |
| **低价策略** | 价格低于专业竞品，性价比高 |

### 4. UI 设计的唯一亮点

| 亮点 | 说明 |
|------|------|
| **波形显示清晰** | 白色波形在深色背景上对比度好 |
| **概览+详细双层波形** | 顶部缩略图 + 主编辑区，方便导航 |
| **多 Tab 支持** | 可同时打开多个音频文件 |
| **Quick Start 向导** | 对新手友好，引导式操作 |

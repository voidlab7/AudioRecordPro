# 竞品分析：Audio Capture Pro

> 分析日期：2026-05-09
> 分析维度：功能 + UI设计优势 + 商业模式

---

## 一、产品概述

Audio Capture Pro 是一款 macOS 音频录制工具，核心定位是**系统音频和应用级音频捕获**。

---

## 二、核心能力

Audio Capture Pro 的核心能力构成了音频录制工具的**基础核心能力三角**（也是我们产品的核心能力）：

| 核心能力 | 说明 |
|----------|------|
| 🔊 **系统音频录制** | 捕获 Mac 系统级音频输出 |
| 📱 **进程级音频捕获** | 选择性录制不同应用/进程的音频 |
| 🎙️ **麦克风录制** | 录制麦克风输入 |

```
        ┌─────────────────┐
        │   系统音频       │
        │  (System Audio)  │
        └────────┬────────┘
                 │
    ┌────────────┼────────────┐
    │            │            │
    ▼            ▼            ▼
┌────────┐  ┌────────┐  ┌────────┐
│ 进程A  │  │ 进程B  │  │ 麦克风 │
│ 音频   │  │ 音频   │  │ 输入   │
└────────┘  └────────┘  └────────┘
```

## 三、功能分析

### 完整功能列表

| 功能 | 描述 |
|------|------|
| **系统音频录制** | 捕获 Mac 系统级音频输出（System Audio） |
| **应用级音频捕获** | 列出所有已打开的应用，可选择性录制特定应用的音频 |
| **多源选择** | 支持同时勾选多个音频源（系统音频 + 多个应用） |
| **波形可视化** | 录制/播放时显示双色波形（青色 = 已播放，黑色 = 未播放） |
| **文件管理** | "Saved Files" 标签页管理所有录音文件 |
| **播放控制** | 播放/暂停、前进10秒、后退10秒 |
| **音量控制** | 右上角音量滑块 |
| **分享/导出** | 分享按钮支持导出 |
| **删除管理** | 直接删除录音文件 |
| **导出格式** | M4A 和 WAV 格式 |
| **独立音轨提取** | Extract individual tracks（付费功能） |

## 四、UI 设计优势

### 1. 布局设计

| 设计要素 | 分析 |
|----------|------|
| **双面板布局** | 左侧导航/选择 + 右侧内容区，经典且高效 |
| **Tab 切换** | "Audio Recorder" / "Saved Files" 两个核心模式清晰分离 |
| **信息密度适中** | 不拥挤，留白充足，视觉舒适 |

### 2. 视觉风格

- **原生 macOS 风格**：标准窗口控件、原生字体、系统级配色
- **极简主义**：无多余装饰，功能即界面
- **浅色主题**：白色背景 + 灰色分割线，干净清爽
- **图标复用**：直接使用各应用的原生图标，用户一眼识别

### 3. 交互亮点

| 亮点 | 说明 |
|------|------|
| **Checkbox 多选** | 音频源用 checkbox 选择，直觉操作 |
| **大录制按钮** | 粉红色圆形按钮，视觉焦点明确 |
| **波形双色区分** | 青色（已播放）vs 黑色（未播放），进度一目了然 |
| **时间双显示** | 当前位置 + 剩余时间 |
| **10秒跳转** | 前进/后退10秒按钮，适合快速定位 |

### 4. 设计不足（可超越的点）

| 不足 | 说明 |
|------|------|
| **文件命名** | 录音文件自动命名为设备名，无法自定义，不够友好 |
| **无搜索/筛选** | 文件多了之后难以管理 |
| **无编辑功能** | 不支持裁剪、拼接等基础编辑 |
| **无标签/分类** | 所有录音平铺，无组织结构 |
| **波形不可交互** | 不支持点击波形跳转位置 |
| **无暗色模式** | 仅浅色主题 |
| **Upgrade 入口突兀** | 右上角 "✨ Upgrade" 略显廉价 |

## 五、商业模式

### 定价策略

| 方案 | 价格 | 折算月费 | 备注 |
|------|------|----------|------|
| **年付** | ¥128/年 | ≈ ¥10.67/月 | 标注 "SAVE 62%" |
| **月付** | ¥28/月 | ¥28/月 | 基准价 |

### 免费版限制机制

| 限制方式 | 具体内容 |
|----------|----------|
| **录制文件数量限制** | 免费版最多保存 **5 个文件** |
| **绕过方式** | 卸载重装可重置计数（说明限制机制粗糙，仅依赖本地存储计数，未做服务端校验） |
| **付费解锁** | 订阅后 Unlimited audio recordings |

> ⚠️ 弹窗提示原文："Saved Files Limit — Subscribe to Audio Capture Pro to record and save more than 5 files."

### 付费版解锁内容

- ✅ Unlimited audio recordings（无限录音）
- ✅ Export as M4A or WAV（导出格式）
- ✅ Extract individual tracks（独立音轨提取）

### 定价对标

| 竞品 | 定价 | 模式 |
|------|------|------|
| Audio Capture Pro | ¥128/年 | 订阅 |
| Loopback (Rogue Amoeba) | $99 买断 | 一次性 |
| SoundSource | $39 买断 | 一次性 |
| Audio Hijack | $76 买断 | 一次性 |

Audio Capture Pro 选择了**低价订阅**路线，与 Rogue Amoeba 系列的**高价买断**形成差异化。

### 竞争策略

> **核心能力相同**（系统音频 + 进程音频 + 麦克风）意味着我们需要在**差异化层**（AI 能力、编辑功能、文件管理、UI 体验、商业模式）上建立优势，而非在基础录制能力上竞争。

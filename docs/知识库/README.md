| 优先级 | 文档 | 用途 |
|---|---|---|
| 1 | `../../AudioRecordApp/`、`../../AudioRecordKit/` | 实际代码事实源 |

## 文档使用规则

1. 讨论产品方向和版本范围，先读 `product.md`。
2. 讨论界面、按钮、布局、状态、录制态 / 编辑态，先读 `../设计/设计规范.md`。
3. 讨论录制管线、编辑器、文件保存、导出格式，先读 `tech.md`。
4. 讨论已知问题、风险、QA 路径、代码与文档差异，先读 `risks.md`。
5. 若文档与代码冲突，以实际代码为准，并同步更新对应知识文档。

## 维护原则

- 不再把所有事实堆进一个超长 Markdown。
- 新事实按主题更新到对应文件。
- 需求执行状态仍以 `../需求/README.md` 和具体 `REQ-*.md` 为准。
- 当前 UI / 交互设计细节也可同步沉淀到 `../设计/`。
- 历史方案、废弃方案、旧设计统一放入 `../归档/`。

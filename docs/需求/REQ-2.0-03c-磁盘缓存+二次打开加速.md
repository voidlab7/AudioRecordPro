# REQ-2.0-03c 磁盘缓存 + 二次打开加速

## 版本：V2.0 | 优先级：P1 | 状态：⬜ 待开发

> 父需求：REQ-2.0-03 剪映式虚拟时间线音频轨道波形展示
> 依赖：REQ-2.0-03a（数据模型 + Tile 引擎）

---

## 1. 一句话需求

为波形 tile 引擎增加磁盘持久化缓存层，使同一录音第二次打开时波形能够秒级显示，无需重新扫描音频文件。

---

## 2. 问题定义

| 问题 | 当前表现 | 用户影响 |
|---|---|---|
| 每次打开都重新生成 | 长录音每次打开编辑器都要等待波形生成 | 反复编辑同一录音体验差 |
| 内存缓存会话丢失 | 关闭编辑器后内存缓存清空 | 下次打开等同首次 |
| 无缓存失效机制 | — | 文件修改后可能显示过期波形 |

---

## 3. 目标用户故事

### US-05（继承自父需求）：二次打开加速

> 作为反复处理同一录音的用户，我希望第二次打开长录音时波形能够更快显示，以便继续编辑而不用重新等待扫描。

---

## 4. 目标方案

### 4.1 缓存路径

```text
~/Library/Caches/AudioRecord/Waveforms/{assetID}/
  ├── lod0_tile0.wfcache
  ├── lod0_tile1.wfcache
  ├── lod2_tile0.wfcache
  ├── lod2_tile1.wfcache
  └── ...
```

### 4.2 缓存 Key 组成

缓存 key（体现在 `assetID` 中）必须包含：

| 字段 | 用途 |
|------|------|
| 文件路径 hash | 定位文件 |
| 文件大小 | 检测文件变化 |
| 修改时间 | 检测文件变化 |
| sampleRate | 确保采样率一致 |
| channelCount | 确保声道数一致 |
| algorithm version | 算法升级后自动失效 |

### 4.3 缓存文件格式

采用自定义二进制格式（非 JSON/Codable），优先读写性能：

```text
[version: UInt8]
[sourceStartTime: Double]
[duration: Double]
[samplesPerPeak: Int32]
[peakCount: Int32]
[peaks: (min: Float, max: Float, rms: Float) × peakCount]
```

### 4.4 缓存层级

```text
WaveformTileProvider.requestTiles()
  ├── 1. 内存缓存命中 → 立即返回
  ├── 2. 磁盘缓存命中 → 提升到内存 → 返回
  └── 3. 未命中 → 后台生成 → 写入磁盘 + 内存 → 回调
```

---

## 5. 缓存失效规则

| 触发条件 | 失效行为 |
|----------|---------|
| 文件大小变化 | assetID 变化 → 旧目录自动孤立 |
| 文件修改时间变化 | assetID 变化 → 旧目录自动孤立 |
| 算法版本升级 | assetID 变化 → 旧目录自动孤立 |
| 文件被删除 | 下次访问时缓存目录可清理 |
| 用户手动清理 | 支持全局清理入口（可选） |

**说明：** 由于 `assetID` 由文件元数据 + 算法版本共同生成，任何变化都会产生新的 ID，旧缓存自然失效（孤立文件可定期清理）。

## 8. 非功能要求

| 维度 | 要求 |
|------|------|
| 读取性能 | 单个 tile 磁盘读取 < 5ms |
| 写入性能 | 单个 tile 磁盘写入 < 10ms |
| 容错 | 缓存文件损坏时静默跳过，不影响正常功能 |
| 磁盘占用 | 单个 1 小时录音全 LOD 缓存 < 20MB |
| 线程安全 | 磁盘读写在后台队列，不阻塞主线程 |

---

## 9. 验收标准

### 9.1 二次打开加速

- [ ] 第二次打开同一长录音（1h+），Fit All 概览波形 < 500ms 显示
- [ ] 第二次打开时不触发后台 tile 生成（已缓存的 LOD）
- [ ] 磁盘缓存命中后正确提升到内存缓存

### 9.2 缓存失效

- [ ] 文件大小变化后旧缓存不被使用
- [ ] 文件修改时间变化后旧缓存不被使用
- [ ] 算法版本变化后旧缓存不被使用（修改 `algorithmVersion` 常量验证）
- [ ] 缓存文件被手动删除后不崩溃，自动重新生成

### 9.3 容错

- [ ] 缓存文件内容损坏（截断/乱写）时不崩溃，静默跳过
- [ ] 磁盘空间不足时写入失败不影响波形显示
- [ ] 缓存目录权限异常时不影响音频播放和编辑

### 9.4 回归

- [ ] 首次打开文件行为不变（无缓存时正常生成）
- [ ] 短文件（≤60s）不受磁盘缓存逻辑影响
- [ ] 编译通过

# UI-043 麦选择器去掉「跟随系统默认」伪行 · 需求规格

> 状态：**已审核**（2026-11-05 老板「这个需求审核通过可以进入开发」）。TODOS.md 池行为状态真相；本文是验收与边界正本。
> 范围：侧边栏麦克风选择器 UI——去掉展开态伪行；跟随语义保留为 `preferredDeviceUID=nil` 投影。

---

## 一、背景

老板 2026-10-31 截图：「打开的时候直接看到几个麦克风输入设备，默认勾选，系统默认那个不用再单独起一行」。

现状：`SidebarView.refreshMicDeviceList()` 恒注入第 0 项「跟随系统默认」（uid=nil + 副标=实际设备名），与设备列表间有分隔线；无显式偏好时勾选落在伪行。

## 二、目标行为

1. 展开态**只列实际麦克风设备**；无「跟随系统默认」行、无该行与列表间的分隔线。
2. 无显式偏好（`preferredDeviceUID == nil`）时：勾选落在当前 `isSystemDefault` 设备；折叠行显示该设备友好名。**不得**把系统默认 UID 写入 UserDefaults（保持动态跟随）。
3. 点击某设备行 → 钉选（`preferredDeviceUID = uid`，重启保留）；系统默认变化不挪勾。
4. **拍板 a**：再点**当前已勾选**行 → 取消钉选回跟随（`preferredDeviceUID = nil`）；无伪行也能回到跟随。
5. 系统默认切换 / 设备热插拔：无钉选时勾选与折叠名跟随跳转（既有 `onDevicesChanged`）。
6. L10n：删除「跟随系统默认」相关 key；空态「未检测到」保留。

## 四、验收标准

- [ ] **a.** 展开选择器只有实际设备列表（无「跟随系统默认」、无 idx==1 分隔线）；系统默认设备带勾选（无钉选时）
- [ ] **b.** 从未选择过：折叠行=系统默认设备名；系统切默认后勾选/折叠名跟随；UserDefaults **无**新增 `preferredMicDeviceUID`（或等价 key）写入
- [ ] **c.** 点击设备行钉选持久化（重启保留）；录音走所选设备（FEAT-004R2 不回归）
- [ ] **d.** 再点已勾选行 → 回跟随（nil）；日志可证
- [ ] **e.** `bash build-app.sh` exit 0
- [ ] **f.** SDK 单测不回退（`bash scripts/test_sdk.sh` 或 adapter 等价）

## 五、实现要点（非强制）

- 主改：`SidebarView.refreshMicDeviceList` / `micDeviceSelected`；`IndustrialMicDeviceSelectorView.rebuildList` 去掉 idx==1 分隔线特例（伪行消失后 idx==1 即第二台真设备，不得再插线）
- 勾选索引：无偏好 → `devices.firstIndex { $0.isSystemDefault }`；有偏好 → 对应 uid 下标
- toggle：`selected(at:)` / `micDeviceSelected` 在「点已选设备」时写 nil
- 注释与 UI-015/UI-027 文档字符串随伪行删除更新

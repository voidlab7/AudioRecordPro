# REQ-2.0-04 LevelMeterCard 电平表卡片 UI 优化

## 版本：V2.0 | 优先级：P1 | 状态：🔲 待实现

## 背景

当前 `LevelMeterCardView.swift` 实现了基本的双通道竖向电平表功能，但在视觉表现力、信息密度和专业度方面存在不足。本需求对电平表卡片进行全面 UI 优化，使其达到专业音频工具的标准。

## 优化项清单

### 1. 卡片内部布局优化

**问题**：64px 宽度内内容填充率 95%，无呼吸空间；底部仅 8px 无法放置峰值数值。

**方案**：

| 属性 | 当前值 | 优化值 |
|------|--------|--------|
| 卡片宽度 | 64px | 80px |
| 左右内边距 | ~1.5px（居中计算残余） | 6px |
| topPadding | 28px | 24px |
| bottomPadding | 8px | 28px（容纳峰值数值） |
| barWidth | 14px | 12px |
| barGap | 3px | 4px |
| labelAreaWidth | 24px | 20px |

**目标布局**：
```
┌─── 80px ────────────┐
│  6px padding         │
│                      │
│   L      R           │  ← 通道标签区 (12px)
│   ─      ─           │  ← 4px 间距
│  ┃▓▓┃  ┃▓▓┃         │
│  ┃▓▓┃  ┃▓▓┃         │  ← 电平条区 (flex)
│  ┃░░┃  ┃░░┃         │     分段 LED 风格
│  ┃░░┃  ┃░░┃         │
│   ─      ─           │  ← 4px 间距
│   -12.3 dB           │  ← 峰值数值 (14px)
│                      │
│  6px padding         │
└──────────────────────┘
  dB 刻度在左侧
```

**验收**：
- [ ] 卡片宽度从 64px 调整为 80px（同步修改 `MainWindowView.swift` 中 `levelMeterWidth` 常量）
- [ ] 内容填充率 ≤ 80%，视觉上有明显呼吸空间
- [ ] 底部有足够空间显示峰值数值

---

### 2. L/R 标签区分度

**问题**：L/R 标签字号 8px、透明度 0.6，与电平条间距仅 3px，视觉区分度不足。

**方案**：
- 字号从 8px 提升到 9px
- 字重从 `.medium` 提升到 `.semibold`
- 透明度从 0.6 提升到 0.75
- 标签与电平条顶部间距从 3px 增加到 6px
- L 标签使用 `onSurface` 颜色，R 标签使用 `onSurfaceVariant` 颜色（微妙区分）

**验收**：
- [ ] L/R 标签在正常使用距离（50cm）下清晰可辨
- [ ] 标签与电平条之间有明确的视觉间隔

---

### 3. dB 刻度位置与密度

**问题**：
- 刻度仅 5 级（0, -6, -12, -24, -48），缺少 -3dB 临界点
- 刻度文字字号 8px、透明度 0.45，可读性差
- maxDB 设为 +6 导致 0dB 不在顶端，用户困惑

**方案**：
- 增加 `-3dB` 刻度（clipping 临界点，专业用户关注）
- 将 `maxDB` 从 6 改为 0（0dB = 顶端，更直观）
- 刻度文字透明度从 0.45 提升到 0.55
- 0dB 刻度使用红色标注（警示色）
- 完整刻度序列：`[0, -3, -6, -12, -24, -48]`

**验收**：
- [ ] 0dB 位于电平条顶端
- [ ] -3dB 刻度可见且位置正确
- [ ] 0dB 刻度文字为红色（`#EF4444`）
- [ ] 其余刻度文字可读性良好

---

### 4. 峰值数值显示

**问题**：设计规范要求底部显示当前峰值数值（如 `-12.3 dB`），但当前实现缺失。

**方案**：
- 在电平条下方 `bottomPadding` 区域绘制当前峰值 dB 值
- 格式：`-XX.X`（保留一位小数）
- 字体：`monospacedDigitSystemFont` 9px
- 颜色：根据电平动态变化
  - 正常（< -6dB）：`onSurfaceVariant`
  - 偏高（-6 ~ -3dB）：`#F59E0B`（黄色）
  - 危险（> -3dB）：`#EF4444`（红色）
- 显示 L/R 中较高的峰值
- 更新频率：跟随电平刷新（~60fps）

**验收**：
- [ ] 底部显示实时峰值 dB 数值
- [ ] 数值格式为 `-XX.X` 带一位小数
- [ ] 颜色随电平动态变化（绿/黄/红）
- [ ] 使用等宽数字字体，数字变化时不抖动

---

### 5. 峰值保持线衰减

**问题**：当前峰值保持线存在但衰减参数不够专业（`peakHoldTime=1.2s`, `peakDecayRate=0.025`）。

**方案**：
- `peakHoldTime` 从 1.2s 调整为 1.5s（设计规范值）
- 峰值线宽度从 1.2px 调整为 2px（设计规范值）
- 峰值线颜色：白色 85% → 根据峰值位置动态着色
  - 绿区峰值：白色 80%
  - 黄区峰值：`#F59E0B` 90%
  - 红区峰值：`#EF4444` 100%
- 衰减曲线：保持期结束后使用 easeOut 缓动（非线性衰减），视觉更自然

**验收**：
- [ ] 峰值保持线宽度为 2px
- [ ] 保持时间为 1.5s
- [ ] 峰值线颜色随位置动态变化
- [ ] 衰减过程平滑自然（非线性）

---

### 6. 颜色渐变层次（分段 LED 风格）

**问题**：当前为连续渐变填充，缺乏视觉节奏感，不符合工业风设计语言。

**方案**：
- 将连续渐变改为**分段 LED 条**风格
- 每段高度：3px
- 段间间隔：1px（使用背景色透出）
- 颜色分段：
  - 0% ~ 60%：绿色 `#22C55E`
  - 60% ~ 80%：黄色 `#F59E0B`
  - 80% ~ 95%：橙色 `#F97316`
  - 95% ~ 100%：红色 `#EF4444`
- 未填充段：`white @ 0.04`（微弱可见的背景段）
- 已填充段：对应颜色 100% 不透明

**验收**：
- [ ] 电平条呈现分段 LED 效果（非连续渐变）
- [ ] 每段 3px 高，1px 间隔
- [ ] 四色分段清晰可辨（绿/黄/橙/红）
- [ ] 未填充区域有微弱的段落轮廓可见
- [ ] 视觉上符合工业风/专业音频工具风格

---

### 7. Clip 指示器

**问题**：当电平超过 0dB（满量程）时，缺少明确的失真警告。

**方案**：
- 在电平条顶部添加 Clip 指示器区域（6×6px 方块）
- 触发条件：电平 ≥ 0dB（`level >= 1.0`）
- 触发后行为：
  - 方块变为红色 `#EF4444` 100%
  - 保持亮起 3 秒（即使电平已回落）
  - 3 秒后自动熄灭
- 点击 Clip 指示器可手动复位（清除 clip 状态）
- 未触发时：暗红色 `#EF4444 @ 0.15`（微弱可见）

**验收**：
- [ ] 电平条顶部有 Clip 指示方块
- [ ] 电平超标时方块亮红
- [ ] 亮起后保持 3 秒
- [ ] 点击可手动复位
- [ ] 未触发时有微弱的暗红色轮廓

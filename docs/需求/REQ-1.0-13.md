## 功能描述

准备 App Store 提交所需的所有材料和配置。

---

## 准备清单

### 必需材料
- [ ] App 截图（多尺寸）
- [ ] App 描述（中/英文）
- [ ] 关键词（ASO 优化）
- [ ] 隐私政策 URL
- [ ] App 图标（1024x1024）
- [ ] 分类选择（工具类）

### 审核要点
- [ ] 隐私描述完整（麦克风+系统音频用途说明）
- [ ] 功能完整可用（无占位/空页面）
- [ ] 无私有 API 调用
- [ ] 沙盒权限正确配置
- [ ] 最低版本标注（macOS 14.4+）

### 付费策略（V1.0）
- V1.0 上线时**完全免费**（无任何限制）
- 目的：积累初始用户和口碑、收集反馈、降低审核复杂度

---

## 验收标准

| # | 标准 | 通过条件 |
|---|------|----------|
| 1 | 截图 | 各尺寸截图清晰、展示核心功能 |
| 2 | 描述 | 中英文描述准确、吸引人 |
| 3 | 隐私政策 | 隐私政策 URL 可访问、内容合规 |
| 4 | 沙盒 | 沙盒权限配置正确 |
| 5 | 提交 | 可通过 App Store Connect 提交 |

---

## 风险

- App Store 首次审核被拒概率较高
- 预留 2-3 次提交周期（每次 1-3 天）
- 常见拒绝原因：隐私描述不全、功能不完整

- 所有 V1.0 功能开发完成
- 隐私政策页面（需要域名）

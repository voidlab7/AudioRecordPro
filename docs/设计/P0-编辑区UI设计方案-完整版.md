<a id="设计目标"></a>
## 一、设计目标

### 1.1 核心目标

从当前"单轨波形查看器"升级为"多轨道 Clip 式音频编辑器"。

| 当前状态 | 目标状态 |
|---------|---------|
| 单轨道显示 | 多轨道层叠 |
| 整段音频操作 | Clip 片段化操作 |
| 柱状离散波形 | 填充连续波形 |
| 按钮式编辑 | 直接拖拽式编辑 |
| 侧边属性面板缺失 | 右侧属性面板 |

### 1.2 竞品对标

```
剪映音频编辑区特征（从参考图提取）：
├── 左侧面板：素材库（已导入素材列表）
├── 中央区域：多轨道时间线
│   ├── 轨道头（左侧）：图标 + M/S 按钮 + 轨道名称
│   ├── 轨道内容（右侧）：Clip 填充波形 + 播放头
│   └── 多轨道层叠显示
├── 右侧面板：属性面板
│   ├── 音量滑块
│   ├── 淡入时长滑块
│   ├── 淡出时长滑块
│   └── 其他音频效果
└── 底部：播放器预览（视频编辑需要，音频可简化）

AudioRecord Mac 适配：
├── 保留：左侧 Sidebar（录制/文件切换）
├── 改造：中央波形区 → 多轨道时间线
├── 新增：右侧属性面板
└── 简化：无需视频预览
```

### 4.3 P0-3: Fade 可视化

**Fade 拖柄交互**:

```
拖拽 Fade-in 拖柄向左 → 增加淡入时长
拖拽 Fade-in 拖柄向右 → 减少淡入时长

淡入区域波形渲染：
  透明 → 半透明 → 全不透明
  0%    →   50%  →   100%
```

**实时预览**：拖拽时只改变 overlay 透明度，不修改 PCM 数据。

<a id="交互细节"></a>
## 六、交互细节

### 6.1 鼠标/触控板交互

| 操作 | 效果 |
|------|------|
| 单击 Clip | 选中，显示选中边框 |
| 拖拽 Clip | 在时间线上移动位置 |
| 拖拽边缘拖柄 | 裁剪 Clip 起始/结束时间 |
| 拖拽 Fade 拖柄 | 调整淡入/淡出时长 |
| 单击时间尺 | Seek 播放头位置 |
| 拖拽播放头 | Scrub 播放（实时出声）|
| Cmd+Scroll | 缩放时间轴 |
| 横向 Scroll | 平移时间轴 |

### 6.2 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Space` | 播放/暂停 |
| `S` | Split（在播放头处切分）|
| `I` | 设置入点（选区开始）|
| `O` | 设置出点（选区结束）|
| `⌘X` | 剪切选中 Clip |
| `⌘C` | 复制选中 Clip |
| `⌘V` | 粘贴 Clip |
| `⌘Z` | 撤销 |
| `⇧⌘Z` | 重做 |
| `Delete` | 删除选中 Clip |

### 6.3 多轨道交互

- **Solo 模式**: 点击 Solo 按钮，只播放该轨道，其他轨道静音
- **Mute 模式**: 点击 Mute 按钮，该轨道静音
- **多选**: Cmd+单击 可同时选中多个 Clip

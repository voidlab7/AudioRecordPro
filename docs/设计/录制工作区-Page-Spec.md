## 一、页面定位

录制工作区是 AudioRecord 的**首屏**和**核心工作区**。用户打开 App 后看到的第一个界面。

**核心任务**：让用户以最少操作开始录制，并在录制完成后无缝切换到编辑态。

**设计原则**：
1. 录制优先 — 录制按钮是视觉焦点，不是文件列表或编辑工具
2. 两态清晰 — 空闲态 vs 录制态 vs 编辑态（录完后）视觉上明确区分
3. 信息密度适中 — 录制状态、目标、波形、电平、计时器清楚即可

## 十一、状态流转

### 录制工作区状态机（REQ-2.0-05 变更）

```
┌─────────┐     点击 Record     ┌───────────┐
│  Idle   │ ──────────────────→ │ Recording │
```

### 各状态 UI 差异

| 元素 | Idle | Recording | Editing（编辑器视图） |
|------|------|-----------|---------------------|
| 视图 | 录制工作区 | 录制工作区 | **EditorViewController** |

## 十二、交互规范

### 录制流程

1. 用户选择音源（Sidebar 或 TitleBar 下拉）
2. 点击 Record 按钮
3. 权限检查（首次需要授权）
4. 录制开始：波形实时滚动、计时器递增、电平表活跃
5. 点击 Stop → 录制停止
6. **自动进入编辑器**：cross-dissolve 动画（200ms）→ EditorViewController 加载完整波形
7. 用户可在编辑器中播放/裁剪/导出，或点击「← 返回」回到录制态

### 快捷键

| 快捷键 | 功能 | 条件 |
|--------|------|------|
| `Cmd+R` | 开始/停止录制 | 非编辑器模式 |
| `Space` | 播放/暂停 | 有文件时 |
| `Cmd+E` | 导出 | 有文件时 |
| `Cmd+,` | 设置 | 始终可用 |

### 拖放支持

- 从 Finder 拖入音频文件 → 自动导入并进入编辑态
- 从文件列表拖出 → 导出到目标位置

## 十四、与编辑工作区的切换（REQ-2.0-05 更新）

### 进入编辑器

触发方式：
- **录制停止后自动进入**（零操作，直接 cross-dissolve 过渡）
- 文件列表中 hover 出现编辑按钮 → 点击
- 文件列表双击文件
- 从 Finder 拖入音频文件

### 退出编辑器

触发方式：
- 编辑器导航栏「← 返回」按钮
- `Cmd+R` 快捷键（退出编辑器并开始新录制）
- 侧边栏切换音源（自动退出编辑器）

### 切换动画

```
录制工作区 → 编辑器:
  recordingContentView 隐藏
  editorView cross-dissolve 淡入 (200ms easeOut)

编辑器 → 录制工作区:
  editorView 移除
  recordingContentView 淡入 (200ms easeOut)
```

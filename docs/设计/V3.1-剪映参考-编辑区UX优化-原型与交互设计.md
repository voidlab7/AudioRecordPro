## 一、现状审计与剪映差距分析

### 1.1 现状问题（代码证据，v1.1 审计）

| # | 问题 | 代码证据 | 影响 |
|---|------|---------|------|
| P1 | 三层同色 | `TrackContainerView` = #1B1B1F，`EditorWaveformView` = #1B1B1F，完全相同 | 轨道区和波形区融为一体 |
| P2 | 轨道头存在感弱 | `headerView` = #2A2A2E 仅高 1 级 + 0.5px border | 几乎察觉不到独立区域 |
| P3 | 无音频段卡片 | 波形直接画在底色上，`clipColor` 0.3 alpha 2px 描边 | 没有"卡片悬浮在轨道上"的感觉 |
| P4 | ruler 沉底 | ruler 在 `waveformRect.maxY + 2`（视图底部） | 不符合从上到下阅读习惯 |

### 1.2 与剪映的正面对比

| 维度 | 剪映 | 当前 AudioRecord | 差距 |
|------|------|-----------------|------|
| 时间标尺位置 | **顶部** | 底部 | 完全反了 |
| 标尺独立性 | **独立色带条** | 与波形区融合 | 无独立背景 |
| 轨道背景 | **每轨一块通栏板（空轨也有）** | 与窗口同色 | 无轨道概念 |
| 轨道头 | **明显独立区域** | 几乎不可区分 | 色差不足 |
| 音频段 | **深色卡片 + 白色半透明边框 + 浮在板上** | 直接画在底色上 | 无卡片概念 |
| Clip 名称 | **覆盖式 chip 叠在波形上** | 独立名称行占位 | 纵向空间浪费 |
| 波形 | **双色调（亮峰 + 实体填充）** | 单色均匀填充 | 峰值读感弱 |
| 工具栏 | **单行，主区仅 split+delete，次要进 ⋮** | 两排平铺 | 密度与分组 |
| dB 尺 | **虚线参考线 + L/R 底部电平条** | 仅录制区有 | 编辑区缺失 |

## 二、设计策略：学什么、不学什么

### 2.1 学剪映的 8 件事（v1.5 汇总）

1. **时间尺置顶独立色带** — ruler 是"框架"的一部分（P4 修复）
2. **L 型框架** — ruler 色带 + 轨道头列同色 #2A2A2E，围出内容区
3. **轨道背景板** — 每条轨道一块板，空轨道也有板（v1.3）
4. **Clip 即卡片** — 圆角色块 + 白色半透明边框 + 浮在板上（P3 修复）
5. **名称 chip 覆盖** — Clip 名称是叠在波形上的深色半透明 chip，不占独立行（v1.5）
6. **双色调波形** — 实体填充 + 亮峰包络，峰值一眼可读（v1.5）
7. **工具栏克制** — 单行；主区仅高频工具（切分/删除），次要进 ⋮ 溢出菜单（v1.2+v1.5）
8. **磁铁吸附** — 总开关 + 参考线，拖拽"咔哒"感

### 2.2 不学剪映的 4 件事

1. 不做视频预览窗 — 纯音频工具
2. 不做素材库面板 — 已有"文件"Tab 承担
3. 不做轨道锁定/可见性 — 轻编辑定位（"轻编辑非 DAW"），M/S 已够
4. 不引入亮蓝 Clip 色 — Clip 卡片用中性深色 #2A2A2E，波形保持珊瑚橙 #E87850 品牌色

### 2.3 设计红线（继承设计规范 §10，两处受控豁免）

- 面板 3 级背景色（#1B1B1F/#2A2A2E/#363638）+ **内容层 2 级**（轨道板 #232327 / Clip 卡片 #2A2A2E+边框）
- 圆角只用 6/10/14 三档；无阴影；发光仅录制按钮与计时器；等宽数字用于一切时间/dB 数值
- ⚠️ **受控豁免 1**：Clip 卡片允许 1px 白色半透明边框（内容对象非面板）
- ⚠️ **受控豁免 2**：轨道背景板 #232327 为内容层半档步进色（L0→L2 之间），不占面板 3 级名额

## 三、四层视觉层次模型（核心）

### 3.1 模型

```
Z 轴自下而上：

L0 面板底（窗口）          #1B1B1F  ── 最暗底，板外边距/缝隙透出的颜色
L1 轨道背景板              #232327  ── 每条轨道一块板（v1.5：6px 圆角 + 外边距）
   ├─ 内容层第 1 级，比 L0 亮半档（ΔL≈4.5%）
   ├─ 外边距形成板间缝隙，透出 L0
   └─ 空轨道 = 空板 + 居中引导文案
L2 L 型框架（ruler+轨道头） #2A2A2E  ← 高 1 级，"浮起来"的参考系
   ├─ 时间尺色带（顶部 24px，底部 1px 分割线）
   ├─ 轨道头列（左 80px，右缘 1px 竖分割线 + 4px 轨道色条）
   └─ 角部单元（ruler 与轨道头交汇处，同色补齐）
L3 Clip 卡片               #2A2A2E + 1px white@15% 边框（内容层第 2 级）
   ├─ 默认：white @15% 边框；hover @25%
   └─ 选中：white @40% 边框（剪映式，不用填充变色）
```

**为什么 L2 和 L3 同底色不会混？**
- L3 被 L1（更暗的轨道板）四面包围，对比产生"浮起"感
- L3 有 1px 白色半透明边框，L2 无边框，边界一眼可辨
- 这正是剪映的做法：Clip 浮在轨道板上，ruler/轨道头同色框架

### 3.2 色彩分配总表

| 层 | 区域 | 颜色 | 分隔手段 |
|----|------|------|---------|
| L0 | 窗口底/走带栏/状态栏 | `#1B1B1F` | 走带栏/状态栏顶部 1px `outlineVariant` |
| L1 | 轨道背景板 | `#232327` | 6px 圆角 + 外边距透 L0（v1.5） |
| L2 | 时间尺色带 | `#2A2A2E` | 底部 1px `outlineVariant` 横线 |
| L2 | 轨道头 | `#2A2A2E` | 右缘 1px `outlineVariant` 竖线 + 左缘 4px 轨道色条 |
| L2 | 角部单元 | `#2A2A2E` | 无（与 ruler/轨道头融为一体） |
| L3 | Clip 卡片 | `#2A2A2E` | **1px white @15% 边框**（受控豁免） |
| L3 | Clip 选中 | `#2A2A2E` | **1px white @40% 边框** |
| — | 右缘 dB 尺 | `#1B1B1F` | 左缘 1px `outlineVariant` 竖线 |
| — | 编辑器 Sidebar | `#2A2A2E` | 右缘 1px `outlineVariant` 竖线（SplitView 分割） |

> **层次自检**：任意相邻区域，要么色差 ≥ 半级，要么有且仅有 1px `outlineVariant` 分隔线，要么（仅 Clip）有白色内容边框。不允许"同色无线"相邻。

## 五、组件级原型规格

```
┌──────────────────────────────────────────────────────────────────────────┐
```

### 5.4 轨道背景板（v1.3 新增 + v1.5 圆角卡片化）

> **剪映证据**：每条轨道一块板，空轨道也有板；板有**圆角**且与边缘有小外边距，呈卡片状而非全通栏。

| 项 | 规格 |
|----|------|
| 背景 | `trackPlateBg` #232327（内容层第 1 级，半档步进） |

## 六、交互图 · 核心流程

### 6.1 录制 → 编辑流转

```
┌─────────┐  点击●   ┌──────────┐  点击■停止  ┌──────────────┐
│  idle   │ ───────► │ recording │ ─────────► │ 编辑工作区    │
└─────────┘          └──────────┘            └──────────────┘
     ▲                       过渡（200ms easeOut）：            │
     └────────── ◀返回 ───── 编辑区 translateY(24px)→0 淡入 ────┘
              （有未保存改动时弹确认：保存/放弃/取消）
```

### 6.2 切分（Split）

播放头定位 → 按 S / 点切分 → 切分线 120ms 白色闪烁 → 两 Clip 各自独立边框+拖柄，间距 2px；播放头不在 Clip 内时按钮禁用 + tooltip；↩ 一步撤销。

### 6.3 Fade 拖拽

悬停（光标 `arrowLeftRight`，拖柄 60%→100%）→ 拖拽（仅改 overlay 不动 PCM，fade 区波形 alpha 渐变，气泡实时显示秒数）→ 松手吸附 0.1s 步进写入编辑栈。范围 0 ~ min(5s, Clip/2)；淡入淡出重叠时气泡变琥珀色警示；与属性面板滑块双向同步。

### 6.4 Trim 拖拽 + 磁铁吸附

| 吸附目标 | 触发 | 视觉 |
|---------|------|------|
| 播放头 | ≤6px | 白色竖参考线（white @40%）贯穿轨道 |
| Clip 边界 | ≤6px | 同上 |
| 选区边界 | ≤6px | 同上 |
| 零点/末尾 | ≤8px | 同上 |

- 吸附后需反向拖出 >10px 才脱离；🧲 OFF 时全部自由拖拽
- 拖拽中已裁剪区显示 25% alpha 幽灵波形 + 时间气泡

### 6.5 选区

拖拽创建 → 选区外遮罩 #1B1B1F @50% → 边缘 ±6px 可调（同吸附规则）；双击 = 全选 Clip；Esc/点空白 = 取消；Delete = 删除选区内容（可撤销）；状态栏同步选区信息。

### 6.6 缩放与导航

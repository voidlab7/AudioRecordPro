## 一、页面定位

设置页是 AudioRecord 的**独立偏好设置窗口**，通过 `Cmd+,` 或菜单栏打开。

**核心任务**：让用户配置录制参数（格式、采样率、存储位置）和应用行为（开机启动）。

**设计原则**：
1. macOS 标准 — 遵循 macOS HIG 偏好设置窗口惯例
2. 即时生效 — 设置变更立即生效，无需"保存"按钮
3. 最小化 — 只暴露用户真正需要调整的选项，不堆砌

---

## 二、窗口规范

### 窗口属性

| 属性 | 值 |
|------|-----|
| 尺寸 | 480×320px |
| 样式 | `.titled` + `.closable` (无 resize, 无 minimize) |
| 标题 | "设置" |
| 外观 | `.darkAqua` (强制深色) |
| 位置 | 屏幕居中 |
| 行为 | 非模态, 关闭不销毁 (singleton) |

### 背景

- 颜色：`surface` (#0E1416) — 与主窗口一致的深色背景
- 无网格纹理（设置页不需要工业感装饰）

## 五、设置项规范

### 录制格式

| 选项 | 值 | 说明 |
|------|-----|------|
| M4A (AAC) | `"m4a"` | 默认，压缩格式，文件小 |
| WAV (PCM) | `"wav"` | 无损格式，文件大，音质最佳 |

- 存储 Key：`recordingFormat`
- 默认值：`"m4a"`
- 变更通知：`Notification.Name.settingsChanged`

### 采样率

| 选项 | 值 | 说明 |
|------|-----|------|
| 44100 Hz | `44100` | CD 质量 |
| 48000 Hz | `48000` | 默认，专业音频标准 |

- 存储 Key：`sampleRate`
- 默认值：`48000`
- 变更通知：`Notification.Name.settingsChanged`

### 存储位置

- 存储 Key：`recordingsDirectory`
- 默认值：`~/Documents/AudioRecord/Recordings/`
- 选择方式：`NSOpenPanel` (仅目录)
- 变更通知：`Notification.Name.settingsChanged`

### 开机自动启动

- 存储 Key：`launchAtLogin`
- 默认值：`false`
- 实现：`SMAppService.mainApp.register()` (macOS 13+)

## 六、交互规范

### 打开方式

| 触发 | 行为 |
|------|------|
| `Cmd+,` | 打开设置窗口 |
| 菜单栏 → AudioRecord → 设置... | 打开设置窗口 |

### 设置变更行为

- **即时生效**：所有设置变更立即写入 UserDefaults 并发送通知
- **无保存按钮**：遵循 macOS 偏好设置惯例
- **无取消按钮**：关闭窗口即可

### 存储位置选择

1. 点击"更改…"按钮
2. 弹出 NSOpenPanel（仅目录选择）
3. 用户选择目录 → 路径更新 → 通知发送
4. 用户取消 → 无变化

## 七、五态覆盖

| 状态 | 场景 | 视觉表现 |
|------|------|---------|
| **Loading** | 不适用（设置页无异步加载） | — |
| **Empty** | 不适用（始终有默认值） | — |
| **Error** | 开机启动注册失败 | 日志记录，不显示 UI 错误（静默失败） |
| **Populated** | 正常状态 | 所有控件显示当前值 |
| **Edge** | 存储路径不存在/无权限 | 路径标签显示红色，提示用户重新选择 |

## 十、与 DESIGN.md 的关系

设置页是 AudioRecord 中**最接近系统原生**的页面：
- 使用系统原生控件（NSPopUpButton, NSButton checkbox）
- 不使用自定义 Industrial 控件
- 背景色使用 `surface` 保持一致性
- 字体使用系统字体（与 Industrial 字体系统一致，因为 Industrial 就是系统字体）

**设计决策**：设置页不需要"工业感"，因为它是系统级偏好设置窗口，用户期望看到标准 macOS 体验。工业风格保留给主工作区。

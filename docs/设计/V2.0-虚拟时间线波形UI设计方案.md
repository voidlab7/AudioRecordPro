# V2.0 虚拟时间线波形 UI 设计方案

> 作者：绘·设计师 | 日期：2026-05-20 | 模式：Build
> 基于：REQ-2.0-03 剪映式虚拟时间线波形展示 + 矩·架构技术方案 + IndustrialDesignTokens 设计体系
> 范围：tile 加载状态视觉、LOD 切换过渡、skeleton 样式、fallback 弱化、波形绘制规范、时间标尺、overlay 层级

---

## 一、设计决策总览

### SAFE / RISK 分层

```
SAFE CHOICES（品类基线）
  ✅ 波形柱状图 + 中线对称绘制（Logic Pro / Audacity / 剪映 共识）
  ✅ 时间标尺在波形区顶部或底部（DAW 行业标准）
  ✅ 播放头贯穿垂直线 + 顶部三角手柄（剪映/Final Cut 共识）
  ✅ 选区拖柄 + 区域外遮罩暗化（裁剪类工具标准）
  ✅ Cmd+滚轮缩放 / 横向滚动浏览（macOS 平台共识）
  ✅ 加载中显示骨架屏/占位（现代 App 加载态共识）

RISKS（产品获得自己面孔的地方）
  🔶 低 LOD fallback 淡化显示而非替换
     → 收益：避免波形跳变（US-04），用户不会误判剪辑点
     → 代价：需要两层绘制（fallback 底层 + 目标 LOD 顶层）
     → 判断：值得——剪映/Logic Pro 均采用类似策略
  🔶 skeleton 使用条纹动画而非静态灰块
     → 收益：用户明确感知"正在加载"，不会误以为无声音
     → 代价：动画性能开销（极小，CSS 级）
  🔶 大文件首次打开显示"录音过大"提示改为渐进式加载
     → 收益：用户不再看到截图中的"录音过大，已跳过编辑器加载"红色警告
     → 代价：需要设计加载进度的视觉反馈
```

## 二、核心问题：当前大文件体验

### 现状（截图所示）

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│        录音过大，已跳过编辑器加载，避免应用无响应            │  ← 红色警告文字
│                                                            │
└────────────────────────────────────────────────────────────┘
```

**问题：**
- 用户看到红色警告 → 感知为"App 不行"，而非"文件太大"
- 完全阻断了编辑器入口 → 用户无法对长录音做任何操作
- 没有渐进式降级 → 要么全量加载，要么完全不加载

### 目标体验

```
┌────────────────────────────────────────────────────────────┐
│  ← 返回    Recording-2h-meeting.wav    ✂️ 🔊 📊 ↩️ ↪️      │  ← 导航栏
├────────────────────────────────────────────────────────────┤
│  0:00    0:30    1:00    1:30    2:00                      │  ← 时间标尺
│  ┃▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓┃ │  ← 波形（tile 绘制）
│  ┃▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓┃ │
│  ┃▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓┃ │
│  ▼ 播放头                                                  │
├────────────────────────────────────────────────────────────┤
│              ▶ 播放    ■ 停止                              │  ← 工具栏
├────────────────────────────────────────────────────────────┤
│  时长: 2:03:45 | 采样率: 48kHz | 声道: 立体声 | 大小: 1.2GB │  ← 状态栏
└────────────────────────────────────────────────────────────┘
```

**关键变化：** 大文件不再被拒绝，而是渐进式加载波形 tiles，用户立即可以操作。

## 三、波形绘制视觉规范

### 3.1 波形柱样式

延续 V1.1 编辑器已有的 Industrial 风格波形柱：

| 属性 | 值 | 说明 |
|------|-----|------|
| 柱宽 | 1.2px | `barWidth` |
| 柱间距 | 2.2px（含柱宽） | `barSpacing` |
| 圆角 | 0.6px | 微圆角，工业感 |
| 颜色 | `IndustrialColors.waveformCoral` | 珊瑚红 |
| 绘制方式 | 中线对称，min/max 上下振幅 | 不再是单向 abs() |
| 绘制高度 | 波形区高度 × 0.82 | 留出标尺和引导文字空间 |

### 3.2 振幅映射（min/max 双向）

**V1.1（旧）：** 只有 `abs(sample)` → 单向振幅
**V2.0（新）：** `peak.min`（负向）和 `peak.max`（正向）→ 双向振幅

```
                    peak.max
                      ↑
         ┃           ┃
         ┃     ┃     ┃  ┃
    ─────┃─────┃─────┃──┃──── 中线 (centerY)
         ┃     ┃     ┃  ┃
         ┃           ┃
                      ↓
                    peak.min
```

**视觉效果：** 波形更真实，能看出正负相位差异，精细编辑时更有参考价值。

### 3.3 透明度规则

| 状态 | alpha 计算 | 效果 |
|------|-----------|------|
| 选区内 | `max(0.34, min(1.0, 0.34 + level × 0.66))` | 强调，振幅越大越实 |
| 选区外 | `max(0.15, min(0.4, 0.15 + level × 0.25))` | 弱化，但仍可辨识 |
| Fallback（低 LOD） | 在上述基础上 × 0.4 | 明显弱化，标记为"非最终精度" |

## 四、加载状态设计（五态覆盖）

### 状态覆盖矩阵

| 状态 | 触发条件 | 视觉表现 | 持续时间 |
|------|---------|---------|---------|
| **Loading** | 文件刚打开，tile 尚未就绪 | Skeleton 条纹动画 | 首屏 tile 就绪前 |
| **Fallback** | 目标 LOD 未加载，低 LOD 有缓存 | 低 LOD 淡化绘制 (alpha 0.4) | 目标 LOD 就绪前 |
| **Populated** | 目标 LOD tiles 已加载 | 正常波形绘制 | 常态 |
| **Error** | tile 生成失败 | 该区域显示错误占位 | 直到重试成功 |
| **Empty** | 文件为空或无法读取 | "无法读取音频数据" 文字 | 永久 |

### 4.1 Skeleton 状态

tile 尚未就绪时，显示条纹动画骨架屏：

```
┌────────────────────────────────────────────────────────────┐
│  0:00    0:30    1:00    1:30    2:00                      │
│                                                            │
│  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │  ← 条纹动画
│  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │
│  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │
│                                                            │
│                    加载波形中...                             │  ← 居中提示文字
└────────────────────────────────────────────────────────────┘
```

**视觉规范：**

| 属性 | 值 |
|------|-----|
| 条纹颜色 | `IndustrialColors.surfaceContainer` 与 `surfaceContainerLow` 交替 |
| 条纹方向 | 45° 斜线 |
| 条纹宽度 | 8px |
| 动画 | 从左到右平移，周期 1.5s，`ease-in-out` |
| 条纹区域 | 波形绘制区（`waveformRect`） |
| 提示文字 | `IndustrialTypography.body`，`IndustrialColors.textTertiary` |
| 提示位置 | 波形区垂直居中 |

### 4.2 Fallback 状态（低 LOD 淡化）

目标 LOD 未就绪但低 LOD 有缓存时，先绘制低精度波形作为占位：

```
┌────────────────────────────────────────────────────────────┐
│  0:00    0:30    1:00    1:30    2:00                      │
│                                                            │
│  ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃ │  ← 低 LOD 波形
│  ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃ │     alpha 0.4
│  ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃ │     柱间距更大
│                                                            │
└────────────────────────────────────────────────────────────┘
```

**视觉规范：**

| 属性 | 值 | 说明 |
|------|-----|------|
| 整体 alpha | 0.4 | 明显弱于正常波形 |
| 柱宽 | 与正常相同 (1.2px) | 保持一致 |
| 柱间距 | 由 LOD 数据密度决定 | 低 LOD 数据稀疏，柱间距自然更大 |
| 颜色 | `IndustrialColors.waveformCoral` | 同色系，仅透明度区分 |
| 过渡 | 目标 LOD 就绪后，fallback 淡出 (150ms) | 避免跳变 |

**关键设计原则：** 低 LOD fallback 不是"错误的波形"，而是"低精度预览"。用户应能感知到"这还不是最终精度"，但不会被误导。

### 4.3 Fallback → Populated 过渡动画

当目标 LOD tile 就绪时，从 fallback 过渡到正常显示：

```
时间线:
  0ms        → fallback 波形 (alpha 0.4)
  tile 就绪  → 目标 LOD 波形淡入 (alpha 0 → 1.0, 150ms ease-out)
              → fallback 波形同时淡出 (alpha 0.4 → 0, 150ms)
  150ms 后   → 仅显示目标 LOD 波形
```

**注意：** 不是"替换"，是"叠加淡入"。这避免了 US-04 描述的"粗到细跳变"。

### 4.4 Error 状态

单个 tile 生成失败时，仅该区域显示错误占位：

```
┌────────────────────────────────────────────────────────────┐
│  ┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃  ⚠️  ┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃ │
│  ┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃      ┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃ │
│  正常波形区域          失败区  正常波形区域                   │
└────────────────────────────────────────────────────────────┘
```

**视觉规范：**

| 属性 | 值 |
|------|-----|
| 错误区域背景 | `IndustrialColors.surfaceContainerLow` (不变) |
| 错误图标 | `⚠️` 或 SF Symbol `exclamationmark.triangle`，12pt |
| 图标颜色 | `IndustrialColors.error` alpha 0.5 |
| 图标位置 | 该 tile 时间范围的水平中心，波形区垂直中心 |
| 不影响 | 其他 tile 正常绘制，播放头/选区正常穿过 |

## 五、时间标尺设计

### 5.1 标尺位置

时间标尺位于波形区**底部**（`waveformRect.maxY` 上方），与 V1.1 保持一致。

### 5.2 自适应刻度

标尺刻度根据 `pixelsPerSecond` 自动调整步长：

| pixelsPerSecond | 主刻度步长 | 子刻度 | 标签格式 | 适用场景 |
|---:|---:|---:|---|---|
| > 200 | 0.1s | 5 个 | `M:SS.mmm` | 秒级编辑 |
| 50~200 | 0.5s | 5 个 | `M:SS` 或 `M:SS.s` | 精细定位 |
| 15~50 | 2s | 4 个 | `M:SS` | 常规浏览 |
| < 15 | 5s/10s/30s | 5 个 | `M:SS` | 全局概览 |

### 5.3 标尺视觉

| 属性 | 值 |
|------|-----|
| 主刻度线高度 | 8px |
| 子刻度线高度 | 4px |
| 刻度线颜色 | `IndustrialColors.onSurfaceVariant` alpha 0.24 |
| 标签字体 | `NSFont.monospacedDigitSystemFont(ofSize: 9, weight: .regular)` |
| 标签颜色 | `IndustrialColors.textTertiary` alpha 0.68 |
| 中线 | 虚线 (3px dash, 3px gap)，`IndustrialColors.gridMedium` alpha 0.5 |

## 八、缩放与滚动交互设计

### 8.1 缩放交互

| 操作 | 行为 | 视觉反馈 |
|------|------|---------|
| Cmd + 滚轮上 | 放大（zoomLevel × 1.5） | 波形柱变密，LOD 可能切换 |
| Cmd + 滚轮下 | 缩小（zoomLevel / 1.5） | 波形柱变疏，LOD 可能切换 |
| 锚点 | 鼠标所在时间点 | 该时间点在缩放前后保持在鼠标位置 |

### 8.2 LOD 切换时的视觉过渡

缩放导致 LOD 切换时：

```
缩放前: LOD-2 (10 peaks/s) 正常显示
  ↓ 用户放大
缩放后: LOD-3 (50 peaks/s) 需要加载
  ↓ 过渡期
显示: LOD-2 数据淡化 (alpha 0.4) + skeleton 条纹叠加
  ↓ LOD-3 tiles 就绪
显示: LOD-3 正常绘制，LOD-2 淡出
```

**关键：** 缩放过程中不出现空白。始终有内容可看。

### 8.3 横向滚动

| 操作 | 行为 | 视觉反馈 |
|------|------|---------|
| 横向滚动 | `visibleStartTime` 平移 | 波形区内容平移 |
| 快速滚动 | 旧 tile 请求取消，新视口 tile 优先 | 可能短暂出现 skeleton |
| 滚动到边界 | `visibleStartTime` 不超出 `[0, totalDuration - visibleDuration]` | 弹性回弹（可选） |

### 8.4 预取策略的视觉影响

- 预取范围：视口左右各 `visibleDuration × 0.5`
- 预取区域的 tile 在后台静默加载，不显示 skeleton
- 用户滚动到预取区域时，tile 已就绪 → 无感加载

## 九、Overlay 层级规范

从底到顶的绘制顺序：

```
Layer 0: 背景色 (surfaceContainerLow)
Layer 1: 时间标尺 (刻度线 + 标签 + 中线)
Layer 2: 选区外遮罩 (editorDimOverlay)
Layer 3: 波形绘制
         ├── Skeleton (条纹动画) — 无 tile 时
         ├── Fallback (低 LOD, alpha 0.4) — 目标 LOD 未就绪时
         └── Normal (目标 LOD, 正常 alpha) — 就绪时
Layer 4: 播放头 (垂直线 + 三角手柄)
Layer 5: 选区拖柄 (左右拖柄 + 纹理)
Layer 6: 引导文字 (无选区时的操作提示)
Layer 7: Error 占位图标 (仅失败 tile 区域)
```

**规则：**
- 播放头和选区拖柄始终在波形之上
- Skeleton/Fallback/Normal 互斥，同一区域同一时刻只显示一种
- Error 图标在最顶层，确保可见

## 十、大文件首次打开体验流程

### 10.1 时间线

```
t=0ms     用户点击"编辑"按钮
  ↓
t=0ms     编辑器 UI 立即出现（导航栏 + 空波形区 + 工具栏 + 状态栏）
  ↓
t=50ms    波形区显示 skeleton 条纹动画 + "加载波形中..."
  ↓
t=100ms   状态栏显示文件元信息（时长/采样率/声道/大小）
  ↓
t=200ms~  LOD-0 概览 tiles 开始就绪
  ↓
t=500ms~  Fit All 视图下 LOD-0 全部就绪 → skeleton 淡出，波形淡入
  ↓
          用户可以开始滚动/缩放/播放
```

### 10.2 关键体验指标

| 指标 | 目标 | 说明 |
|------|------|------|
| 编辑器 UI 出现 | < 100ms | 框架立即渲染，不等待数据 |
| 首屏波形可见 | < 3s | LOD-0 概览 tiles 就绪 |
| 可交互 | < 3s | 滚动/缩放/播放头 seek 可用 |
| 精细波形就绪 | 按需 | 用户缩放到某区域后 1-2s 内 |

### 10.3 与 V1.1 短文件体验的对比

| 维度 | 短文件 (≤60s) | 长文件 (>60s) |
|------|--------------|--------------|
| 加载方式 | 全量 buffer → 一次性绘制 | tile 模式 → 渐进式绘制 |
| 首屏时间 | < 500ms | < 3s |
| 波形精度 | 固定（全局压缩） | 自适应（LOD 按缩放级别） |
| 加载提示 | "加载波形..." 文字 | Skeleton 条纹动画 |
| 用户感知 | 瞬间完成 | 渐进式出现 |

### 11.3 大文件仅查看模式

## 十四、给铸（开发）的设计交付物

### 交付清单

1. **本文档** — 视觉规范 + 状态设计 + 交互规则
2. **Token 列表** — 复用 + 新增（见第十二章）
3. **层级规范** — Overlay 绘制顺序（见第九章）
4. **状态机** — 五态覆盖 + 过渡动画时序（见第四章）

### 关键约束

- ⚠️ **Skeleton 必须是动画** — 不是静态灰块，用户需要感知"正在加载"
- ⚠️ **Fallback 必须淡化** — alpha 0.4，不能用正常透明度冒充最终波形
- ⚠️ **过渡必须平滑** — tile 就绪后淡入 150ms，不是瞬间替换
- ⚠️ **播放头/选区不受 tile 状态影响** — 始终正常绘制
- ⚠️ **不再显示"录音过大"红色警告** — 改为渐进式加载

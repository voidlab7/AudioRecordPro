# AudioRecord 设计规范 v3.0

> **唯一设计规范来源** — 参考剪映设计语言重新制定
> Category: macOS Native Audio Tool · Recording + Light Editing
> Design Language: Studio Dark — 层次分明、色差分层、无边框
> Token Source: `AudioRecordApp/Sources/Utilities/DesignTokens.swift`（待重构）
> 更新：2026-07-11 | 基于剪映 UI 截图逆向分析

## 1. 设计哲学

### 核心理念

AudioRecord 是 macOS 原生音频录制+轻编辑工具。视觉语言参考**剪映专业版**——干净、层次分明、克制。

**三个关键词：**
1. **色差分层**：用 3 级背景色做空间层次，而非边框线
2. **面板归属感**：每个功能区是一个整体"面"，内部元素属于这个面
3. **克制表达**：强调色仅用于选中态和录制状态，其余以灰度呈现

### 设计原则

1. **录制优先**：首屏核心任务是"开始录制"
2. **两态清晰**：录制工作区与编辑工作区视觉明确区分
3. **面板 > 边框**：用整块色面区分区域，不用碎线条切割
4. **对齐一致**：所有列表行高统一、间距统一、圆角统一
5. **层次克制**：最多 3 级背景色 + 1 级选中色，不堆砌
6. **轻编辑非 DAW**：不做复杂多轨混音

## 2. 色彩系统

### 背景色阶梯（3 层，核心）

整套界面只用 3 级背景色建立空间层次：

| Token | Hex | 用途 | 对标剪映 |
|-------|-----|------|---------|
| `bgDeepest` | `#1B1B1F` | 最深底色 — 轨道区、时间线背景、窗口底 | 剪映轨道区 |
| `bgPanel` | `#2A2A2E` | 面板色 — sidebar 整体、toolbar、控制面板、卡片 | 剪映左侧面板 |
| `bgElevated` | `#363638` | 抬升色 — hover 态、弹出层、active 容器 | 剪映素材卡片 hover |

**铁律：所有区域层次只靠这 3 级色差表达，不加边框线。**

### 补充背景色

| Token | Hex | 用途 |
|-------|-----|------|
| `bgOverlay` | `#424245` | Tooltip、Popover、Menu 背景 |
| `bgInput` | `#232326` | 输入框、搜索框内部（比面板暗一级） |

### 文本色

| Token | Hex | 用途 |
|-------|-----|------|
| `textPrimary` | `#E8E8EA` | 主文本 — 标题、文件名、数值 |
| `textSecondary` | `#A0A0A5` | 次要文本 — 描述、元数据、分区标题 |
| `textTertiary` | `#6B6B70` | 三级文本 — 占位符、禁用态、时间刻度 |
| `textOnAccent` | `#FFFFFF` | 强调色上的文本 |

### 强调色（功能色）

| Token | Hex | 用途 |
|-------|-----|------|
| `accent` | `#3CD5C8` | 主强调 — 选中态填充、活跃 tab、功能 icon |
| `accentDim` | `#2A9B91` | 暗强调 — 选中行背景色（accent @20% 混合） |
| `recording` | `#E85050` | 录制状态 — 录制按钮、录制指示 |
| `recordingGlow` | `#E85050` @ 0.3 | 录制发光效果 |
| `waveform` | `#E87850` | 波形色 — 珊瑚橙，音频波形条 |
| `waveformDim` | `#E87850` @ 0.4 | 波形弱电平 / 选区外 |

### 状态色

| Token | Hex | 用途 |
|-------|-----|------|
| `success` | `#4CAF50` | 正常、已连接 |
| `warning` | `#FFB74D` | 高电平 70-90% |
| `danger` | `#EF5350` | 过载 >90%、错误 |

### 分割线

| Token | Hex | 用途 |
|-------|-----|------|
| `divider` | `#ffffff` @ 0.08 | 区域间唯一分割线（toolbar 与轨道区之间） |
| `dividerLight` | `#ffffff` @ 0.04 | 轨道区内虚线引导 |

**规则：分割线仅允许出现在以下 3 个位置，其余全靠色差：**
1. Toolbar 底部 — 与轨道区分隔
2. 轨道头与片段区之间 — 竖向分割
3. 面板内部功能分区之间 — 横向分割（如左侧 tab 栏与列表之间）

### 快速开发参考

```swift
// 背景（3 级核心）
bgDeepest:    #1B1B1F  // 轨道区、窗口底
bgPanel:      #2A2A2E  // sidebar、toolbar、卡片面板
bgElevated:   #363638  // hover、active

// 文本
textPrimary:  #E8E8EA  // 主文本
textSecondary:#A0A0A5  // 次要
textTertiary: #6B6B70  // 占位符

// 功能色
accent:       #3CD5C8  // 选中、交互
recording:    #E85050  // 录制
waveform:     #E87850  // 波形

// 分割
divider:      white @8%  // 仅用于 toolbar 底部
```

## 3. 字体规范

### 字体系列

- **主字体**：SF Pro（系统字体）
- **等宽数字**：SF Mono — 计时器、dB 值、时间码
- 无自定义字体

### 字号层级

| 角色 | 大小 | 粗细 | 用途 |
|------|------|------|------|
| Title | 13px | Semibold | 分区标题（系统音频、App 音频、麦克风设备） |
| Body | 13px | Regular | 列表行文本、按钮标签 |
| Caption | 11px | Regular | 次要信息、badge、格式标注 |
| Timer | 28px | Bold Mono | 录制计时器 |
| Mono | 11px | Regular Mono | dB 值、时间码、采样率、状态栏 |

### 规则

- 分区标题使用 `textSecondary` 色 + Semibold，不需要大写
- 数值类永远等宽（计时器、时间刻度、dB、采样率）
- 行内最多 2 级字重变化（Semibold + Regular）

## 4. 圆角规范

**全局统一 3 种圆角值：**

| Token | 值 | 用途 |
|-------|-----|------|
| `radiusSm` | 6px | 小元素 — 按钮、badge、输入框、列表行 hover |
| `radiusMd` | 10px | 中元素 — 面板卡片、toolbar、sidebar 内分区 |
| `radiusLg` | 14px | 大元素 — 弹窗、设置窗口 |
| `radiusFull` | 50% | 圆形 — 录制按钮 |

**铁律：整个 App 只用这 4 档圆角，不出现 4px/8px/12px/16px/32px 混用。**

## 6. 组件规范

### 6.1 面板（Panel / Card）

面板是 AudioRecord 最核心的视觉容器。

**样式：**
- 背景：`bgPanel` (#2A2A2E)
- 圆角：`radiusMd` (10px)
- 边框：**无**
- 阴影：**无**
- 内边距：`spacing12` (12px)

**面板与底色关系：**
```
窗口底色 #1B1B1F
  └─ 面板 #2A2A2E（浮于底色之上，靠色差区分）
      └─ 面板内元素（文本、列表行）
```

**规则：**
- 面板之间不用边框分割，靠 `bgDeepest` 底色做间隙（4-8px 间隙即可）
- 面板内部不再嵌套卡片（扁平化）
- 面板内部功能分区之间允许 1px `divider` 横线（如 tab 栏与列表之间、列表与底部状态区之间）

### 6.2 Sidebar（左侧面板）

**整体：**
- 宽度：220px 固定
- 背景：`bgPanel` (#2A2A2E)
- 圆角：右侧无圆角（紧贴窗口左边缘），或整体 10px 圆角（若浮于底色上）
- 与右侧内容区之间：**无分割线**，靠色差区分

**内部结构：**
```
Sidebar (#2A2A2E)
├─ Tab 切换（录制 / 文件）— 顶部 padding 12px
├─ 分区标题 "系统音频" — textSecondary, 13px Semibold
├─ 系统音频行 — 40px 高, 左侧 12px padding
├─ 分区标题 "App 音频" + 刷新按钮
├─ App 列表（可滚动）
│   ├─ 行高 40px, icon 24px + 文字
│   ├─ hover: bgElevated 背景 + radiusSm 圆角
│   └─ 选中: accent 背景填充（不用边框！）
├─ 分区标题 "麦克风设备"
└─ 麦克风开关行
```

**列表行选中态（关键改动）：**
- ❌ 旧方案：青色边框描边 → 看着碎、不整体
- ✅ 新方案：`accentDim` (#2A9B91) 背景填充 + 白色文字 + `radiusSm` 圆角

### 6.3 Toolbar（工具栏）

**参考剪映 toolbar 设计：**
- 背景：`bgPanel` (#2A2A2E)
- 高度：44px
- 圆角：`radiusMd` (10px)，或顶部 10px + 底部 0px
- **底部分割线**：`divider` (white @8%)，1px — 这是整个界面唯一的主分割线
- 内边距：左右 12px

**工具按钮：**
- 默认：透明背景，`textSecondary` 色 icon
- Hover：`bgElevated` 背景 + `radiusSm` 圆角
- Active/选中：`accent` 色 icon（不变背景）
- 禁用：0.3 透明度

### 6.4 轨道区（Timeline）

**背景：**
- 使用 `bgDeepest` (#1B1B1F) — 最深色
- 轨道引导线：`dividerLight` (white @4%) 虚线

**轨道片段（Clip）：**
- 背景：`bgPanel` (#2A2A2E)
- 圆角：`radiusSm` (6px)
- 波形色：`waveform` (#E87850)
- 垂直居中于轨道区，上下留空（不顶满）

**轨道头（Track Header）：**
- 宽度：独立区域，约 60-80px
- 背景：与轨道区同色 `bgDeepest`
- 与片段区之间：1px `divider` 竖线分隔（参考剪映 image-5）
- 图标：🔒 锁定、👁 可见、🔊 音量、S Solo
- 图标排列：纵向堆叠或横向排列，`textSecondary` 色

**时间标尺：**
- 背景：`bgDeepest`
- 刻度文字：`textTertiary` (#6B6B70), 11px Mono
- 刻度线：`dividerLight`

### 6.5 控制面板（底部录制区）

**背景：** `bgPanel` (#2A2A2E)
**圆角：** `radiusMd` (10px)（顶部有圆角，浮于底色上）
**高度：** 80-100px（比旧版 150px 更紧凑）

**布局：**
```
┌─────────────────────────────────────────────┐
│   00:00.00       [● REC]        48kHz Stereo │
└─────────────────────────────────────────────┘
```

- 计时器：28px Bold Mono, `textPrimary`
- 录制按钮：48px 圆形, `recording` 色, 录制时脉冲发光
- 格式信息：11px Mono, `textTertiary`

### 6.6 录制按钮

- 尺寸：48px 圆形
- 空闲：`recording` (#E85050) 实心圆
- 录制中：`recording` + 脉冲发光（`recordingGlow`），圆内变为方形 stop 图标
- 无多层复杂发光（简化旧版 3 层 glow 方案）

### 6.7 电平表

- 位置：右侧窄栏（24px 宽）或内嵌于波形区右上
- 背景：`bgDeepest`
- 填充渐变：`success` → `warning` → `danger`
- 刻度：`textTertiary`, 10px Mono
- 无边框

### 6.8 状态栏

- 位置：窗口底部
- 高度：24px
- 背景：`bgDeepest`（与窗口底色融为一体）
- 文本：`textTertiary`, 11px Mono
- 内容：`● 录制中  48kHz`

### 6.9 Tab 切换（Sidebar 顶部）

- 选中 tab：icon/文字变为 `accent` 色 + 底部 2px 小指示点
- 未选 tab：icon/文字为 `textSecondary`
- 整体高度：44px（含 icon + 文字标签）
- 布局：水平等分排列（如剪映顶部 素材/音频/文本/贴纸... 栏）
- **注意：不是整个 tab 块填充颜色，是 icon+文字变色**

### 6.10 Toolbar 工具组按钮（选中态）

- 默认：透明 + `textSecondary` icon
- 选中/激活：`accent` 色小方块背景（圆角 4px, padding 4px）+ icon 变白
- 这类按钮是「模式切换」类（如剪映的磁吸/对齐/关键帧按钮组）
- 与普通 ghost 按钮（hover 才变色）区分开

## 9. 必须 / 禁止

### 必须

- 用 3 级背景色做空间层次（`bgDeepest` / `bgPanel` / `bgElevated`）
- 选中行用背景色填充（`accentDim`），不用边框
- 面板用 `radiusMd` (10px) 统一圆角
- 列表行高统一 40px
- 面板内边距统一 12px
- 计时器和数值用等宽字体
- 轨道片段垂直居中，上下留空

### 禁止

- ❌ 不用边框线做区域分割（只有 toolbar 底部可以有 1px divider）
- ❌ 不在卡片/面板上加 border
- ❌ 不用多种不同圆角值（只有 6/10/14 三档）
- ❌ 不用阴影（暗色界面阴影无意义）
- ❌ 不用纯白 #FFFFFF 或纯黑 #000000
- ❌ 不用发光效果做装饰（仅录制按钮可以脉冲发光）
- ❌ 不在选中态用描边/边框高亮（用填充色）
- ❌ 不在同一视觉区域混用超过 2 种背景色
- ❌ 不让面板之间紧贴无间距（至少留 1px bgDeepest 透出）

## 11. Token 源映射（待重构）

当前代码使用 `IndustrialDesignTokens.swift`，需重构为新 Token 体系：

| 新 Token 类 | 覆盖范围 |
|------------|---------|
| `StudioColors` | 背景色、文本色、功能色、分割线 |
| `StudioTypography` | 字号、字重、字体系列 |
| `StudioSpacing` | 间距值 |
| `StudioRadius` | 圆角值 |
| `StudioLayout` | 固定尺寸（sidebar 宽度、行高等） |

**迁移优先级：**

## 评审详情

### ✅ 设计亮点（做得好的）

1. **三态信息架构清晰** — idle/recording/editing 三态的 UI 差异化设计是正确的产品决策。用户不会困惑"我现在在哪个状态"。

2. **录制按钮视觉焦点** — idle 态将 REC 按钮作为唯一视觉焦点，符合 Fitts 定律（大目标 + 高对比 = 快速点击）。当前实现中 `IndustrialRecordButtonView` 已有 48×48 尺寸 + `statusCritical` 红色，视觉权重足够。

3. **编辑工具栏隐藏策略** — idle 态隐藏编辑工具栏是正确的"默认做减法"（原则 #8）。当前 `EditToolbarView` 已有 `setEnabled(false)` 机制，改为 `isHidden = true` 更彻底。

4. **电平表实时预览** — 在 idle 态显示实时输入电平是优秀的"准备就绪"信号设计。用户看到电平跳动就知道"声音通路正常"，减少认知负担。

5. **状态栏引导文案** — 从"准备就绪"改为"选择录制目标，点击 ● 开始录制"，提供了明确的行动指引。

### ⚠️ 需要补充/优化的设计细节

#### FINDING-001 [MEDIUM] 波形区占位内容缺少精确视觉规格

**问题**: PRD 提到"麦克风/音波图标 + 文案"，但未定义：
- 图标具体尺寸（建议 48×48 或 64×64）
- 图标与文案的间距
- 文案字体大小和权重
- 整体占位区域的垂直居中方式

**建议规格**:
```
图标: SF Symbol "waveform.circle" 或 "mic.fill"
图标尺寸: 48×48
图标颜色: IndustrialColors.onSurfaceVariant (alpha 0.6)
文案: "点击 ● 开始录制"
文案字体: IndustrialTypography.body (13px Regular)
文案颜色: IndustrialColors.textTertiary
图标-文案间距: 12px
整体: 水平+垂直居中于波形区域
```

#### FINDING-002 [LOW] "上次录制"快捷入口设计模糊

**问题**: PRD 提到"如果有上次录制的文件，可选择显示'上次录制：xxx.wav'的快捷入口"，但：
- 这是可选功能还是必须功能？
- 视觉上如何与引导占位共存？
- 点击后的行为是什么？（进入编辑态？播放？）

**建议**: V1 先不实现此功能，保持 idle 态极简。后续版本再考虑"最近文件"快捷入口。理由：idle 态的核心目标是"引导录制"，增加快捷入口会分散注意力。

#### FINDING-003 [MEDIUM] 无障碍设计缺失

**问题**: PRD 未提及任何无障碍要求。作为 macOS 原生应用，需要：
- VoiceOver 对 idle 态占位内容的朗读（"录制准备就绪，按空格键开始录制"）
- 键盘快捷键提示（空格键 = 开始录制）
- 波形区占位图标的 accessibility label

**建议补充**:
```swift
// 波形区 idle 态 accessibility
waveformView.setAccessibilityLabel("录制准备区域")
waveformView.setAccessibilityHelp("按空格键或点击录制按钮开始录制")

// 录制按钮 accessibility
recordButton.setAccessibilityLabel("开始录制")
recordButton.setAccessibilityRole(.button)
```

#### FINDING-004 [LOW] 录制按钮"脉冲动画"需要克制

**问题**: PRD 提到"脉冲动画暗示'可点击'"。需要注意：
- 动画不应过于频繁（避免分散注意力）
- 应遵循 `prefers-reduced-motion` 系统设置
- 建议使用微妙的呼吸效果（opacity 0.8↔1.0，周期 2s），而非明显的缩放脉冲

**Craft 规则引用**: `animation-discipline.md` — 动效仅用于空间/时间重定向，有持续时间和缓动约束。

#### FINDING-005 [LOW] 轨道板 idle 态"灰色圆点"需要与录制态红色指示灯形成对比

**问题**: PRD 提到"灰色圆点，非红色录制指示灯"，这是正确的状态区分。建议：
- 灰色圆点使用 `IndustrialColors.textTertiary` (#9CA3AF)
- 尺寸 8×8，与录制态红色指示灯 (8×8, `statusCritical`) 保持一致
- 确保两态切换时有微妙的颜色过渡动画（200ms ease-out）

## 结论与建议

### 评审结论: ✅ 通过（附建议）

设计规格整体方向正确，信息架构清晰，与现有 Industrial Design 系统一致。可以进入开发阶段，但建议在开发时注意以下优先级：

### 开发优先级建议

1. **P0（必须）**: 编辑工具栏 idle 态隐藏 + 录制按钮视觉突出 + 状态栏引导文案
2. **P1（应该）**: 波形区引导占位 + 电平表实时预览 + 轨道板待录制状态
3. **P2（可选）**: 录制按钮脉冲动画 + "上次录制"快捷入口

### 下游建议

- **交矩（架构师）**: 关注 ViewMode 状态机的实现方式，确保三态切换的代码架构清晰
